## 1. 我们卖的是什么（对外表述原则）

**正确表述（推荐）**

- 卖的是：**「手绘工坊」网站学习权益开通码**（兑换码）。
- 买家付款后收到**短码** → 打开官网/App → 登录会员 →「权益兑换」输入短码 → 系统开通对应权益。
- 写清：网站名称、权益内容、有效多久（写生/工具用「一次开通，长期可用」；Pro 写明月/年；**对外勿写「永久」**）、兑换步骤、到账时效（如「兑换成功即时生效」）、客服边界。

**禁止 / 高危表述**

| 禁止 | 原因（政策方向） |
|------|------------------|
| 出售/出租**网站账号、共享账号、密码直登** | 账号类属高风险禁限售方向；且与我们站点防共用策略冲突 |
| 暗示「网盘打包下载整站课程」「百度网盘发货」作为**主交付**（尤其挂「教育培训·在线课堂」叙事） | 教育培训规范要求在线观看通道合规；网盘交付易被滥发/侵权投诉 |
| 「你懂得」「老用户专拍」「补差价」等无法判断商品 | 数字生活等规范明确禁止无法判断的商品 |
| 把多个**品牌**或多个**有效期**糊在同一链接却不说清 | 数字生活规范：不同品牌、有效期须分商品发布 |
| 购买前强制旺旺联系才能拍 | 数字娱乐等规范禁止限制购买/强制先联系 |
| 向买家索取**验证码、登录密码、支付密码**等非交易必要信息 | 数字生活等规范明确禁止 |
| 第三方品牌会员（腾讯视频/QQ 会员等）无授权代充 | 须官方授权目录内商品 + 授权；未经准入可删品扣分 |
| 盗版课程、未授权素材当正版卖 | 知识产权；教育类盗版可清退频道并按规则处理 |

## 2. 类目与资质（上架前必做）

1. **先在千牛发品页搜叶子类目**，选带「虚拟 / 服务 / 电子凭证」属性、且**无需物流或支持自动发货**的类目；**严禁**错放到实物服装等类目（滥发/降权/下架）。
2. **不要默认挤进「教育培训 → 淘宝同学在线课堂」**：该类对录播通道、在线观看、电子凭证等要求严；我们当前交付是**自有站兑换码**，更贴近「自有网站数字权益 / 软件服务 / 数字生活类虚拟服务」叙事——**最终叶子类目以发品时系统可选且可过审的为准**，选定后写回本文「类目定稿」表。
3. 若系统提示**准入 / 保证金 / 授权**：先办完再上架；属于「须提供官方授权的虚拟商品目录」的品类（多为第三方大牌充值）**不要碰**，我们只卖**自有品牌「手绘工坊 / 童画师吴晓」**权益。
4. 入驻相关虚拟行业市场（若要求专营）前，确认会不会**限制只能卖该类目**——本店还有旧素材货，**不宜**为卖几个码而整店锁进「游戏点卡」类专营市场。

### 类目定稿（2026-11-06 · 千牛发品页实测）

**首批 5 链统一叶子：**

`生活服务 → 网店/网络服务/软件 → 电脑软件`  
（发品页路径字样：`网店/网络服务/软件>电脑软件`）

| 写生·几何 | 手绘工坊 静物写生台 兑换码 | 生活服务 > 网店/网络服务/软件 > 电脑软件 | 阿奇索卡密 | 一次开通，长期可用 |
| 写生·肖像 | 手绘工坊 肖像写生台 兑换码 | 同上 | 阿奇索卡密 | 一次开通，长期可用 |
| Pro·3月 | 手绘工坊 高级会员Pro 三个月 | 同上 | 阿奇索卡密 | 分链 |

**为何定这格（业务结论）**

- 卖的是**自有站学习权益兑换码**，叙事贴近「软件/网络服务使用权」，不是淘宝同学录播课、也不是第三方会员代充。
- **无**「数字娱乐生活市场」专营锁定提示；入驻该类市场后会**无法再发市场外类目**——本店还有旧教程货与后续定制服务，**绝不能**为卖码整店锁死。
- 发品时须选品牌：优先「无品牌/无注册商标」，或日后新增「手绘工坊」自有品牌；**不要**冒用第三方软件品牌。
- 流量不靠「逛电脑软件类目」；靠标题关键词、店铺分类「手绘工坊」、旧货/站外导流。

**明确不用（首批）**

| 路径 | 原因 |
|------|------|
| 其他商品 → 数字生活 → 生活娱乐线上会员 / 生活购物消费会员 等 | 要入驻数字娱乐生活市场，且可能限制只能发该类 → **危及旧货与定制** |
| 同级「网络软件账号」 | 账号售卖高危，与我们「兑换码开权益」冲突 |
| 教育培训（淘宝同学通道） | 录播/在线课堂规范严；首批交付是站内兑码，暂不挤 |
| 其他商品 → 兑换卡（实物/零售卡券向） | 与网站权益码不贴合 |
| 充值平台软件/加款卡 | 易碰授权/充值类管控 |

**与肖像画定制等其它货的关系（硬口径）**

- 本定稿**只约束「手绘工坊兑换码」新品线**的叶子类目。
- **不影响**以后挂肖像画定制、头像定制、设计服务等：仍走本店已有能力类路径（如发布历史中的「头像定制/手绘真人漫画/画类定制」、`个性定制/设计服务/DIY`、`商务/设计服务` 等——以上架时系统可选且可过审为准）。
- 前提是：**不要**为卖码去入驻「只能卖数字生活/点卡」类专营市场。选「电脑软件」正是为避开这条锁店坑。
- 旧教程素材继续留在原类目作引流；与新品用标题前缀/店铺分类区分即可。

## 3. 链接拆分规则（SKU / 一品一链）

1. **Pro 不同时长 = 不同商品链接**（或平台明确允许的多 SKU 且属性为「服务时长」且展示清晰）。优先**分链**，减少「多有效期糊一链」违规风险。
2. **写生两库 = 两个商品**（几何 / 肖像），不与 Pro 绑死同一链接（产品未决「Pro 是否含写生」前，默认**分开卖**）。
3. 旧货教程素材与手绘工坊新品：**标题前缀/店铺分类区分**（如「【手绘工坊】」vs 旧编码 CO/SKA），避免买家以为买到的是网盘旧课。

## 4. 详情与主图必写清单（合规优先）

每条新品详情须含（可用模块固化）：

1. **品牌**：手绘工坊 · 童画师吴晓（**主图/详情烤图不印官网域名**；域名在拍后发货消息）。  
2. **权益内容**：写生库名或 Pro 档位；**不含**未购买的其他库/课包。  
3. **有效期**：写生/工具写「一次开通，长期可用」；Pro 写 X 月/年（自兑换成功起算，与站点逻辑一致）。**对外勿写「永久」**。  
4. **交付方式**：付款后自动发送**兑换短码**（非账号密码）；发货消息含开通地址。  
5. **使用步骤**：拍下后按卡密/发货说明 → 登录官网或 App → 会员页「权益兑换」→ 粘贴短码 → 即时生效。  
6. **到账时间**：兑换成功后即时（或写明最长人工处理时效）。  
7. **设备与登录限制**：如实写站点规则（如设备数上限），避免「可无限共享」。  
8. **售后**：  
   - 虚拟商品往往不适用七天无理由——须在显著位置说明；  
   - **未兑换**可退；**已兑换**按站点规则（当前工程：退款是否收回权益仍为产品未决——对外先写「已兑换请联系客服，按实际使用情况处理」并尽快在路线图钉死）。  
9. **禁止诱导**：不引导微信/支付宝私下转账；不索要短信验证码。

主图建议：品牌名 + 权益名 + 「兑换码发货」角标；避免「全网通用会员」「游戏代充」等误导视觉。

## 5. 自动发货与卡密（阿奇索 + 运营台）

1. **只使用**服务市场正规工具（本店：**自动发货阿奇索**）；不用来路不明外挂脚本。  
2. 卡密 = 站点运营台按类型批量生成的**一码一用短码**；导出后导入阿奇索对应商品/SKU 卡密库。  
3. 库存 = 未发出卡密数量；售罄或卡密耗尽要停售或补码，**禁止超卖空单**。  
4. 作废未兑码：运营台作废后，阿奇索侧对应库存也要同步失效，避免发出废码。  
5. 保留发货记录、卡密导出批次，便于纠纷举证。

## 6. 禁限售红线（与本店相关的摘要）

以下方向按《淘宝禁售商品管理规范》等长期管控理解（表述随官方更新）：

- 出售/出租各类**账号**（含网盘账号、视频站账号等）。  
- **盗版**课程、未授权数字内容。  
- 第三方大牌会员/点卡**无授权、非准入**代充。  
- 代写论文、代考、考试答案等不当教育服务。  
- 刷单、站外收款、洗钱式虚拟交易。

旧货区若存在**非自有版权**教程/合辑：长期风险高；新品线不要复用「网盘合辑」玩法；旧货逐步清理时优先下架版权不清款。

## 7. 教育培训类目特别提醒

- 「教育培训」下在线课程规范强调：**在线观看**、指定发布通道；**网盘/邮件发包当课**易被删。
