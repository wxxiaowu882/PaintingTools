> 3. **下列旧稿默认不作设计依据**（多已过时，现网场景已有较大变动）：`场景规划设计.md`、`几何体场景设计草案.md`、`几何体场景设计.md`、`几何体场景设计_舞台版本.md`；`站点规划_访谈与路线图.md` 只作站点级目标备忘，**不约束**单个场景怎么设计。写文案时若旧稿与现网冲突，**跟现网、跟本文**。

## 1. 一句话结论

| 块 | 它是什么 | 它不是什么 |
|----|----------|------------|
| **场景说明** | 列表里扫读用的**短简介** | 不是本场景知识正文 |
| **童画师讲解** | 进场景**必看**的知识正文：我要通过本场景向学员传达的内容 | 不是一句口号、不是「定调子」 |
| **场景内标注** | 围着讲解转的**落地配合**（指哪儿、看什么） | 不是另开一堂课，也不和讲解抢同一段总结 |

三条拧成一句话：**列表勾兴趣 → 讲解把知识讲透 → 标注让眼睛对上号。**

### 2.1 生产端字段（JSON / 编辑器）

### 2.2 谁在什么时候看

- **场景说明**：还在目录里时看；决定「要不要点开」。

- **标注**：对照**当前画面**与引线看；短标签 +（必要时）详细说明，服务讲解里已经钉死的那一点。

## 3. 「童画师讲解」的宗旨（最高优先级）

**童画师讲解 = 我想通过本场景向学员传达的知识。**

它相当于整场的知识载体，必须同时尽量覆盖（可长短不一，但意图要全）：

1. **引导** — 进来先看什么、怎么看（不训人、不施压）  
2. **知识说明** — 本场景真正要讲清的内容（可以多段，不限于一句口号）  
3. **总结** — 学完带走什么（能复述、能迁移）  
4. **铺垫** — 和下一个场景怎么接（链条感，而不是孤立卡片）

### 3.1 合格 / 不合格

**合格**

- 学员只读这一块，也能说清「这一关学会了什么判断 / 什么看法」。  
- 和场景里看得见的证据对得上（不是空讲）。  
- 空字段要补；已有但只剩口号、跑题、或和标注重复同一段总结的，要重写。

**不合格**

- 只有氛围句、鸡汤句，没有可带走的知识。  
- 把本该在讲解里的正文，整段塞进某条红色「★ 总之」标注里（讲解空着或极短）。  
- 一口气讲多个互不统属的知识点（主线索糊掉时，优先砍讲解，而不是硬塞）。  
- 列表说明写得像操作手册（点哪、关标注等）——这类进场景后再讲。

### 3.2 语气（和品牌一致）

- 自称语境：**童画师吴晓**在讲；温暖、邀请，**欢迎感，不训人**。  
- 术语先人话，再给名字。  
- 不搞「每天打卡练」式营销；要的是看得懂、记得住、愿意收藏分享。  
- 大白话优先；该精炼就精炼，不堆说明书腔。

### 3.3 用语：符合中文习惯（高优先级）

写讲解、说明、标注时，优先用学员听着自然的说法；**少用翻译腔 / 文案腔**。

**硬规矩：不用中文里生疏、生硬的词和搭配。** 学员听着别扭、日常不这么说的，一律改掉。写完自检一句：**「学员平时会不会这么说？」**——不会，就换成人话。

**收束、强调时（推荐）**

- 「请记住」「请牢记」  
- 「敲重点：…」  
- 或直接把重点句加粗，不必硬套固定前缀  

**避免（听着别扭）**

- 「带走这句话」「带走两句」——不像日常中文，以后不要用  
- 同类生硬套话：为「显得像课」而硬造的口号前缀  
- **生造搭配 / 生疏说法**（例：「圆转上的体积」——中文里一般不这么说）  
- **非日常指称**（例：说画面用「这一镜」→ 改用「这一幅」；勿用「手就多练一层」这类硬造层递）  

其它句子同样原则：能说「就眼前这个画面，对照标注看…」，就不要写成洋腔或公文腔；口诀、术语可以保留韵味，但解释句要像人在说话。收束、比喻须一听就懂。

### 3.4 观察口径：钉在当前画面（高优先级）

每个教学场景默认已经定好相机与光位——**眼前这张画面，就是要分析的画面**。

**推荐写法**

- 「请就眼前这个画面，对照标注看…」  
- 「在当前画面里认清：哪里是亮部，哪里是暗部…」  

**讲解正文禁止（认调子 / 找交界 / 验虚实的必要步骤）**

- 「转视角 / 慢慢转视角 / 转动视角 / 调节视角」——一转，画面就变了，刚才讲的调子对不上号  
- 「改光 / 微微改光 / 调节光线 / 动主光」——当作完成本关判断的默认练习（同样会重塑画面）  

**边界说清楚**

- 工具本身仍可让学员自由转、自由调光（逛场景、写生模式等），这没问题。  
- 但「童画师讲解」**不指挥**学员改画面来完成这一关的明暗/交界/虚实判断；分析钉在进入场景时看到的那一帧教学画面上。  
- **写生类例外（练习延伸，不是认调子捷径）**：先就眼前这一幅练熟之后，可鼓励学员自己调光线、视角或氛围，再用万物观察法看一遍、再写生——详见 §5.4。这与「禁止把改光/转视角当作完成本关判断的必要步骤」不冲突。

### 3.4.1 写文案须严格对照截图 / 当前画面（最高优先级之一）

协作方根据用户提供的**场景截图**（或编辑器当前所见画面）写「场景说明 / 童画师讲解」时：

**必须**

- 先看图，再下笔：高光硬不硬、谁更亮、谁染了谁的色、暗部朝向谁——**以画面里看得见的证据为准**。  
- 材质以当前所用材质为准（如「自带材质」与「亮面陶瓷」观感不同）；用户若说明已切换材质，须按**切换后的截图**重写，不得沿用旧材质下的判断。  
- 物邻色染、环境色等，只写**画面上确实能看到、且朝向关系说得通**的那一对；写清「谁的什么色 → 染到谁的哪一侧」。

**禁止**

- 凭「金属就该高光很硬」「釉面就该怎样」「多件同台就一定互相染色」等**经验公式**臆造现象。  
- 写与截图不符的句子（例：图上易拉罐高光并不锐，却写成「高光又窄又硬」；图上绿釉瓶暗部并未对着可乐亮部，却写成「绿瓶也染上了红」）。  
- 把教学知识点硬塞进画面里没有证据的位置。

**自检一句**：写完后对照截图问——「这句话在图上找不找得到？」找不到，就删或改。

### 3.5 目标表述勿缩水（高优先级）

说明与讲解里的**本关目标**，必须对准真实学习意图；**禁止**为求短、求顺口而说偏、说浅。

**禁止**

- 把目标说成幼稚捷径（例：画球 ≠「画圆了」；写生不是为了画成一个圆）  
- 把入口步骤写成全部答案（例：只写「先分阴阳、再立交界」就暗示「做完就够」——阴阳与交界是入口，不是光影关系的全部）  

**应当**

- 写清本关完整意图（如：把球上的光影关系看全、画稳——亮、灰、暗、反光与投影都要落在该在的位置）  
- 教学关里步骤可以提示观察顺序，但须让学员明白：**还有层次与整体关系要落稳**，不是两步交差  
- **写生关例外**：不按「画法步骤」写目标或讲解（见 §5.4）；主线索仍须对准「光影关系看全、看稳」，勿缩水

## 4. 「场景说明」怎么写

- **位置**：只服务目录扫读；短、分行、一眼抓住。  
- **默认结构（三行内为佳）**  
  1. 一句钩子（为什么在乎）  
  2. 一句用 `<b>...</b>` 钉死的**本关主线索**（能加粗就加粗；不要为了「唯一判断」硬套旧模板）  
  3. 可选：一句引路（别写成操作步骤）  
- **允许**：换行；仅 `<b>` 强调。  
- **禁止**：堆标签字段（入门/分钟/收益等）；在列表里写「点写生 / 拖光 / 关标注」等操作说明。  
- **目标勿缩水**：加粗主线索须符合 §3.5——不得缩成错误或片面目标（例：勿写「球就容易画圆了」这类说法）。  
- **和讲解的关系**：说明是「门上的牌子」；讲解是「进门后的展板」。说明里出现的关键句，应能在讲解里被展开，而不是两套互相打架的说法。  
- **跟现网**：某一类场景在现网里已经形成自己的说明口吻时，优先对齐同类现网场景，而不是对齐过时设计稿。

## 5. 结构按场景类型（不定死一套四段模板）

约定：**不强制每个场景都写成固定四段标题**；按**现网实际类别 / 编号习惯**选骨架，但 §3 的四种意图（引导 / 知识 / 总结 / 铺垫）在合适处要落下来。  
下面分类是按当前沙盒目录常见形态写的**工作提示**，不是旧设计稿的强制课表；某一类现网做法已经变了，以现网为准，并回写本节。

### 5.1 入门 / 导览（如 `001` 欢迎、`002` 以简驭繁）

- 偏欢迎 + 世界观 +「你接下来会碰到什么」。  
- 讲解可以稍长；标注以「举例指认」为主，**不要把总结再写进一条大标注里**。  
- 铺垫：指向学员接下来更可能点开的那一类（以现网目录顺序为准）。

### 5.2 万物观察法 · 单形体步骤链（球/方/柱/锥/棱… 步骤一～三、最深处、虚实等）

- 优先对齐**同形体相邻编号**的现网讲法；讲解把「看哪里、看什么变化」写清。  
- 引导句短；知识段是主体；结尾用一两句接到现网里真实的下一步（不要按过时课表硬接）。  
- 标注：对准证据点，用词与讲解一致。

### 5.3 构图 / 色彩 / 氛围专题

- 讲解先钉本关主看法；对比、口诀可进讲解。  
- 场景说明更要短、钩子强。  
- 标注负责指出对比双方或关键区域，不复述长文。

### 5.4 几何体写生 / 静物写生

这类场景是**对照写生**：用已学看法练观察、练手，**不是**再开一整课万物观察法 / 色彩 / 构图。

**宗旨（高优先级）：偏观察，不教「怎么画」**

- 童画师讲解**只提醒如何观察**（用前面教学关已学的万物观察法，就眼前这一幅来看）。  
- **不教作画手段与落笔顺序**：不写「先画外形 → 再铺大调子 → …」这类画法课；也不偏向铅笔素描 / 水彩 / 油画等任一画种。  
- **为什么**：学员用什么材料、什么技法因人而异；写生关要的是**观察对了、最后效果关系站住**，不是统一成同一种画法。可轻描一句「用你习惯的方式画就好」，点到为止。  
- **观察也不开细课**：不要在写生关里重讲亮灰、暗灰、交界带的完整定义与步骤；一句「用前面××课走过的万物观察法来看」即可。本关只需**轻点 1～2 个与本形体相关的重点**（如圆柱侧壁多是交界带、方折交界常贴棱），让学员知道「和上一关哪里脾气不同」。

**讲解怎么写**

- **短提示优先**：半屏左右够用；骨架**可参考**（不是必填顺序）：请进眼前这一幅 → 唤起万物观察法 → 轻点本形体重点 → 练习节奏 → 下一关出口。  
- **意图可同、措辞必须换皮（最高优先级之一）**：同编号段写生关教学意图可以一条链，但**每一关的开场、切口、比喻、强调句、收束都要重新写**，读起来应像人在说话，有人情味；**严禁**只换器物名、其余照抄上一关。像「依葫芦画瓢」的批量生成感，一律不合格。  
- **换皮时至少换掉这些**：  
  1. **开场切口**：可从器物性格、光线、最易看错处、装饰抢眼处等起笔——**不要**每关都以「这一幅……旁边一颗小球」起。  
  2. **本关只抓 1 件真脾气**：金属高光锐、花纹抢戏、竖棱多、固有色深……点透即可；**不要**每关把六区调子清单全文背一遍。  
  3. **口头禅轮换**：认准 / 看清楚 / 校对 / 拆开看 / 别被带走……轮着用；禁用固定套话串（如每关都「六区调子最老实 → 一眼能对上 → 不要停在模糊里 → 自圆其说 → 多看几遍 → 熟了再改光」）。  
  4. **收束可变**：有时鼓励再看，有时只留一句提醒，有时轻接下一幅脾气——**不要**每关同一段尾声。  
- **节奏（仍要有，但说法可变）**  
  1. 先就**眼前这一幅**用万物观察法看（钉住当前光与视角，符合 §3.4）  
  2. **同一幅可以反复看、反复画**——不要催着换下一幅  
  3. 熟了，再鼓励自己调光线、视角或氛围，换一套条件，再用万物观察法看一遍、再画（练习延伸，见 §3.4 边界；**不必每关都把这句写满**）  
  4. 「下一关」写成**练够了再走**的出口，不要写成「画完马上换」  

**场景说明**

- 短；主线索对准真实写生目标（§3.5），偏「把光影关系看全、看稳」，勿幼稚缩写，也勿写成画法说明书。  
- 相邻写生关的说明句式亦宜略有变化，避免目录扫读时像复制粘贴；**禁止**「先认球上的光，再用六区调子给××定点」这类生硬、雷同句。  

**标注**

- **默认可不加**。教学关已指认过的亮部 / 交界 / 暗部等，写生关不必再标一遍。  
- 仅当本关有**新的、教学关未指认过的**关键证据时，才建议补短标注；否则交付时写明「不必再加」。  

**铺垫**

- 按现网同类场景的真实衔接来写；出口语气轻，不催进度。
### 5.5 静物写生 · 陶瓷器皿专项规则

> 适用范围：`2200`～`22xx` 系列「静物写生」场景（陶瓷罐、陶瓷壶、花瓶等器皿为主体）。

#### 5.5.1 场景命名约定

- 统一称「陶瓷」，不称「陶」（因质感往往含瓷器成分）。
- 场景 `name` 和 `meta.detail` 里的器物名，以**器物实际形态命名**，而非用编号流水号（如「双耳陶瓷罐」「残破瓷罐」「鼓腹陶罐」「陶瓷壶」「陶瓷罐与花瓶」），**禁止**用「陶瓷罐01 / 陶瓷罐02」直接对外命名。
- `meta.detail` 主线索加粗格式参考：`<b>静物写生 · 器物名</b>`。

#### 5.5.2 几何参照体（小球/小柱）的讲解处理

- **有参照体时**：可点明参照体用途（认光向、对照六区调子），但**参照体不是每关开场的固定主角**；可写成「小声提示」「对照灯」等，也可后置或一笔带过。  
- **无参照体时**：说明「脑子里把器皿拆成简单体来看」，无需专门道歉或说明「没有参照体」。  
- 参照体只是**入口**，不是主角；讲解篇幅重心放在器皿本身。

#### 5.5.3 素描部分（骨架）的写法

- 同 §5.4 原则：只提醒如何**观察**，不教落笔顺序与具体技法；**每关表述必须换皮**（见 §5.4「措辞必须换皮」）。  
- **知识要有、句子要新**：下列意图应出现，但**禁止**用同一套句式串联——  
  1. 唤起万物观察法 / 六区调子（点本器皿脾气即可，**勿全文背六区清单**）。  
  2. 看不准时可根据光向、面的朝向、邻接关系**主动推断**（说法轮换，勿每关同一句）。  
  3. 练习节奏可提「同一幅多看」，**不必**每关写满「熟了再改光或视角」。  
- **用语忌生硬搭配**：如「用六区调子给罐身定点」——中文不习惯这么说；改用「按六区调子把明暗看清楚 / 认准 / 分析 / 校对」等自然说法。

#### 5.5.4 色彩延伸段（方案 A 末尾追加，但禁止复读同一段）

每个场景讲解末尾**追加**色彩提醒（可用「如果你正在用色彩作画——」起笔，也可换更口语的起法），规则如下：

**意图（要有）：**

1. 明暗骨架先稳住，色彩跟六区色律走。  
2. **只写本场景真用得上的色彩点**（固有色深浅、釉面/金属高光、白地与纹样、物邻色交等）——点透 2～3 处即可。  
3. 涉及天光时，遵守下方天光括注约定。

**禁止（防机械化）：**

- **不要**每关全文复读六区色律标准描述。  
- **不要**每关以同一句收束（如固定「六区调子定了位，色彩就跟着落」）。  
- 标准描述仅作**素材库**，按需裁剪、改写进本关口气。

**六区色律素材（可按需裁剪，勿整段粘贴）：**

> 高光被主光冲淡、纯度最低近乎白；亮灰是本色最足的地方，明度与纯度都高；交界带往暗走，色发闷、纯度收；暗灰色浊而压；反光略透一点，仍在暗部里，可带一点环境色；投影偏灰，常混地面或天光的色味。

**天光的写法（重要）：**

- 这一系列场景**默认未设置天光**（天光色为黑色）；凡提到「天光染阴 / 天光偏青 / 阴处偏冷」，**必须在首次出现处**说明可自调，措辞宜友好、无歧义。推荐口径之一：  
  > `（场景默认未设置天光，你可以在"氛围"面板中自行调整天光颜色来体验这个效果）`  
  也可写成更口语的等价句（如「这个场景默认没有开天光，想体会阴处偏冷，可以自己去氛围面板里调天光颜色」）——**意思不变即可，句子宜换皮**。  
- 同一段后续再出现「天光」不重复加括注，避免啰嗦。  
- 若某场景实际已设置了天光色，则不需此括注，但需在讲解里说明。

**物邻色交 / 临物而色染：**

- **先看图，再决定写不写**：只有截图里确实看得见染色，才写；并写明「谁 → 染到谁的哪一侧」。  
- 多件同台**不等于**件件互染。暗部若没有对着邻物亮部，就不要写染上了邻色（例：绿釉瓶暗部未对可乐亮部 → 不写「绿瓶染红」）。  
- 单件器皿 + 浅色小球/小柱：物邻色交常不明显，可点到为止或省略。  
- 固有色深的器皿：若画面上暗部易糊成死黑，再提醒「亮灰仍是纯度较高处，反光要留色彩倾向」——仍须与画面相符。

#### 5.5.5 样板口径（2210「换皮」）

`2210` 花卉纹装饰罐一稿可作为静物写生「换皮」参考：开场从「装饰抢眼」起，小球降为小声提示，六区调子点到为止，色彩段只谈白地+花+金，收束不走固定尾声。后续 `2211` 及以后**对齐这种人情味与变化感**，不要退回「先看球 → 敲重点 → 色彩全文 → 多看几遍」的流水线。

### 5.6 静物写生 · 水果专项规则

> 适用范围：`2300`、`2302`～`2315` 等「静物写生 · 水果」场景（现网无 `2301`）。  
> 拍板口径：**1C**（单果偏「别被果皮抢走体积」+ 同色六区色变；组合关偏整桌主次）+ **2A**（用果名 / 组合实名，不用「水果01」对外）。

#### 5.6.1 和几何体、陶瓷罐的差别（写之前先认清）

| | 几何体 | 陶瓷罐 | 水果 |
|---|---|---|---|
| 形体 | 标准、可拆 | 硬壳容器，外形复杂 | 更接近有机体：鼓、扁、弯、凹、蒂、棱 |
| 表面 | 哑光石膏感为主 | 釉面 / 哑光 / 纹饰 | **果皮**：蜡质反光、绒毛、麻点、条纹、鳞片 |
| 颜色 | 固有色单纯 | 釉色 + 纹饰 | **固有色强、品种感强**，同色里还有熟度变化 |
| 易偏航 | — | 被纹饰/金边/商标带走 | 被「画得像某个水果」带走——抄皮纹、丢体积 |

水果段基调：**用已学会的看法，去对付有皮、有品种、有细节诱惑的有机体**；不是再开一批「画水果技法课」。

#### 5.6.2 命名约定（2A）

- 单果用**果名**（如「红苹果」「香蕉」「火龙果」）；组合用实名（如「果盘」「桌上的水果」）。  
- **禁止**对外使用「水果01 / 水果02」。  
- `meta.detail` 加粗格式参考：`<b>静物写生 · 果名</b>`。

#### 5.6.3 主钉子怎么分（1C）

**单果关（约 `2300`～`2308` 一类）偏重：**

1. **别被果皮细节抢走体积**（本段对陶瓷「纹饰抢戏」的对应钉子）：果脐、梗、斑点、条纹、鳞片再清楚，也只是表面；先让圆鼓/弯柱等体积与六区调子站住，再谈皮上的花活。  
2. **同色在六区里怎么变**：同一种红/黄/绿，亮灰本色最足，高光被冲淡，暗部发闷；深色果提醒勿画死黑。  
3. 几何参照体（球/柱等）可当认光尺子，**不抢戏**；水果比参照体「多出来」的是起伏与皮，不是另一套光。

**组合 / 果盘关（约 `2309`～`2315` 一类）偏重：**

1. 整桌同一套光、主次清楚。  
2. 次要可弱化、复杂可暗示（接陶瓷段后半「后方弱化 / 暗示复杂」）。  
3. 邻色染色**先看图再写**；无证据不写。  
4. 氛围·气：现网水果关多数未开厚雾——**不作为水果段主课**；截图若无明显气，勿每关复读远淡近实。

#### 5.6.4 写法共性（与 §5.4 / §5.5 对齐）

- 偏观察，不教落笔顺序与画种技法。  
- **每关必须换皮**；开场切口跟着该果脾气走（圆、弯、刺、深色、一盘乱……）。  
- 严格对照截图（§3.4.1）：果皮高光软硬、邻色有无，以画面为准，禁止「水果就该怎样」的公式臆造。  
- 色彩延伸可短，点本关 2～3 处；天光默认未开则首次提及说明可自调。

#### 5.6.5 背景墙：环境色对比（工具核心价值之一，高优先级）

水果段（及同类静物写生）讲解 / 场景说明中，**宜主动鼓励**学员使用下方控制面板里的「背景墙」：

- **开 / 关背景墙**对比看一遍：暗部、反光、投影边缘的色彩与明暗有何不同。  
- **自设背景墙颜色**再对比：墙的反光会作为环境色渗进物体（尤其暗部与反光区），比「只开天光」往往更容易看出环境色影响。  
- 点明这是本工具的核心价值之一：同一套形体与主光下，换环境、换墙色，观察立刻可变——写生时不要只抄默认一帧。  
- 措辞宜邀请、可动手；可提示调乱了用「重置」。**不必每关长篇复读**，但水果段开篇关（如 `2300`）与色彩相关关应写清楚；后续关可用一句换皮提醒承接。  
- 与 §3.4 不冲突：此处是**练习延伸 / 工具体验**，不是「必须改墙才能认完本关六区调子」。

### 5.7 其它 / 综合类

- 先看该场景自己已经摆了什么、标了什么，再反推讲解该讲什么。  
- 少引入和画面证据对不上的新概念；总结仍归讲解，标注只做索引。

> 某一类型写多了若形成固定小节标题（如「先看」「记住」「下一站」），可以沉淀回本文档，但**先跟现网内容，后沉淀模板**。

## 6. 标注如何配合讲解

- **从属关系**：讲解是统领；标注是附件。改讲解时，顺带检视标注是否过时、重复、抢戏。  
- **短标签**：指认对象或现象（「圆柱体」「交界线」）。  
- **详细说明**（标注的 `detailText` 等）：需要时再展开类比/补充；不要把整篇讲解搬进一条标注。  
- **建议交付物**（做文案优化时）：除两段正文外，可附「标注改写 / 增补建议」（改哪条、删哪条、**建议新加哪几条**、语气怎么收）；需要落地时再给可粘贴清单。

### 6.0 缺标注时要主动建议补（高优先级）

优化场景时，不只处理「已有标注怎么改 / 删」，还要看：**讲解里钉死的关键证据，画面上有没有指认点？**

**该建议加标注的常见情况：**

- 讲解写了「左 / 右」「这个 / 那个」，但模型上没有对应短引线，学员对不上号  
- 本关关键现象只出现在讲解或地面总述里（如「圆锥在圆柱上的投影」「灰球无色相 / 红球有色相」），画面上缺一条短指认  
- 对比课、并置课只有文字说明，缺少指向对比双方的标注  

**怎么建议：**

- 主动写出「建议新建」清单：锚在哪个对象 / 区域、短标签文案、是否需要半句详细说明  
- **宜短不宜长**：新标注只指路，细则仍归童画师讲解；不要再造一条总述长标注  
- 若现有标注已够用，明确写「不必再加」，避免为加而加  

**写生关（与「该补」并列的另一面）：**

- 几何体写生 / 静物写生：**默认可不加标注**（见 §5.4）  
- 教学场景已指认过的同名证据（亮部、交界带、暗部等），写生关**不要再标一遍**；交付时写明「不必再加」  
- 仅当出现教学关未指认过的新证据时，才按上面「该建议加」处理

### 6.1 历史债：讲解正文曾写在「经典标注」里（必查、必迁）

早期版本还没有「童画师讲解」字段时，有些场景会把**本该是整场知识正文**的内容，写进场景里的一条（或几条）**经典引线标注**。这是已知历史债，优化场景时**默认要主动排查**，不靠用户逐条点名。

**常见识别信号（满足多条更可疑）：**

- 篇幅明显长于同场景其它标注  
- 语气像总述 / 收束 / 练习指令（「总之」「请你找出」「记住」「掌握…即可」等），而不是指认某个局部  
- 颜色或位置像「总述牌」（如醒目红、★ 开头），不像普通指认  
- `meta.keyPoints` 为空或极短，但标注里已有完整论述  

**处理步骤：**

1. **主动发现**：同时读 `meta.keyPoints` 与全部标注的 `text` / `detailText`，用判断识别「这其实是讲解正文」。  
2. **移植**：迁入 **童画师讲解**（`keyPoints` / `keyPointsRich`）。  
3. **优化**：按 §3 重写——补引导、理顺知识、收束、接下文；**不是原样粘贴完事**。  
4. **善后标注**：原总述标注改为短指认、删除，或只留与局部证据相关的一句；**禁止**讲解与标注各留一份完整总结。  
5. **两边都有时**：以「哪套更贴近本场景画面证据、更符合 §3」为准合并优化，去掉重复那一侧。

> 例：`002` 一类场景里，红色「★ 总之，复杂世界都是由简单几何体构成…」长标注，即属本条对象。

## 7. 和业务目标的对齐（写的时候心里要有数）

- 访客要感到：这是 **童画师吴晓** 设计的学习场景，有路径、能学会，不是冷冰冰工具页。  
- 几何体·静物线服务「观察入门 → 可迁移到静物/肖像」；文案要帮品牌记住所教的路径，而不是堆术语。  
- 内容权威在**生产工具生成的 JSON**；文案定稿后在生产端写入并发布，**避免手改已发布 JSON 当常态**（紧急修正也要回到生产端闭环）。

## 8. 专业纠偏：把教学体系当作活的作品来完善

写文案时，协作方不只做「填字段」，还要以**专业艺术家 / 教学设计者**的眼光，随时审视这套场景教学体系，发现问题就提出，并尽量当场收进该场景交付（需要定规矩的则回写本文）。

**随时可纠的方面（不限于纯文案）：**

- **观察与造型**：术语是否先人话后术语；形体 / 光影 / 边缘是否说准；有没有和画面证据打架。  
- **教学节奏**：本关主线索是否清晰；是否过载；和相邻场景是重复、断层，还是接得上。  
- **审美与呈现**：标注是否吵画面；总述是否抢戏；说明 / 讲解是否像说明书，而不是「欣赏中学习」。  
- **路径感**：学员读完是否知道「学会了什么、下一眼看哪」；品牌语气是否仍是童画师吴晓（欢迎、不训人）。

**怎么落地：**

- 发现不足 → 在该场景交付里直接改文案 / 给标注与结构建议；需要成文定规矩 → **补进本文修订记录**。  
- 不替用户擅自改生产 JSON（除非明确要求落地）；但**必须主动指出**，不能假装没看见。  
- 纠偏优先级：先让「童画师讲解」站住 → 再收标注与说明 → 再提体系级结构调整建议。

## 9. 协作时怎么推进（我们以后按这个干活）

### 9.1 单场景交付检查清单

写完或优化一个场景时，自问：

1. 场景说明是否短、有钩子、有加粗主线索、无操作说明书？主线索有无按 §3.5 缩水成错误/片面目标？  
2. 童画师讲解是否能单独讲清本关知识，并含引导 / 收束 / 下节钩子（按类型可有侧重）？  
3. 是否已排查「讲解正文藏在经典标注里」的历史债？该迁的是否已迁入讲解并优化，标注是否已去重？  
4. 标注是否服务于讲解、无重复长总结？讲解里的关键证据若画面上对不上号，是否已**主动建议补短标注**（或写明不必再加）？写生关是否避免重复教学关已教过的分区指认？  
5. 是否跟**该场景现网内容**一致（模型、标注、相邻编号），而不是跟过时设计稿一致？  
6. 语气是否欢迎、是否先人话后术语？收束是否用「请记住 / 请牢记 / 敲重点」等自然说法（不用「带走这句话」）？**有无生疏、生硬的词和搭配**（§3.3）？  
7. 观察指令是否钉在**当前画面**（有无「转视角 / 改光」来认调子、找交界）？写生关是否写成「先就这一幅用万物观察法反复看/练 → 练熟后再调参再观察」，而不是催换下一幅？**对照截图自检**：高光、材质、邻色染色等描述是否都在图上找得到（§3.4.1）？  
8. **写生关专查**：是否偏观察、**未**写成落笔顺序 / 某画种技法课？是否只轻点本形体重点、未复读教学关细课？与相邻写生关相比，开场/切口/收束/色彩段是否已**换皮**（不像依葫芦画瓢）？有无生硬搭配（如「给××定点」）？水果关是否符合 §5.6（果名实名；单果勿被果皮抢走体积；组合偏主次；描述对照截图）？  
9. 可粘贴进生产端的正文是否**不含**「场景说明 / 童画师讲解」等分区标题（见 §9.2）？  
10. 以专业艺术家视角：本场景在观察、节奏、审美、路径上有无明显漏洞？有则是否已提出纠正？
### 9.2 建议工作顺序

1. **先读现网**：该场景 JSON 的 `name`、`meta`、**全部标注文案**，以及目录里前后相邻场景——这是设计真相来源。  
2. **先判历史债**：`keyPoints` 空/弱 + 标注里有总述长文 → 按 §6.1 移植并优化进童画师讲解。  
3. 再写/改 **童画师讲解**（定知识），再压 **场景说明**，再给 **标注建议**（改 / 删 / **该新建的也写上**，见 §6.0；写生关常为「不必再加」）。  
4. 顺带做 §8 的专业纠偏（能当场改的改，需定规矩的回写本文）。  
5. 成批做时：按现网类别或编号段推进；新类型先共创 1 个样板定**意图与节奏**，再按关写；写生关**复制骨架不复制原句**（见 §5.4）。  
6. UI 显示名已改为「童画师讲解」（内部字段仍为 `keyPoints`）；与文案落地可分开推进。  
7. 发现旧稿与现网冲突时：改文案跟现网；有必要再把结论补进本文，**不要回头去「修好」过时设计稿当依据**。
