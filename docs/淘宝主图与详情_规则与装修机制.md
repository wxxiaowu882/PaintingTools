## 0. 业务怎么套到规则上（先读这节）

我们淘宝卖的是两类：

| 类型 | 交付 | 类目口径（已定） | 详情要强调 |
|------|------|------------------|------------|
| 写生台 / 三工具 / Pro | **兑换短码** → 官网开通 | 网店/网络服务/软件 → 电脑软件 | 不是账号密码；不是网盘整包课；Pro 非视频课 |
| 约画（肖像定制） | 沟通 + 手绘交付 | 定制/设计服务类（另选叶子） | 定制流程、周期、修改次数、肖像授权 |

**对外文案红线（本店已钉）**

- **勿写「永久」**（含标题、主图字、详情烤图）。写生/工具统一：**一次开通，长期可用**。  
- Pro：**三个月 / 一年 / 三年**，分链。  
- 勿写：最、第一、顶级、独家、百分百、立刻见效、终身 VIP、账号出租。  
- 勿诱导站外收款；勿索要短信验证码 / 支付密码。

站点内侧 `productUnlocks` 仍是「不限期权益」，**对内可说长期，对外不说永久**。

## 1. 主图规范（设计时就要守）

### 1.1 常见尺寸与张数（以发品页提示为准）

| 项 | 业内常用口径 | 我们建议 |
|----|--------------|----------|
| 主图比例 | **1:1**（本店发品页已核） | 首批虚拟权益按 **1:1** |
| 推荐尺寸 | 发品页提示 **1440×1440** | 导出按 1440；亦可 800～1200 再放大，以清晰为准 |
| 张数 | **最多 5 张** | 第 1 张定身份；2–5 张讲权益/对比/步骤/系列 |
| 格式 | png / jpg / jpeg | 深色画室风可用深底；**勿靠白底硬凑「实物感」** |
| 主图上的字 | **同样受广告法 / 滥发信息约束** | 字少、可读；烤进图前过一遍禁用词 |
| 3:4 / 1:1 互裁 | 编辑器有「从 3:4 主图裁剪 / 从 1:1 主图裁剪」 | 视频封面可互裁；主图仍以 1:1 为主 |

### 1.2 主图内容原则（结合我们业务）

1. **一眼能判断卖什么**：品牌「手绘工坊 / 童画师吴晓」+ 权益名（写生台 / 晓阶 / Pro…）+「兑换码」或「定制」。  
2. **第 1 张不要堆说明书**：主信息 ≤3 块（名 / 一句价值 / 交付形态）。  
3. **虚拟品易被误判**：避免「游戏代充 / 全网通用会员」视觉；Pro 卡上已有 logo+标题即可，不必再叠站内角标（首页已定不加）。  
4. **肖像 / 儿童图**：仅用自有作品或已授权；约画主图勿蹭明星。  
5. **旧货「钢笔淡彩」等网盘合辑**：可参考其**学习心理文案结构**，**不要**复用「网盘打包课」交付叙事到新品线。

### 1.3 主图建议结构（7 品共通骨架）

| 序号 | 作用 | 示例 |
|------|------|------|
| 1 | 身份卡 | 产品名 + 一句人话价值 + 兑换码/定制 |
| 2 | 解决什么烦恼 | 「形飘 / 色脏 / 画不像」等 |
| 3 | 你得到什么 | 权益清单（短） |
| 4 | 怎么用 | 拍下收码 → 官网兑换 → 开通（三步） |
| 5 | 系列导航 | 「还可搭配：写生台 / 工具 / Pro / 约画」 |

约画第 4–5 张可改为：流程 / 适用对象 / 作品局部，不必硬套兑换三步。

### 1.4 高质量主图标准（调研摘要 · 本店取舍）

> 来源：淘宝开放平台「商品素材上传规则」公告（建议宽 **1440**、原图质量、避免二次压缩）、发品页本店实核（1:1 · 1440×1440 · ≤5 张）、以及公开整理的主图/白底/牛皮癣口径。细则仍以千牛 / [rule.taobao.com](https://rule.taobao.com/) 最新提示为准。

| 项 | 平台侧常见「高质量」口径 | 本店怎么做 |
|----|--------------------------|------------|
| 比例 | **1:1** 为主；部分类目另有 3:4 | 7 品主图按 **1:1** |
| 像素 | 旧底线多见 800；**建议宽 ≥1440**（手机 2K 更清晰） | 导出目标 **1440×1440**；勿把小图硬拉大 |
| 张数 | 最多 **5** 张 | 满 5 张叙事（身份→烦恼→权益→三步→系列） |
| 清晰度 | 原图导出；上传质量检测会拦糊图/过压 | 烤图前不二次狠压；确认页虚拟裁剪只定取景 |
| **色彩** | 真实不过度艳丽；光线均匀；忌荧光大色块字抢戏 | 深色画室可保留，主体仍须清晰可读 |
| **内容** | 图物一致；主体居中偏大；第 1 张干净、字少 | 自有截图/作品；第 1 张定身份；卖点放 2–4 |
| 文字 | 忌「牛皮癣」：面积宜 ≤20%；禁价格/促销/联系方式/二维码/极限词 | 字少可读；禁「永久」；主图 1 字最少 |
| 白底图 | 实物类常建议第 5 张纯白底（猜你喜欢等） | **虚拟兑换码不强求白底实物**；第 5 张优先系列导航 |
| 主体 | 商品/界面一眼能辨；主体占比宜高（常说 ≥60%） | 缩略图（搜索/推荐）也要能认 |
| 禁区 | 夸大宣传、非本品牌 Logo、盗图、与商品不符 | 只用自有截图/作品；Pro 非视频课说清 |

确认页<strong>每张主图上方</strong>各写该张作用与注意点（第 1 张最干净；2–5 须有画面底、勿纯文字；第 5 张本店不强求白底实物）。

**本地确认页**：主图/详情图位均可「编辑」→ 换图 + 虚拟裁剪（缩放 / 拖移 / 明暗对比饱和 / 衬字遮罩），对齐店铺装修确认页交互。

## 2. 详情页内容规范

### 2.1 必须出现的信息块（兑换码类）

与 `淘宝店铺商品规则.md` §4 对齐，详情烤图或文字模块须覆盖：

1. 这是什么（写生台 / 工具等**权益开通码**；静物样板钉「3D 几何体·静物写生台」，勿写成「学习/课程」）  
2. 你将获得（本链权益；**不含**未购的其它库/课）  
3. 有效期（一次开通长期可用 / Pro 时长）  
4. 怎么用（注册登录 → 权益兑换 → 粘贴短码）  
5. 怎么开通：拍下后按卡密 / 发货说明兑换（**详情不印官网域名**；域名在发货消息里）  
6. 售后（虚拟品；未兑可协商；已兑联系客服）  
7. 注意（勿分享短码；不提供账号；不索验证码）

### 2.2 文案与社区常见雷区

| 雷区 | 我们怎么避 |
|------|------------|
| 绝对化 / 极限词 | 不用最、第一、顶级、独家… |
| 「永久 / 终身」 | 改「一次开通，长期可用」；Pro 写清月年 |
| 功效保证 | 不写「包学会 / 立刻画出大师感」 |
| 虚假交付 | 不写网盘发整站课；不写送账号 |
| 诱导站外 | 不写加微信发货、私域转账 |
| 图片文字违规 | 烤图前文案过一遍；OCR 也会扫主图/详情图 |
| 肖像权 | 儿童/人物作品须有权；定制须委托人授权说明 |

### 2.3 「钢笔淡彩」可借鉴点（学习心理层）

旧货详情里曾有**学习心理**向文案（缓解畏难、强调练习节奏、降低「买了就该马上会」的焦虑）。新品详情建议保留同结构的一块**共通模块**，例如：

- 学人物画最难的不是颜料，是**敢看、敢改、敢反复**  
- 工具 / 写生台帮你把「看不见的形与光」摊开看，不是替你画完  
- 一次练一小步，比囤一堆网盘课更重要  

具体措辞以读图精录为准（见 §5 待补）。**交付叙事不可照搬旧货网盘合辑。**

## 3. 详情装修技术机制（千牛）

### 3.1 两条路径别混

| 路径 | 入口（大致） | 做什么 |
|------|--------------|--------|
| **店铺首页装修** | 店铺 → 店铺装修 → 手机/PC | 楼层海报、热区、货架；**不是**商品详情 |
| **商品详情装修** | 商品 → 商品装修 / 详情装修；或发品页「电脑端详情 / 手机端详情」 | **单个宝贝**的详情内容 |

本波设计的是 **商品主图 + 商品详情**；首页深色画室确认页是另一条线（已有确认页）。

### 3.2 详情页常见机制（设计假设）

1. **主体仍是「从上到下的图文流」**  
   - 有图的段落：用 **宽度固定的详情图**（手机常见宽 **750px**，高度按段切开，单张不宜过长以免加载差）。  
   - **本店「长图 / 配图」口径**：场景实拍、控制条效果、课表规模拼图等 **画面** 用图；图上若有叠字（总览卡标题、主图大标题等）才烤进图——**叠在图上的字不要拆成纯文本**（位置与观感绑死画面）。  
   - **图外说明尽量用真文字**（品牌、适合谁、权益说明、学习心理、系列导航、图上方「图片说明」、扩容提示等）：千牛侧用文字/图文模块承载，**不要为了「省事」把整段说明再烤成无画面的纯字图**。  
   - **图外字体（2026-11-10 实核口径）**：淘宝详情**挂不上**官网同款 **Inter** / 外链 webfont。买家端中文基本是系统字（iOS 多见苹方系，Windows 多见微软雅黑）。确认页「图外真文字」预览改用 **苹方 / 雅黑 · 常规字重**，靠 **字号层级 + 行距 + 深浅色** 保可读；**不要**用细到 100/200 的 Inter 气质去期待千牛落地。  
   - **主图 / 图上叠字**仍可按官网 Inter 排版后**烤进图**（字形可控）。图外品牌感靠配图与主图，不靠详情硬嵌自定义字体。  
   - 发品页可见「使用文本编辑 / 使用旺铺详情编辑器」；**勿为查字体擅自点「返回旧版图文描述」**（有不可逆提示）。

2. **电脑端详情 vs 手机端详情**  
   - 两端常**分开编辑**；可共用素材思路，但导出宽度不同（PC 详情图常更宽，如 790 / 990 量级，**以编辑器提示为准**）。  
   - 我们确认页可「一稿两切」：先定叙事与模块，再导出手机/PC 两套静帧。

3. **官方详情模板 / 智能详情**  
   - 千牛「商品装修」可拖模块（图文、关联宝贝、店铺推荐等）。  
   - **基础版能力有限**；复杂排版仍以**自绘长图**最稳。  
   - 关联宝贝模块适合做「7 品互联」（写生台详情挂工具与 Pro 等）。

4. **图片空间**  
   - 详情图须先入本店图片空间；外链图不可靠。  
   - 单张体积控制（常见建议控制在约 500KB～2MB 级，以当页提示为准），过重拖慢详情打开。

5. **与主图的关系**  
   - 主图在商品头图轮播；详情在「图文详情」区。  
   - 主图第 1 张决定搜索/列表第一眼；详情负责转化与降低纠纷。

6. **热区 / 跳转**  
   - 详情长图上的「按钮」若只是画上去，**默认不能点**，除非用支持热区的详情模块或关联宝贝组件。  
   - 互联互通优先用：**关联宝贝模块** + 文案引导「搜店内：晓阶 / Pro…」，不要假装可点的假按钮却无链。

### 3.3 对本店 7 品设计的落地含义

| 设计物 | 本地确认页 | 千牛落地 |
|--------|------------|----------|
| 主图 1–5 | 确认页预览 + 导出 PNG | 发品「主图」上传 |
| 详情配图（场景/控制条/课表等） | 确认页分区贴图预览 | 手机/PC 详情上传图片模块 |
| 图外文案（说明/列表/心理等） | 确认页真文字 + 统一样式；预览详情可见 | 千牛文字/图文模块，尽量不烤纯字图 |
| 共通块（兑换三步 / 心理 / 售后 / 系列导航） | **一套组件多品复用** | 同一套导出图复用，只换头图与权益段 |
| 品间互联 | 详情内「系列导航」+ 关联宝贝 | 关联模块链到真实 itemId |

## 5. 详情编辑器机制（本店发品页 2026-11-09 实核）

编辑入口示例：`item.upload.taobao.com/sell/v2/publish.htm?itemId=…`

| 能力 | 本店可见 |
|------|----------|
| 图文描述 | 「使用文本编辑」/「使用旺铺详情编辑器」；可「返回旧版图文描述」 |
| 预览 / 模板 | 有预览、保存为模板、清空 |
| 主图区提示 | 1:1 · 推荐 1440×1440 · 最多 5 张 · png/jpg/jpeg |
| 电脑端 vs 手机端 | 发品流程内分块；详情长图建议宽 **750**（手机）为主设计，再切 PC |

**落地含义**：**有画面才上图**；图外说明用真文字；关联宝贝做互联；假按钮无链不要画。

**本店确认页口径（2026-11-09）**

- **主图**：设计稿旁「搜索 ≈168 / 推荐 ≈120」是**同一张 1:1 的真实缩小**（淘宝不能分传搜索专用/推荐专用主图；确认页勿做成三套不同字图比例）。用途：检查缩略是否可辨。  
- **缩略可读闸门（硬）**：凡烤进淘宝主图的字，以**推荐流 ≈120** 为验收底线——须一眼可认；**不通过就删字或改成大标题级**，勿指望「大图好看、缩略看不清也没关系」。  
- **主图 ≠ 详情总览**：详情最前总览屏与淘宝主图**切断关联**（独立贴图、独立文案）；详情够宽，用通览字号，**勿套用主图缩略放大字**。静物样板总览现为 **4 屏**（去掉「系列」；系列互指走详情底部共通「系列导航」）。  
- **文案禁「画飘」**：对外主图/详情勿用「形总画飘 / 画飘了」等虚词；痛点改「体积立不起来 / 大形对不准 / 缺石膏布光」等。  
- **主图品名**：静物样板第 1 张用 **「3D 静物写生台」**（点明在线 3D，避免被当成实体桌子）。  
- **主图字体**：对齐官网首页「手绘工坊」——**Inter + 苹方 / 微软雅黑**（细字重），**不用宋体**；忌报纸/硬广黑体堆字。  
- **主图字**：极短版**只留大标题**（不要副句/角标占位）；**单行不换行**，字号随主图框宽自适应（长句缩小）；确认页可点字改，写入 `mainCopy`。  
- **详情文案**：确认页给出框架 + 初始稿；五屏总览（`overviewCopy`）与各段落（`detailText`）均可点字改；「清空已贴图」不删文案。定稿后再烤进导出图。

### 本店确认页 · 草稿防丢（硬性）

确认页草稿存在**本机浏览器 localStorage**（键名稳定：`tb-product-detail-slots`）。

| 规则 | 说明 |
|------|------|
| **禁止改存储键名当「清库」** | 曾因 `…-v2`→`…-v3` 导致主图设置像被覆盖。功能升级只**扩字段**（如加 `regions`），旧主图 `mains` 必须保留。 |
| **旧版键只读合并** | 打开页面时自动把历史键（v1/v2/v3 等）里**有图的槽**合并进稳定键；有图的优先保留，空槽不盖有图。 |
| **导出 / 导入** | 「导出草稿」→ JSON；「导入草稿（整份替换）」会**整库覆盖**。导入 / 清空 / 只补空图前，页面会**自动再下一份「安全快照」**到下载目录。 |
| **只补空图 ≠ 整份恢复** | 「从备份只补空图」**只填无 `src` 的槽**；**禁止**用旧备份整槽覆盖当前 `caption` / 取景 / 文案块。整份回滚只能走「导入草稿」，且须先有安全快照。 |
| **Agent 改确认页 / 修图时** | 不得清空用户 `mains`；不得换新键丢弃旧数据；schema 变更须带合并逻辑。**禁止**用 CDP/`localStorage.setItem` 把旧备份整份写成 preferred 当前稿；缺图时只允许 `fillMissing` 语义（空槽补图，文案与已有取景一律保留）。修前先请用户或脚本导出快照；修后核验：图数量、抽样长文案、取景是否仍是用户下午稿。 |
