安装步骤（安卓）
  1. 点「下载安卓安装包」，等通知栏或文件 App 出现下载。
  2. 若浏览器提示「文件可能有害 / 危险」：从网页装 App 时经常会出现，属正常提醒；选「仍要下载 / 仍要安装」即可（本站官方安装包）。
  3. 打开下载好的 APK；若提示未知来源，允许本次安装。
  4. 桌面出现「手绘工坊」即可打开（需联网）。

若点击后没反应：请确认不在微信内打开；或点「复制下载链接」到 Chrome / 系统浏览器粘贴访问。
