# 站点安全配置（业务账本）

> **用途**：记录我们已做的站点安全取舍与落点，避免靠对话记忆。  
> **修订**：2026-10-30  
> **Agent 记忆**：同步见 `.cursor/rules/site-security.mdc`

---

## 1. 产品口径（先读）

| 话题 | 口径 |
|------|------|
| 单课 JSON 直链 | **暂不修**。高级会员配方外泄可接受；门禁管正规入口，不追求直链绝对防下。 |
| GLB 防盗链 | **要做**：挡外站挂我们模型 URL；**不挡**用户本机下载/另存。 |
| GLB 加密 | **后置**。加密挡不住懂技术的人从浏览器抠模型；全工具链成本高。 |
| 防内嵌 | **已做**：外站 iframe 嵌我们的页 → 浏览器拦；**安卓 App 整页打开，不受影响**。 |
| 防盗链实现 | **用 Cloudflare 面板 WAF 自定义规则**；**禁止**再在业务 Worker 里做防盗链（曾试过，已回退）。 |
| 图片防盗链 | **暂不做**（避免影响搜索引擎收录图片）。 |

## 2. 已落地清单

### 2.1 防内嵌（仓库配置）

- 文件：仓库根目录 `_headers`
- 头：`X-Frame-Options: SAMEORIGIN` + `Content-Security-Policy: frame-ancestors 'self'`
- 作用：静态 HTML 等；测站 / 正式均已验证
- 冒烟：`docs/membership/prod-deploy-smoke.mjs` 会查防内嵌头

### 2.2 模型防盗链（Cloudflare 面板，非 Worker）

| 项 | 内容 |
|----|------|
| 作用域 | Zone **`wuxiaoart.com`**（含 `test.` / `www` 等子域） |
| 入口 | Dashboard → 域名 → **Security** → **Security rules** → Custom rules |
| 规则名 | **`Block model hotlink`** |
| 动作 | **Block**，状态 **Active** |
| 表达式（大意） | 路径以 `/docs/model/` 开头 **且** Referer 非空 **且** Referer 不含 `wuxiaoart.com` **且** 不含 `soft-voice-f822` |
| 放行 | 空 Referer（App / 部分内置浏览器 / 直链下载仍可能成功——防盗链不防下载）；本站页面加载 |
| 不拦 | `/docs/img/`、`galleryIMG` 等图片路径（SEO） |
| 验收 | 2026-10-30：测站/正式「外站 Referer → 模型 403」；本站/空来源 → 200；图片外站来源 → 200；**安卓 App 开课加载模型 OK** |

**明确禁止**：在 `functions/` + `wrangler.toml` `run_worker_first` 里再挂防盗链。原因：占免费 Worker 请求次数；用户要求走面板；已整段回退。

### 2.3 登录 / 注册 / 兑换 / 运营台防刷

- `functions/membership/rate-limit.js`
- 挂到：学员登录、注册、兑换；运营台登录
- 失败多次 → 429

### 2.4 发版安全预检 / 冒烟

- 预检：`docs/membership/prod-deploy-preflight.mjs`（Secret 是否存在、探针是否关）
- 冒烟：`docs/membership/prod-deploy-smoke.mjs`（含防内嵌头）
- 说明：`docs/membership/DEPLOY.md`、`.cursor/skills/site-prod-deploy/SKILL.md`

### 2.5 版本与壳

- 站戳 / 壳戳：`docs/site-version.json`；App 显示 `V{壳}.{站}`
- 壳改动升版本：`.cursor/rules/android-webview-shell.mdc`

## 4. 改面板时的同屏约定（防指错页）

1. 优先用 **Cursor 内置浏览器**打开 Dashboard，双方看同一窗口。  
2. 每步：打开页 → 截图/口述标题 → 用户回「一致」再点下一步。  
3. **只按屏幕上实际出现的按钮文案**指挥，禁止套文档旧入口名（曾因此把用户带到转域名页 / Variables 页）。  
4. Cloudflare MCP OAuth 弹窗易超时、按钮文案因界面而异；面板改规则以 **已登录的 Dashboard 同屏** 为主，不必强绑 MCP。

---

## 5. 以后若要加严

1. 模型路径仍优先 WAF；若加图片，须单独评估爬虫 Referer / SEO。  
2. 若 App 误伤：检查是否误拦空 Referer；放行条件不要收太紧。  
3. 免费档 Custom rules 条数有限；改规则前先看现网 `Block model hotlink` 是否已存在，避免重复建。
