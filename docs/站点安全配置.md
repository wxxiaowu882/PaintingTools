## 2. 已落地清单

### 2.1 防内嵌（仓库配置）

- 文件：仓库根目录 `_headers`
- 头：`X-Frame-Options: SAMEORIGIN` + `Content-Security-Policy: frame-ancestors 'self'`
- 作用：静态 HTML 等；测站 / 正式均已验证
- 冒烟：`docs/membership/prod-deploy-smoke.mjs` 会查防内嵌头

### 2.2 模型防盗链（Cloudflare 面板，非 Worker）

| 项 | 内容 |
|----|------|
| 作用域 | Zone **`wuxiaoart.com`**（含 `test.` / `www` 等子域） |
| 入口 | Dashboard → 域名 → **Security** → **Security rules** → Custom rules |
| 规则名 | **`Block model hotlink`** |
| 动作 | **Block**，状态 **Active** |
| 表达式（大意） | 路径以 `/docs/m/` 开头 **且** Referer 非空 **且** Referer 不含 `wuxiaoart.com` **且** 不含 `soft-voice-f822` |
| 放行 | 空 Referer（App / 部分内置浏览器 / 直链下载仍可能成功——防盗链不防下载）；本站页面加载 |
| 不拦 | `/docs/img/`、`galleryIMG` 等图片路径（SEO） |
| 验收 | 2026-10-30：测站/正式「外站 Referer → 模型 403」；本站/空来源 → 200；图片外站来源 → 200；**安卓 App 开课加载模型 OK** |

**明确禁止**：在 `functions/` + `wrangler.toml` `run_worker_first` 里再挂防盗链。原因：占免费 Worker 请求次数；用户要求走面板；已整段回退。

### 2.3 登录 / 注册 / 兑换 / 运营台防刷

- `functions/membership/rate-limit.js`
- 挂到：学员登录、注册、兑换；运营台登录
- 失败多次 → 429

### 2.4 发版安全预检 / 冒烟

- 预检：`docs/membership/prod-deploy-preflight.mjs`（Secret 是否存在、探针是否关）
- 冒烟：`docs/membership/prod-deploy-smoke.mjs`（含防内嵌头）
- 说明：`docs/membership/DEPLOY.md`、`.cursor/skills/site-prod-deploy/SKILL.md`

### 2.5 版本与壳

## 6. 模型加密原则（已定稿口径 · 待实施 · 可迭代）

> 2026-10-30 与业务对齐。目标：**加载几乎无感** + **后缀伪装** 都重要；安全预期是「挡顺手下载 / 别的播放器不好开」，不是绝对防逆向。

### 6.1 后缀与双轨兼容

| 后缀 | 含义 | 工具 / 前台 / 后台 |
|------|------|-------------------|
| **`.glb`** | **明文**（尚未加密） | **必须能直接读、播、处理**（兼容迁移期与内部作业） |
| **`.png`（现行假后缀）** | **已加密** | 经**同一加解密包**解密后再播/处理；导出进公网目录时默认加密并改此后缀 |

- **全站假后缀只允许一种**（1A）：现行定为 **`.png`**（2026-10-30）。若以后要改扩展名，须同步迁存量 + 改统一包与文档。  
- 识别密文**不能只靠后缀**：文件头须有**我方魔数**（真 PNG 图片打不开当模型；我们的密文也不是合法 PNG，系统不应当正常图解码）。  
- 公网目标态：`docs/m/` **以 `.png` 密文为主**；残留 `.glb` 明文在迁移期仍可播，发版检查可逐步收紧「禁止新明文进 docs/m」。  
- 注意：课表/缩略图若也用 `.png`，路径与「模型密文」不要混目录约定——**模型密文只放 `docs/m/`**，避免和 `docs/img` 真图混淆。

### 6.2 统一程序包（硬性）

- 浏览器播放、Cloudflare/本地工具、批处理加密：**只调用同一套加解密包**（一改全改）。  
- 禁止各页/各工具复制粘贴第二套算法或私自改容器格式。  
- 建议形态：共享 ESM（前端）+ 同算法 Node 入口（脚本/导出）；格式版本号写在文件头，便于以后轮换。

### 6.3 工具默认流程

1. **打开 / 导入**：若密文 → 解密到内存再处理；若 `.glb` 明文 → 直接处理。  
2. **编辑 / 预览**：内存中按 GLB 逻辑走（与现网一致）。  
3. **导出到 `docs/m`（或对外目录）**：**默认加密 + 假后缀**。  
4. 内部工作区可暂存明文 `.glb`；**不要把「未加密 glb」当长期公网规范**。

### 6.4 密钥（2A）

- **第一版：固定钥**（游客也能播课，无需登录才下钥）。  
- 预期：钥最终会出现在客户端；价值在伪装容器 + 非标准后缀 + 无公网裸 glb。  
- 以后若要加「登录后才下钥」，单开迭代，不推翻本容器格式。

### 6.5 性能（与伪装同等重要）

- 优先 **标准快速对称加密（如 AES）+ 流式/分块解密**，少拷贝，解密结果直接进现有 `GLTFLoader`。  
- 「非常规」放在：**容器、魔数、假后缀、分发流程**，不放在自研慢算法上。  
- 验收建议：同网同模型，密文首开相对明文增幅应**体感可忽略**（实施时用数字门槛卡住，例如弱机再测一刀）。

### 6.6 与防盗链

- 加密与 WAF `Block model hotlink` **叠用**；假后缀文件仍放在 `/docs/m/` 下即可被现规则覆盖。  
- 加密**不替代**防盗链，也**不替代**会员门禁。

### 6.7 实施顺序（提醒）

原则变更时：**先改本节 + `site-security.mdc`，再改代码。** 分步细则见 **§7**。

## 7. 模型加密实施拆步（计划 · 2026-10-30）

> 目标态：公网 `docs/m` 以 `.png` 密文为主；`.glb` 明文全程可读兼容；**一个加解密包**打通播放与工具。  
> 每步有验收；**上一步通过再开下一步**。未勾选「开工」前可只当路线图。

### 第 0 步 — 规格钉死（文档/契约，几乎无业务代码）

- 定：魔数、版本字节、AES 模式（建议 AES-GCM 或 AES-CTR+完整性）、固定钥存放约定（构建期注入，勿散落多处明文注释）。  
- 定：统一包路径与 API 草图，例如 `encrypt(glbBuffer)→密文` / `decrypt(密文)→glbBuffer` / `isOurContainer(buf)` / `loadModelUrl(url)→ArrayBuffer`（自动认 `.glb` 或密文）。  
- 验收：书面规格进本账本附录或包内 README；与业务确认无歧义。

### 第 1 步 — 统一包最小实现（Node + 浏览器同一算法）

- 实现加解密与魔数检测；Node 脚本可把样例 `.glb` ↔ `.png` 互转。  
- 单元自测：随机小 buffer 往返一致；真 PNG 文件 `isOurContainer` 为假。  
- 验收：命令行往返；**不改** Solid 业务加载。

### 第 2 步 — Solid 双轨加载冒烟（测站）

- Solid（及必要的 `SolidGlbPersistCache` 等）经统一包取 ArrayBuffer，再交现有 `GLTFLoader`。  
- 测站放 **1 个密文 `.png` + 保留原 `.glb`**；课表可临时指密文。  
- 验收：明文课仍开；密文课能开；弱机/App 体感加载可接受；错误密文有明确失败提示。

### 第 3 步 — 生产工具默认流程

- `Solid_Portrait_Create`、GLB 管理器等：**读** 明文 glb 或密文均可；**导出到 docs/m 默认加密为 `.png`**。  
- 验收：导出物能在 Solid 打开；工具内预览不二次走错格式。

### 第 4 步 — 存量迁移（可分批）

- 批处理：`docs/m/*.glb` → 密文 `.png`；JSON/路径引用分批改写（生成端权威，消费端少手改）。  
- 迁移期双轨并存；发版检查可警告「model 下仍有 glb」。  
- 验收：抽样课表全开；防盗链对 `.png` 模型仍 403 外站 Referer。

### 第 5 步 — 收紧与正式

**已定口径（2026-10-30）**

| 码 | 决定 |
|----|------|
| **3A** | **测站发版冒烟通过后**再删 `docs/m` 明文 `.glb`；在此之前明文暂留双轨。 |
| **4A** | 生产工具**默认只出密文 `.png`**；发版预检若发现 `docs/m` 仍有 `.glb` → **警告不阻断**。 |
| **5A** | **先发测站冒烟**（含密文课抽检），再谈删明文 / 发正式。 |

- 对外文案不出现「无法破解」。  
- 验收：测站密文课可开；防盗链对 `.png` 模型仍 403 外站 Referer；正式 App + 浏览器开课后再标「现行」。

### 拆步原则

- **加载优先卡性能**：任一步导致明显变慢 → 先优化流式/少拷贝，再扩大范围。  
- **伪装不牺牲真图**：真 PNG 缩略图不进 `docs/m` 当模型密文用。  
- **禁止**第二套加解密实现。

## 8. 密文容器技术规格（v1）

| 项 | 值 |
|----|-----|
| 实现路径 | **仅** `docs/js/model-crypto/ModelCrypto.js` |
| CLI | `node docs/js/model-crypto/cli.mjs` |
| 算法 | AES-256-GCM（Web Crypto / Node `crypto.subtle`） |
| 钥 | 固定材料字符串 → SHA-256 → AES 钥（2A；客户端可见属预期） |
| 魔数 | 4 字节 ASCII **`PTGL`**（`50 54 47 4C`），**不是** PNG 签名 |
| 版本 | 1（头第 5 字节） |
| 头布局 | `magic(4) + ver(1) + flags(1) + reserved(2) + iv(12)` = 20 字节，其后密文+GCM tag |
| AAD | `ver + flags`（防头篡改） |
| 假后缀 | **`.png`** |
| 明文后缀 | **`.glb`** |

API 要点：`isOurContainer` / `encryptGlb` / `decryptToGlb` / `toGlbArrayBuffer` / `loadModelUrl`。

## 9. 课表列表卡字段（锁课削薄时仍须保留）

锁课/列表轻量裁剪**只去掉**可复现载荷（`items`、标注、相机灯光全文等），**必须保留**：

| 字段 | 用途 |
|------|------|
| `uid`（及如有则 `id`） | 列表标题编号「71 · 婴儿头」、收藏/进课唯一键 |
| `meta.material` / `gender` / `age` / `region` | 肖像沙盒筛选芯片（石膏/儿童/男/西方等） |
| `meta.line` / `slot` / `modelId` 等 | headform 课线；勿只留 category/detail |

实现口径：服务端 `functions/membership/policy.js` 的 `toCatalogListCard` / `stripScenePayload`；本地无 Functions 回退见 `docs/js/membership/MembershipAccess.js`（须与线上同口径）。**禁止**先做「只留 category/detail」的 strip 再拼列表卡——会把编号与「儿童」筛空。

加课脚本克隆模板时**必须重写 `uid` 为本课号**，禁止继承模板 uid（曾导致多课同显「71 ·」）。重建索引 `rebuild-portrait-index.js` 遇 uid 碰撞应失败退出。
