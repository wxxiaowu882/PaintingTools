# 学员开通（运营台 · C12 首版）

产品口径见 `docs/站点规划_访谈与路线图.md` §4.5。本文只记**运营写权**怎么落，避免和第二套逻辑分叉。

## 学员是什么

同一账号上两本账：

| 账 | 内容 | 到期 |
|----|------|------|
| 站内 Pro | `member_3y`，开通日起 **1095 天** | 会到期；每次购课/开通 **覆盖重算** |
| 课包 | `coursePacks[]` | **永久**；Pro 过期不停课 |

不另造「学员」登录身份。

## 运营主路径

1. 用户微信联系，报 **手机号 + 课包意向**。  
2. 运营台「会员账号」→ **开通学员**：填手机号、选课包（可选备注；游客可不填密码，系统生成）。  
3. 系统：  
   - 无账号 → 开户并发初始密码（须私下告知用户）；  
   - 有账号 → 不改原密码；  
   - **一律**把 Pro 写成「今天起三年」；  
   - 课包 ID 写入清单（已有则不重复加，但仍重算 Pro）。  
4. 已付时长 Pro 的退费/抵扣由运营线下处理；工程只保证写权口径。  
5. 特殊多延期几天：仍用现有「延期高级」，不要另开通道。

## 撤销

- **取消课包**：只从 `coursePacks` 去掉该项；**不**自动取消 Pro。  
- **取消高级**：现有「取消高级」；**不**自动清课包（课永久，除非再点取消课包）。

## API

- `POST /api/membership/admin/accounts`  
  - `{ action: 'grant_course_student', phone, packId, packTitle?, password?, displayName?, wechatNote? }`  
  - `{ action: 'revoke_course_pack', phone, packId }`  
- 课包目录（静态）：`/docs/course/packs.json`

## 播放门禁（已接首刀）

- `GET /api/course/play-url` 对 **R2 正课短时链**：须登录且账号 `coursePacks` 含对应 `packId`（可用 `?courseId=` / `?packId=`；默认 `watercolor-portrait-demo`）。  
- **demo\*** 本地样片路径、未配 R2 时的测站回退：**不验课包**（方便搭 UI）。  
- Pro 是否在期**不**代替课包；Pro 过期只要课包还在仍可拿链。
