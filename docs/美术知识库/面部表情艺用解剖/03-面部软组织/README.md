## 精录要点（摘自 @@要点）

### 脂肪室

- 软组织先记层序：皮→浅脂→SMAS→表情肌→深脂→骨；韧带把脂肪室隔开 〔书页 128〕
- 浅层脂肪不是一整块——额、眶、颊、颌、颏各有分室，后面表情鼓起常挂在这些室上 〔书页 129〕
- 深脂藏在肌下/缝里，和浅脂室不是同一层——鼓起位置别混层解释 〔书页 130〕
- 深脂室记 ROOF/SOOF 与颊脂延伸——眼袋、泪沟、中面鼓起常挂这些室 〔书页 131〕

### 结缔组织

- 〔书页 132〕
  - 先分清真性（钉到骨膜）与假性（浅筋膜系统内）
  - 沟纹（鼻唇沟、下颌唇沟）往往是韧带锚点加脂肪下垂的共同结果
  - 眼轮匝肌支持韧带与 ot：理解眶下缘到眼轮匝肌的锚定
- 〔书页 133〕
  - 图例分两套：编号韧带 vs 字母隔膜或褶
  - 绿线多=隔膜分层；蓝点或蓝线多=韧带锚定
  - 看见 nf / lf，先回头找对应深层锚点（4/b、5 等）
