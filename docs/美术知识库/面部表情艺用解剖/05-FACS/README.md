## 精录要点（摘自 @@要点）

### FACS 与运动单元

- 〔书页 204〕
  - 先记 AU 编号与「脸上哪里动」
  - 每个 AU 都要和中立位对照看皱纹与开合变化
  - AU4 与 AU1/AU2 方向相反：一个压眉，一个抬眉
- 〔书页 205〕
  - 每个 AU 对照中立位看皱纹与开合
  - AU9–12 串起鼻翼→上唇→鼻唇→口角这条中面链
- 口角相关 AU：13 上提、14 起窝、15 下垂；17 颏顶、18 噘唇 〔书页 206〕
- 口/颈后段：露舌、横拉、颈带、以及口轮匝肌的三种收拢 〔书页 207〕
- 开合与颌位：25/26/27 管开口幅度，28 抿入，29/30 前推与侧摆 〔书页 208〕
- 咬合与颊内动作：咬紧/咬唇、吹鼓吸颊、舌顶颊 〔书页 209〕
- 鼻孔开合与睑位：38/39 管鼻翼，40–42 管睑下落与闭合 〔书页 210〕
- 眯/眨/使眼色：43 别和压眉混，44 是瞬时闭开，45 是单侧挤眼 〔书页 211〕

### 眼睛动作编码

- 眼球方向码：左右上下 + 对眼，靠六条眼外肌组合 〔书页 212〕
