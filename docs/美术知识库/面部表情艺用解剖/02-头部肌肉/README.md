## 精录要点（摘自 @@要点）

### 头部肌肉总览与多视角

- 〔书页 36〕
  - 先建立「整脸肌地图」，后面局部肌卡才有坐标
  - 正视适合对左右对称与口眼鼻中轴关系
- 〔书页 37〕
  - 3/4 视角适合同时看清额、颧、口角与颈侧的空间转折
  - 先认「腱膜—额肌—眼轮—口周」这条自上而下的主链
- 〔书页 38〕
  - 侧面最能看清颞肌扇面与咬肌厚度
  - 帽状腱膜是额腹与枕腹的桥
  - 口角斜向后上的肌束多为颧肌系统
- 3/4 后视适合看「腱膜—枕腹—颈后」过渡，补正面看不到的后份 〔书页 39〕
- 先认枕腹左右成对，再连向前经腱膜到额肌（前后腹一套枕额肌） 〔书页 40〕
- 顶视把枕额肌「前—腱膜—后」连成一条，颞肌在两侧像扇形垫 〔书页 41〕
- 正视先把 G→额→眼周→鼻→颧这条中轴读通 〔书页 42〕
- 口角 M 是多肌汇入点；表情读写常从这里倒推拉力方向 〔书页 43〕
- 〔书页 44〕
  - 侧视主课：「颞肌扇面 + 咬肌厚垫 + 颧肌斜向口角」
  - 枕肌(5) 证明枕额肌前后腹经腱膜相连
- 〔书页 45〕
  - 同一编号在不同视角页的图例可能按「本页可见肌」重排——以该页底栏为准
  - 后斜视重点看颧大肌、颊肌、笑肌如何绕向口角
- 后视最少要素：腱膜 G + 左右枕腹；侧绿块提示颞区延续 〔书页 46〕
- 顶视是检查枕额肌连续性的最快视角 〔书页 47〕
- 表情肌「扯皮肤」，咀嚼肌「扯骨头」——后面读 AU 先分清你在看哪一类 〔书页 48〕
- 〔书页 49〕
  - 记口诀：纤维方向 ⊥ 皱纹方向
  - 面肌讲的是「皮肤形变组合」，不是练出一块块肌肉轮廓

### 头部区域

- 〔书页 50〕
  - 先记「区名 + 大致位置」，再往里塞肌肉与脂肪室
  - 中轴五官带（眉间/眶/鼻/眶下）是读表情变化的优先观察带
  - 侧面「颧—颊—腮腺咬肌」决定脸的侧体积与咬合感
  - 仰视图专门补全颏下、下颌下与下颌后窝，正面容易漏看
- 〔书页 51〕
  - 大区管「落在哪一块」，细部管「画哪一条沟/缘」
  - 眼周优先分清：睑缘、泪沟、眶下沟（层次不同，影也不同）
  - 口周抓住：口角轴、人中、鼻唇沟、唇红缘四条线
  - 鼻部按 眉间到鼻根到鼻梁到鼻尖到鼻翼 串成一条中轴线

### 额叶与顶叶区域肌肉

- 〔书页 52〕
  - 记住公式：枕腹 + 腱膜 + 额腹 = 可前后拉动的头皮系统
  - 画抬头纹时，动力在额腹，但整条系统从后枕经颅顶传到眉
  - 额腹止点扎进眉与鼻根皮肤，并与眉间肌群交织，故抬眉会牵动眉心附近
  - 字母对照：O 枕腹，F 额腹，G 帽状腱膜，nl 上项线，M 乳突
- 〔书页 53〕
  - 先分「内眉 / 外眉 / 整眉」三档，再记 AU 编号
  - AU1 与 AU2 可单独出现，也可叠加成 AU1+2
  - 横纹长短与位置，直接反映额肌哪一段在用力

### 眉间区域肌肉

- 〔书页 54〕
  - AU4 = 眉毛降低（皱眉、专注、不满常见）
  - 三肌协同：既下压又向中聚拢眉头
  - 画眉心竖纹/鼻梁横纹时，要想是哪一条肌在主导
- 〔书页 55〕
  - AU4 = 眉毛降低/聚拢，常见于皱眉、专注、不满
  - 读形时先找眉间纵纹与鼻梁横纹是否同时出现

### 面部肌肉（睑提等）

- 〔书页 56〕
  - AU5 = 上睑提高（常出现在惊讶、恐惧等）
  - 提睑主力是上睑提肌与上睑板肌；眼轮匝肌主要负责闭睑
  - 读剖面时先认 L/S/O，再看①②睑缘与睑板位置
- 〔书页 57〕
  - AU5 = 上睑提高，露出更多虹膜上方巩膜
  - L 提睑，O（眼轮匝肌）主要负责闭睑，方向相反
  - 惊讶/恐惧常见 AU5 参与
- 先分清眶部（大力挤眼）与睑部（轻闭/收紧睑裂）——后面 AU6 vs AU7 就挂在这两部 〔书页 58〕
- 〔书页 59〕
  - AU6 = 真笑眼周证据之一：颊上提 + 外眦纹，不只是嘴角动
  - 与 AU7 比：AU6 更「眶部大力环缩」，牵动颊脂

### 眶区肌肉与眼外肌

- AU7 主课睑裂「收紧变直」，常与 AU6 叠用；读图时左右分看 AU7 增量 〔书页 60〕
- 〔书页 61〕
  - 这是「用力挤眼 + 皱鼻」组合课：分清环眶拉力与鼻侧提肌
  - E = 强度顶格，不是另一个独立肌
- 先认六条动眼球肌 + 一条提上睑；滑车是上斜肌腱的转向点 〔书页 62〕
- 直肌共享总腱环；斜肌另起、上斜必经滑车——这是后面 AU 眼动页的底图 〔书页 63〕
- 〔书页 64〕
  - 记口诀：向左看 = 左眼 LR + 右眼 MR
  - 左右指标的是模特解剖左右，不是读者左右
- 写生时先看虹膜中心相对内外眦的偏移，再补眼白三角形 〔书页 65〕
- 上视 = SR + IO 收缩；别漏掉拮抗肌放松 〔书页 66〕
- 上视不只「虹膜上移」：下睑区会因眶脂前推变鼓，上睑同步抬 〔书页 67〕
- 下视 = IR + SO；与 AU63 成对记忆 〔书页 68〕
- 下视时上睑常跟随下降；写生用参考线核对瞳孔相对睑裂的位置 〔书页 69〕
- 单 AU64 是下视；加上 AU2 才把眉外角与眶上缘「拉开」看得更清楚 〔书页 70〕
- 闭眼不是只「放下眼皮」：睑部主动收 + 提肌放松，二者缺一不可 〔书页 71〕
- 斜下视是双眼不同肌配对；按模特解剖左右记，勿按读者左右反了 〔书页 72〕
- 右上视与右下视成对：换的是直肌/斜肌组合，不是随便「斜看」 〔书页 73〕

### 鼻区与面中部肌肉

- 〔书页 74〕
  - 鼻周肌决定皱鼻、扩鼻孔、压鼻翼等细动作
  - L（提上唇鼻翼肌）常参与 AU9 类「皱鼻」表象
  - 先认字母，再记每条肌贴在鼻的哪一侧
- 先把 Nt / Na / Ds 钉在梨状孔周缘，再谈软骨上的扩张与压迫 〔书页 75〕
- AU9 主肌就是这条：看鼻侧横纹 + 鼻唇沟顶上移 〔书页 76〕
- 皱鼻不是只皱鼻梁：眶下三角上移与鼻唇沟加深是写生高频证据 〔书页 77〕
- AU38 = 扩鼻孔三联；微笑时别忘降鼻中隔可把鼻尖「压矮变鼓」 〔书页 78〕
- 扩鼻孔看鼻翼外翻与开口变圆；叠 AU9 时鼻侧横纹一起出现 〔书页 79〕
- AU39 与 AU38 相反：横部把两侧往鼻梁「收」，开口变窄 〔书页 80〕
- 收鼻孔时鼻翼贴面、开口变竖缝——与扩鼻孔的「外翻变圆」成对记 〔书页 81〕

### 口区肌肉

- 口区先认「环肌 O + 放射状提降肌」：所有 AU 口部动作都挂在这张地图上 〔书页 82〕
- 把前页肌腹地图钉回骨面：上提链在上颌/颧，下降链在下颌斜线与颏 〔书页 83〕
- 口轮匝肌是口裂括约肌；颊肌在更深的颊壁；颏肌专管颏皮肤与下唇底 〔书页 84〕
- 颊肌止于口轮匝肌——吹气、吮吸时颊壁张力直接传到口角 〔书页 85〕
- 〔书页 86〕
  - 字母对照：O 口轮匝肌，B 颊肌，M 口角轴，1 上颌骨，2 下颌骨
  - 口轮匝肌是「环形底座」，其它口周肌多止到它或口角轴
  - 画唇形变化时，先想环肌收紧 vs 口角被外拉
- AU18 看两点：唇前突 + 口角轴(M) 向中靠拢 〔书页 87〕
- AU23 是「缩紧变窄」而非 AU18 的「前突噘起」 〔书页 88〕
- 记「窄而不短」：唇红变少、口周鼓起，不是整段嘴变短 〔书页 89〕
- 图标签以 AU22（非 AU23）为准：漏斗状聚唇 + 张口 + 皱鼻 〔书页 90〕
- AU22 是「漏斗/吸取」外层环肌；叠 AU25 才露齿，叠 AU9 才皱鼻 〔书页 91〕
- 22+23 = 既前突漏斗又缩紧——比单纯 AU18 更「收成 O 形」 〔书页 92〕
- AU18 把唇聚前，AU25 把唇分开——合起来是「噘着张开」 〔书页 93〕
- 酒窝 AU 的解剖底是深层颊肌把口角往深里收，不是浅层笑肌斜拉 〔书页 94〕
- 酒窝看嘴角「内收起褶」，别和 AU12 斜上拉的真笑混 〔书页 95〕
- 吹气看「颊体积外鼓 + 唇闭紧」，不是单纯嘴角动作 〔书页 96〕
- AU33 的体积主要来自气压撑开颊壁，颊肌被拉长而不是「鼓肌块」 〔书页 97〕
- 颏肌管的是「颏皮起皱 + 下唇上推」，写生盯颏唇沟与颏尖颗粒 〔书页 98〕
- AU17 = 颏上推 + 下唇上拱；桔皮颏是强度过高的体表证据 〔书页 99〕
- 降口角 = 斜线起 → 口角轴止；写生盯嘴角下撇与口角下凹陷 〔书页 100〕
- 15 下撇嘴角 + 17 上推颏 = 常见「委屈/难过」口颏组合 〔书页 101〕
- 真笑主轴：颧大肌斜向口角轴；脂肪垫会被带着上移 〔书页 102〕
- AU12 不只嘴角斜上：颧脂上移、鼻唇沟加深、眼下可连带变鼓 〔书页 103〕
- 颧小肌比颧大肌更靠内、更贴鼻唇沟中上段——后面 AU11 就挂在这里 〔书页 104〕
- AU11 是「鼻唇沟中上加深 + 上唇中外段微提」，别和 AU12 的斜向大笑混 〔书页 105〕
- 降下唇 = 下唇中份垂直下拉；与降口角肌相邻但更靠中 〔书页 106〕
- 露下牙常是 16+25；只下拉不下开唇则单独 AU16 〔书页 107〕
- 提口角肌深在口角轴，主稳定而非主表情——后面 AU13 挂这里 〔书页 108〕
- AU13=嘴角更尖、更垂直上提；唇红不跟着抬——别和 AU12 斜向大笑混 〔书页 109〕
- 提上唇肌居中宽扁，夹在鼻翼提肌与颧小肌之间——后面 AU10 挂这里 〔书页 110〕
- AU10=上唇中份上提+鼻唇沟加深；有兔纹多半是 AU9 而非纯 AU10 〔书页 111〕
- 笑肌薄而弱，主横向微拉嘴角；强后外拉多半靠颈阔肌口角部 〔书页 112〕
- AU20=嘴唇水平向后拉开；颏与鼻唇沟下段常一起被横向扯平 〔书页 113〕

### 颈部肌肉

- 颈阔肌三部到下颌、下唇与口角轴——后面 AU20/强下拉常挂这里 〔书页 114〕
- 颈阔肌发力时颈带竖起 + 嘴角后外下——AU20 的「力」常在这里看，不只看笑肌 〔书页 115〕

### 咀嚼肌

- 合嘴三对（咬/颞/翼内），张嘴主看翼外——咀嚼章先立这张总图 〔书页 116〕
- 咀嚼肌起止先记色块：绿颞、红咬、紫翼内、蓝翼外 〔书页 117〕
- 〔书页 118〕
  - 扇形肌腹在颞部，肌腱走颧弓下到冠突
  - 咬合上提的主力之一；后部纤维可帮助下颌后缩
  - 画太阳穴起伏时，要想颞肌填充颞窝
- 颞肌放松=纤维拉长口开；收缩=上提下颌合嘴 〔书页 119〕
- 咬肌浅头到下颌角、深头到支上半——后面 AU31 咬紧看这块鼓起 〔书页 120〕
- AU31=咬紧鼓起下颌后份；一松就容易落到 AU26 张颌 〔书页 121〕
- 翼内肌在下颌角内侧，与咬肌成悬带一起抬颌 〔书页 122〕
- 翼内既帮合嘴，也参与对侧/同侧搭配的侧摆 〔书页 123〕
- 翼外双头：上头稳盘，下头主开颌前伸 〔书页 124〕
- 张口看翼外：髁突+关节盘一起前下走，不是只会“下巴掉下来” 〔书页 125〕
