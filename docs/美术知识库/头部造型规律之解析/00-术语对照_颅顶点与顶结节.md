# 术语对照：颅顶点 / 顶结节

电子书旁注句式：`「颅顶结节」（主流学术称为颅顶点）`；`「颅侧结节」（主流学术称为顶结节）`。

## 头部造型规律场景（headform）侧方点口径（2026-09-19）

- **主名（② / 顶视 4 等）**：**脑颅侧方最宽点**（不计耳朵）。
- **说明（短）**：高度约耳到头顶一半。头前后较长时多在耳廓后上方，常即顶结节；头前后较短或后脑偏平时可能移到耳尖正上方。
- **顶结节**：放在说明里作对照，不作此外轮廓侧方点的主标签。
- **骨点课**：仍可单独钉「顶结节」（摸诊丘顶）。

## 学术定位（对照用）

- **颅顶点**：标准姿势下颅盖正中最高点，多位于矢状缝一带。
- **顶结节**：左右顶骨外面近中央的最凸圆隆；常近头最大宽，典型约在耳尖上且略偏后。
