# 正前光下「交界2」为何有时不明显

> 课务口径补充：对应沙盒 **205【交界线规律】正前光 · 头侧交界** 的【交界2 · 颞—眉—眼】（⑦颞线→⑧眉峰→⑨眶外角）。  
> 与书中「光照边际停在大面外缘转角」一致；本页补**群体形态学依据**与**教学表述边界**。

## 课上短版（四套 205 共用）

```
【交界2 · 颞—眉—眼】
⑦→⑧.颞线（⑧是眉峰）
⑨.眶外角
正前光下，这条交界依赖颞线、眉峰、眶外角一带的前后转折。头型偏扁、东亚常见面型、女性、低龄者，这片往往更平，交界2常不明显甚至几乎糊掉——不是没有这些点，而是亮暗边不够锋利。点位框架仍用⑦→⑧→⑨，再按个体强弱调整。
```

格式约定：标题后须换行；**先列⑦⑧⑨点位**，再写强弱说明；⑨ 与说明之间**不空行**。

## 造形机制（为何正前光特别挑「坎」）

- 交界清楚，靠表面**转得够不够**：转角急 → 正前光易画出锋利明暗边；表面平 → 只剩缓坡灰调。
- 交界2踩在颞线、眉峰/眶上缘、眶外角。这片若前突弱、额更竖、面中更扁，正前光就很难「打」出交界2。
- **解剖点仍在**；弱的是**亮暗边**。勿写成「没有交界2」。

## 与经验对应的形态学依据（群体倾向）

下列均为**群体平均 / 常见倾向**，不是人人如此。

### 1. 头型偏扁、面中起伏弱

- 东亚人群在多项颅面研究中常表现为上/中脸相对更扁、眉间（glabella）前突较弱、额骨更圆等倾向（如 Hanihara 2000 对面扁的跨人群比较；当代东亚颅面综述亦常归纳类似特征）。
- 面形三维对照（如东亚与欧裔平均脸）亦常见：欧裔对照样本在眉间—鼻根一带更前突；东亚平均脸颧颊相对显、上中脸前后起伏不同。
- **课上含义**：额—眉—眶外这道脊不够「立」时，正前光下交界2易弱。

### 2. 东亚常见面型

- 同上，是**平均倾向**，不是「亚洲人一定看不见交界2」。
- 表述宜用「东亚常见面型上交界2常较弱」。

### 3. 女性

- 眶上缘 / 眉弓 / 眉间：男性通常更粗、更前突；女性额面更光滑、更竖（法医人类学与三维面形性二型研究常见结论）。
- 跨人群三维研究亦报告女性更平的前额等共同倾向（如土耳其与日本样本的性二型比较，*Scientific Reports*）。
- **课上含义**：性别这一条学术支持较稳；若再叠面扁，交界2可更弱。

### 4. 低龄

- 眉脊明显性差，很大程度在青春期前后才拉开；儿童与少年额眶区更圆，性二型未充分展开。
- **课上含义**：低龄者交界2弱，多属发育未完成，不是光线设错。

## 表述边界（写解析时务必守住）

1. 用「常常 / 更容易 / 群体上」，不用「必定没有」。
2. 区分：**点位框架⑦⑧⑨仍成立** vs **正前光下明暗交界弱**。
3. 「亚洲人」不是唯一原因：扁头型、女性、少年可单独成立，也可叠加。
4. 本关条件是**正前光**；换侧光/顶光仍可能把弱交界「救」出来。

## 和书内口径的衔接

- 《头部造型规律之解析》贰章：人体无刀切分面线；分面由大面外缘较明显的转角串成；用控制光源后的「光照边际」凸显交界（见 `02-大面交界` 要点）。
- 正侧相关骨点含眉峰、眶外角等（书内正侧五点表述）；交界2是正前光头侧课上的**额颞支线**读法，强弱随个体起伏变。
