### 一、「顶面与纵面」交界处的造形规律

- 顶纵交界＝额结节、颅侧结节、枕后突隆连线；与顶视「外围轮廓」及同方位「光照边际」重合。 〔书页 100/101〕
- 枕后突隆＝颅后最突转折；不同于医用「枕外粗隆」（更靠下的肌附着粗糙面）。 〔书页 100/101〕
- 〔书页 102/103〕
  - ■ 正面观点：光源在正上方时，「光照边际」是「顶面与纵面」转换的位置。从光影分布可以看出：头颅前窄后宽，与俯视图的颅顶五边形相符，参考图 1。模特儿的光源位置与头骨一致时反应出相同的「顶面与纵面」交界处。
  - ■ 侧面观点：「顶面与纵面」交界处以「枕后突隆」位置最低、「颅侧结节」略高于「额结节」。
  - ■ 背面观点：光源前移时，明暗分出了前顶、后顶与纵面：亮调是前顶、以左右「颅侧结节」连线为界；灰调是后顶、以「枕后突隆」与左右「颅侧结节」连线为界；连线之下的暗调是纵面。因此，五边形之上的顶面亦可分成顶前的梯形、顶后的三角形，三角形向深度空间延伸成斜面，手掌在「巅顶结节」之后即可感受到。
- 顶纵三点：额结节／颅侧结节／枕后突隆——定高、定宽、定后界。 〔书页 102/103〕

### 二、「底面与纵面」交界处的造形规律

- 〔书页 106/107〕
  - ■ 正面脸部的下巴最窄、额部次之、颧骨弓处最宽，而「颅侧结节」更宽于颧骨弓；因此从底面仰视时，下颚底之外两腮饱满，「颧骨弓」「颅侧结节」超出下颚底甚多。仰头时颧骨弓突出于下颚底，两颊向外扩张；低头时下颚底隐藏，两颊削瘦。（图 3、4）
  - ■ 从头骨底面观之，可清楚看到「颧骨弓」起点、「颅侧结节」转角处。「颧骨弓」后段内收因此耳壳内藏、正面观点看不见耳壳基部。从模特儿底面可以看到耳壳与头颅前面约成 120° 切角。
  - ■ 模特儿极力上仰时，下颚骨底缘清晰地呈现为倒「V」形。下颚底面为双「V」合成的矢状，后方的倒「V」是下颚底与颈部交会。低头时下颚底隐藏、颊部削瘦，在描绘时应将左右颚角拉提为画面的前突处；照片中的耳壳基底并未呈现，为前方的颧骨弓所遮蔽。
- 底纵交界落在下颚骨底缘与下颚枝后缘；矢状双「V」定下脸轮廓基础。 〔书页 106/107〕

### 三、「正面与侧面」交界处的造形规律

- 正侧交界线形似侧躺「N」；用「颧突隆」「眶外角」内外缘两组光照边际对照定位。 〔书页 110/111〕
- 笑→浅 s；大笑→s 加深；大乐→侧躺 w（眶外角、口外为转折）。 〔书页 114/115〕
- 鼓嘴撑开鼻唇沟；嘟嘴按骨点重分面；憋气使正侧交界趋直。 〔书页 116/117〕
- 名作或把正侧交界外移以放大脸部主体，或贴合自然人交界以强化凝聚与朝向。 〔书页 120/121〕
- 正侧五点：额结节外侧—眉峰—眶外角—颧突隆—颏结节。 〔书页 120/121〕

### 四、「侧面与背面」交界处的造形规律

- 侧背交界依斜方肌侧缘／枕下侧角上延；耳垂水平以上与头骨同，颈肩顺斜方肌外缘。 〔书页 124/125〕
- 侧背三点：颅侧结节、斜方肌外缘、枕下侧角。 〔书页 126/127〕

### 五、不同脸型的多重角度观摩

- 同为「目」字脸：脂肪厚则交界柔、眼饱满；脂肪薄则交界直、睑眉沟清楚。 〔书页 132/133〕
- 脸型随年龄可「目→国→用」递变；光照边际在松弛肌肤上变模糊。 〔书页 136/137〕
- 贰章完成大框架（外围轮廓＋大面交界）；下一章改由纵向解剖结构织成网状。 〔书页 138/139〕
