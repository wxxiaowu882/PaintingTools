### 一、「正面视点」外围轮廓线对应在深度空间的规律

- 〔书页 34/35〕
  - 将「正面视点」外围轮廓线经过的位置，分颅顶、头侧、颈肩三部位进行，再以小结整合单元研究结果。
  - 每部位就「解剖形态」及「造型意义」分析：「解剖形态」是研究每一解剖点的个别位置、形态；「造型意义」是串连解剖点、分析它在整体造型中的意义；由单一点至整体、再延展成「变化规律」、立体探讨。
- 〔书页 34/35〕
  - 脑颅正面外围轮廓在颅顶呈大「V」。
  - 关键点：「颅顶结节」（最高）、「颅侧结节」（最宽，耳壳除外）。
- 〔书页 36/37〕
  - 外围轮廓线之前与后，形体皆内收；光源由前方投射时，「巅顶结节」「颅侧结节」也是明暗的分野。「巅顶结节」「颅侧结节」一个在耳前缘垂直上方、一个在耳后缘垂直上方，因此，正面视点头额最大范围的塑土应置放在此深度处。
  - 图 2 的正面照片中可以看到：「颅侧结节」也是顶面与纵面的分界。
  - 图 3 的头骨俯视照片中可以看到：「颅侧结节」位置在头骨的中后方，之后的脑颅宽而扁，这是长期卧躺所形成。
  - 图 2 的头骨侧面中可以看到：「巅顶结节」之前的顶面以和缓的斜度移行至「额结节」，再急转向脸部纵面。「巅顶结节」之后则是以较大的弧度后弯，再内收转成颈部。
- 〔书页 36/37〕
  - 头侧外围轮廓呈侧躺「W」。
  - 「颧骨弓隆起」=正面光照边际／脸部最大范围界限（宽于颧骨、窄于颅侧结节）。
  - 正面常看不到耳壳基部；下颌枝／下颌角多被咬肌遮蔽。
- 〔书页 38/39〕
  - 头侧「W」五转折：颏结节、颊转角、颧骨下端／颧骨弓隆起、颅侧结节、颅顶结节。
  - 正面形塑时，最大范围塑土应落在「W」位置。
  - 颊侧外围轮廓有「<」「|」两类变化。
- 〔书页 40/41〕
  - ■ （图 8）「<」之前端是「颧骨」下缘，从「光照边际」可以证明：「<」之尖端在侧面眼尾的后下方，「<」之下部是「咬肌」前缘；由明暗分布可以分辨出夹角内的形体变化可分为两部分：
  - 耳前条状的暗带：随着「颧骨弓」的内收，颊后范围随之内收，在耳前形成条状的暗带。
  - 「颧骨」后的块状：从图 6 侧后角度照片中可以证明，「<」夹角内的块状阴影与耳前条状是分离的；条状与块状间的亮调，是因为「颧骨」后的「颧骨弓」更向外隆起。
- 〔书页 40/41〕
  - 颊侧外围轮廓两类：「<」形结构棱角清楚；「|」形丰润柔顺、块面弱。
  - 「|」形常见于瓜子脸、古典美女与动漫美少女脸型。
- 〔书页 42/43〕
  - 颈肩外围轮廓分上中下：胸锁乳突肌 → 颈肩交会 →「肩棱线」至锁骨上缘。
  - 光照在正前时，光照边际即外围轮廓经过处；肩部前低后高、前亮面宽。
- 〔书页 44/45〕
  - 「光照边际」证明了外围轮廓线经过耳壳正下方的「胸锁乳突肌」侧部。
  - 「肩棱线」位置偏后，呈弯弧状，因此肩部形体后高前低。
  - 俯视角更可见「锁骨」呈「S」形，「锁骨」外端是外围轮廓线经过的位置。
  - 从俯视角更可见肩部后高前低，颈部插入躯干的情形。左右肩上的三角斜面是由「锁骨」「肩棱线」、颈下缘合成。
  - 侧前角度的「光照边际」几乎是顺着肩部的轮廓线。
  - 左右「锁骨」会合成弓形。
  - 平视角度可以看到「下颌骨」的厚度，证明了上颈部较窄。
  - 俯视角度可以看到「胸锁乳突肌」在前、「斜方肌」棱线在后。
- 正面视点外围轮廓关键点：颅顶结节、颅侧结节、颧骨弓隆起、颧突隆、颊转角、颏结节，以及颈肩的胸锁乳突肌、肩棱线、锁骨外端。 〔书页 44/45〕

### 二、「背面视点」外围轮廓线对应在深度空间的规律

- 〔书页 46/47〕
  - 背面与正面外围轮廓有重叠处，可接续印证。
  - 同位置光源的「光照边际」=背面外围轮廓在深度空间的位置。
  - 研究仍分脑颅／头侧／颈肩；头侧正背位置前后相离。
- 〔书页 48/49〕
  - 背面头侧外围轮廓呈长「Z」。
  - 关键：颅顶结节、颅侧结节、耳壳上隆起、下颌枝／下颌角、颌后沟。
- 〔书页 50/51〕
  - 「Z」中段长长的「/」是「颅侧结节」、耳壳、耳垂前、「下颌枝」的连线。
  - 「Z」的下端转入「下颌底」，止于「下颌枝」后缘。颈部最大范围对应在「胸锁乳突肌」的侧缘，在耳壳下方。
  - 「Z」的上端向前斜向「巅顶结节」。
  - 由于颈部较窄两颊较宽，光线投射出「下颌枝」侧面。
- 〔书页 50/51〕
  - 本页以图为主：背面视点外围轮廓线在颊侧的立体变化（B／C／D三组模特儿）。
  - 三列分别为：模特儿左侧外围轮廓线｜对应深度空间位置｜侧前视角的立体变化。
- 〔书页 52/53〕
  - 「背面」视点外围轮廓线经过处位置较后：由「颅侧结节」经耳壳上端，至颊侧。
  - 「正面」视点外围轮廓线经过处位置较前：由「颅侧结节」经「颧骨弓」隆起、「颧骨」下、「咬肌」隆起，再沿下颚走向下巴。
- 〔书页 52/53〕
  - 背面颈肩外围轮廓与正面经过处相同：上胸锁乳突肌侧缘 → 中颈肩交会 → 下「肩棱线」至锁骨外端。
  - 斜方肌上缘最高处形成「肩棱线」。
- 〔书页 54/55〕
  - 「光照边际」在体表上的位置也是前与后的分界处；从侧面角度观看（图 8 左二），每一点都是水平线上的最突点，因此从背面形塑最大范围时，塑土应置于「光照边际」线上。
  - 从侧面角度可以看到：「光照边际」将颈、肩范围划分成前宽后窄的；颈侧的「光照边际」大多是垂直在耳下，颈后是上窄下宽，颈前是上宽下窄，颈前低、颈后高、「肩棱线」更后，代表着肩部前低后高。「肩棱线」在全长二分之一处向前转至「锁骨」外端，这是呼应手臂主要是在向前活动的机制。
  - 从「背面视点」观看，颈肩的外围轮廓线上段是「胸锁乳突肌」a，下段是「斜方肌」b，上下段之间的颈肩过渡 h 是「斜方肌」之投影；下段外端骨点是「锁骨」外侧头 c，「光照边际」至此纵走至「三角肌」d。
  - 侧前视点更明显看到「锁骨」外侧头 c 的隆起、「肩棱线」的弯弧。
  - 侧前、侧后视点的近端「肩棱线」与远端的肩部轮廓线很对称，描绘时需多加参考。
- 背面外围轮廓关键点：颅顶结节、颅侧结节、耳壳上端／耳垂前缘、颊侧下颌枝、胸锁乳突肌、肩棱线、锁骨外端。 〔书页 54/55〕

### 三、「侧面视点」外围轮廓线对应在深度空间的规律

- 侧面轮廓线不在正中线上，而是侧面视点下头部大范围的界线；用同方位光源的「光照边际」可从任意角度研究它。 〔书页 56/57〕
- 〔书页 58/59〕
  - 将「侧面视点」外围轮廓线经过的位置，分脸部中央带的主线、脸部的支线、颅顶与颈肩三部分进行，每部分再以小结整合出阶段研究结果。
  - 三部位再就「解剖形态」「造型意义」及「变化规律」研究：「解剖形态」是研究每一关键解剖点的个别位置、形态；「造型意义」是串连解剖点、分析它在整体造型中的意义，由单一点至整体、再延展成「变化规律」及表情中的立体探讨。
- 〔书页 58/59〕
  - 侧面主线走中央带，并不全在中心线；另有支线。
  - 「额结节」内缘常是侧面外围轮廓经过处；统计位在黑眼珠内半垂直上方。
- 〔书页 60/61〕
  - 「唇颊沟」分口唇与下巴；主线经下唇→唇颊沟→颏突隆外缘而完成。
  - 颏突隆略成三角；上唇尖、下唇平可由光照边际证明。
- 〔书页 62/63〕
  - ■ 形体是永不变的，在任何光源变化中，皆应忠实地反应出造型。人体是左右对称的，外围轮廓线经过处与另侧的对称位置，形成中央带最前突的范围，其中以额部最宽、下巴次之、鼻梁最窄。形塑人物的侧面最大范围时，塑土应依照「光照边际」位置放置，它非常接近脸中心线，但几乎都不在中心线上。
  - ■ 脸部中央带有四凸三凹，形塑时应特别注意这些凹凸的范围及相对比例位置：四凸为「眉弓隆起」（女性为额部）、鼻梁、上唇「唇珠」「颏突隆」，三凹为「鼻根」「人中」「唇颏沟」。
- 〔书页 62/63〕
  - 中央带外围轮廓随脸型变化：圆脸／鹅蛋脸／「目」字脸。
  - 「目」字脸额之光照边际较直；东方人上唇唇珠常不如西方人明确。
- 〔书页 64/65〕
  - 侧面外围轮廓分主线（中央带）与支线（眼最高处＋颊正面）。
  - 「眉峰」=额正转侧；黑眼珠=眼部弧面最高。
- 〔书页 66/67〕
  - 支线概括眼最高处与颊正面；形塑侧面塑土应依光照边际放置。
  - 颊前两类：明确型／综合型。模特儿F为明确型范例。
- 〔书页 68/69〕
  - 综合型＝明确范围＋细碎起伏，多见中年后肌肤松弛。
  - 变化要点：眼袋扩大、鼻唇沟延长、颊前支线更低并连口角沟、颈前轮廓由折变弧。
- 〔书页 70/71〕
  - ■ （图 11）上面二张照片之「光照边际」是「侧面视点外围轮廓线经过处」之基本型，末为「正面与侧面交界线」；请注意前者颊部的「光照边际」止于「鼻唇沟」（法令纹），后者经过「口轮匝肌」外侧。两者之间的额部差距似一个长三角形，眉毛前段为三角形的底，「额结节」为三角尖。「眉峰」「眶外角」「颧突隆」、黑眼珠围成的菱形是「正侧交
  - ■ 「侧面视点外围轮廓线经过处」的支线中，最受表情影响的是脸颊、软组织这一段，因此以下表情分析以此为主。
- 〔书页 70/71〕
  - 微笑：侧面支线常呈「C」；正侧交界常呈「S」。
  - 大笑：隆起更强，口角更外上，沟纹更深。
- 〔书页 72/73〕
  - 嘟嘴：嘴前聚、颊前拉、鼻唇沟消失；正面左右侧面轮廓几乎合成菱形前突基底。
  - 惊讶：上近中心线较模糊，下因颧骨支撑较外较对比；嘴大开时眶外角至鼻唇沟光照边际变模糊。
- 〔书页 74/75〕
  - 名作可用来印证侧面视点外围轮廓／正侧交界的光照安排。
  - 鲁本斯常把光照边际放在侧面外围轮廓经过处，并兼顾纵横向起伏。
- 巅顶结节＝平视最高点；枕后突隆＝颅后最突，与医用「枕外粗隆」不同位，造型上不可省。 〔书页 76/77〕
- 〔书页 78/79〕
  - 侧面背后轮廓分三段：第七颈椎／肩胛内缘斜线／肩胛冈至下角。
  - 横切面略呈扁「w」；光照边际应作分面线使用。

### 四、「外围轮廓线」与各「面」的立体关系

- 〔书页 80/81〕
  - 外围轮廓线经过处=大面中介、确立各视点最大范围。
  - 面交界起伏更强，是立体感关键；下章专论。
  - 几何图形化3D模型用于对照并强化分面认识。
- 本页以真人／头骨照片对照几何分面模型，说明各视点外围轮廓与分面的立体关系（5–12）。 〔书页 82/83〕
- 〔书页 84/85〕
  - II＝多重角度＋三人脸型与几何模型同光源对照。
  - 正面：青年合规律；女子颧骨较平；中年改咬肌斜度。
  - 背面：青年合规律；细颈亮面大；中年「胸锁乳突肌」界限易糊。
- 本页为正面视点：几何模型与三名自然人对照图版，用以确认外围轮廓与分面关系。 〔书页 84/85〕
- 本页为侧面视点：几何模型与三名自然人对照图版，确认前面外围轮廓与分面立体关系。 〔书页 86/87〕
- 侧面视点经背面处：青年转折明确（第七颈椎、肩胛内上角／内缘）；中年常较模糊。 〔书页 88/89〕
- 以游戏角色与名作夸张像对照中央带规律：眉弓隆起、颏突隆三角、颧宽额次颏窄。 〔书页 90/91〕
- 〔书页 92/93〕
  - 32 正面、背面、侧面角度的「外围轮廓线经过处」计正面、背面、左侧面、右侧面各一条，共四条。它们共同经过头部最高点——「巅顶结节」，有如地球的经线，是以解剖点串连而成。
  - 33 左右侧的「正面与侧面的交界线」、左右侧的「侧面与背面的交界线」，与原有「外围轮廓线经过处」的四条经线，合计八条经线。而「顶面与侧面的交界线」、「底面与侧面的交界线」相当于二条纬线。
  - 34 「几何图形化 3D 模型」是陈廷豪建模，笔者造形指导、打光、拍照。
