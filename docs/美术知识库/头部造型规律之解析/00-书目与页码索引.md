# 网页电子书（请从这里读）

主入口是**尊重原版目录的网页书**：左侧目录，右侧**左文右图**（简体精校 + 竖版原书页）。

## 现在就可以打开

本地 HTTP 访问（勿用 `file://`）：

`自用工具文件_不部署/知识库原稿/头部造型规律之解析/ebook/index.html`

示例：

```bash
cd "自用工具文件_不部署/知识库原稿/头部造型规律之解析/ebook"
python -m http.server 8766
```

再打开 `http://127.0.0.1:8766/`（硬刷新 Ctrl+F5）。

## 怎么用

- **点目录**：切到该节（默认单页）；一级章点进「本章目录」页，树里不重复列「本章目录」。
- **左文右图**：滚轮缩放 / 拖动平移书页图；「调图」可调亮度对比度。
- **检索**：多词 AND；`G` 跳印刷页码；`B` 书签。
