## 精录要点（摘自 @@要点）

### 绪论

- 〔书页 14/15〕
  - 取用「块状造型」以加强姿态观念；并改良「简化的平面造型」，使面交界落在正确解剖点，做成「几何图形化3D模型」。
  - 肯定系统研究价值，但批评偏生理、造形探讨不足。
- 印刷精美，但外型与内部结构连结不足；实用造形说明少。 〔书页 16/17〕
- 〔书页 16/17〕
  - 重「学会观察」与「在整体结构中观察」；内部结构与表面形态对照充分。
  - 笔者因此购得「农夫」系列石膏像，并与乌东角面像对照。
- 外部形态分类有参考价值；缺解剖图与体块感，内外连动仍待补足。 〔书页 16/17〕
- 〔书页 18/19〕
  - 头部研究可通往写实、写神与自我表现。
  - 法兰切斯卡以头部透视作为透视学入门；比例标示如「等高线」。
  - 解剖须参佐艺术品，才有艺用价值。
- 〔书页 20/21〕
  - 本书得规律 → 下一本做「立体形塑应用」并做行动研究。
  - 要归纳「立体造形实践的程序」：学理 → 明暗与形体 → 实践；考试验学理，专题验应用。
  - 下书将接头部体表特征，比较皮萨烈夫斯基等解剖点研究，并落到ZBrush与泥塑。
- ■ 轮廓线的探索：从「正面」「背面」「侧面」视点探索外围轮廓线经过的位置。例如：光源与「正面」视点同位置的「光照边际」，即为正面视点外围轮廓线经过深度空间的位置、正面视点最大范围经过处；拍摄要点从最不受透视影响的全侧、全顶开始，再拍摄侧前、侧后角度，以呈现该正面视点外围轮廓线与整体造型之关系。 〔书页 22/23〕
- 〔书页 22/23〕
  - 「光照边际」落在突隆／转折解剖点上，才能看清大面交界与区内结构。
  - 关键词：形体与结构、光照边际、表面标志、解剖点（骨点）、解剖线、脸部正面／正面脸部。
  - 本书规律将落到ZBrush与泥塑胸像，并由下一本全面承接。
- 〔书页 24/25〕
  - 本页为绪论注释清单（1–21），含书目、网址与作者补充说明。
  - 注9–10对 Goldfinger 图式缺漏与「额结节／颅顶结节／颞侧结节」位置有作者补正。
  - 注21点出「以光认识形体」与罗丹塑造科学之渊源。
- 〔书页 26/27〕
  - 正面视点外围轮廓：脑颅呈大「V」；头侧呈侧躺「W」；颈肩落到胸锁乳突肌与「肩棱线」。
  - 关键点：颅顶结节、颅侧结节、颧骨弓隆起、颊转角、颏结节。
