## 和站内场景怎么配合（重要）

这本书讲的是用光影认识造形；落到我们站点时，**不要把「讲结构」和「讲表象」混在同一条线里硬塞**：

| 站内线 | 主课 | 本书怎么用 |
|--------|------|------------|
| 头骨 · 骨点 · 肌肉 | **结构本身**（骨点 / 肌肉）；可用打光把结构「打出来」 | 作解剖与命名对照 |
| 五官 | **五官结构与体表** | 第肆章等为权威展开；脑图附录见 [五官造型规律.md](../五官造型规律.md) |
| **头部造型规律**（headform） | **表象规律**：① **光位线**；② **视角线**；结构只短句解释「为什么」。两线分开；场景顺序按作品常见度（路线图 **§5.8.1**）；必备元素 **§5.8.2** | 光照边际、外围轮廓等作口径；斜光等作品高频角度可进课 |

共识原文与排期见 `docs/站点规划_访谈与路线图.md` **§5.8**。
