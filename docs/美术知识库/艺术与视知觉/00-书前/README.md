### 全书逻辑脉络

- 〔书页 书前·脉络〕
  - 本书主线：看见是有组织的理解，不是照相
  - 十章是同一套规则换材料演，不是互不相干的专题
  - 先读脉络立地图，再进正文，细读才不迷路
- 〔书页 书前·脉络〕
  - 新版要把几条总原则写醒，方便教、也好学
  - 绪论诊断：概念与知觉脱节，眼睛只剩测量
  - 格式塔：整体优先；本书工具磨利直觉，不取代直觉
- 〔书页 书前·脉络〕
  - 平衡章立住：看见里有力场，构图先是力的事
  - 重量、方向、上下左右都在改这本「视觉账」
  - 下一章：力附在什么形状上，形怎样被抓住
- 〔书页 书前·脉络〕
  - 形状章：看见等于主动整理与抓要点
  - 简单、分合、相似、骨架，都是组织规则
  - 下一章：形态是在媒介里发明可表达的等价物
- 〔书页 书前·脉络〕
  - 形态章：图像是媒介里的等价发明，不是投影复印
  - 像真、侧面、重叠、抽象档，都服务「说清楚」
  - 下一章：这些能力怎样一步步生长出来
- 〔书页 书前·脉络〕
  - 生长章：再现能力按分化阶段长，不是「画错」
  - 教育尊重阶段；雕塑里同样有一维到三维的生长
  - 下一章：空间——深度与层次怎样被看见
- 〔书页 书前·脉络〕
  - 空间章：深度与层次是组织成就，透视只是一种手段
  - 梯度、重叠、简单律与焦点，决定「空间故事」
  - 下一章：光——看见的条件，也是可被表现的主题
- 〔书页 书前·脉络〕
  - 光章：照明是可分离的一层；亮度多为相对
  - 影、辉光、象征，让光从条件变成主题
  - 下一章：色——另一套结构规则的媒介
- 〔书页 书前·脉络〕
  - 色章：色任性，但构图仍靠结构关系说话
  - 少谈偏好趣闻，多谈组织与相互作用
  - 下一章：运动——时间里的看见
- 〔书页 书前·脉络〕
  - 运动章：动是组织与力的故事，不是纯位移账
  - 框架、闪现、剪辑、因果、活度，层层加深
  - 下一章：动力——不动形里的张力
- 〔书页 书前·脉络〕
  - 动力章：简单律之外，还要张力与导向
  - 不动之动可感、可讲，是表现的底座
  - 下一章：表现——力怎样成为可懂的意思
- 〔书页 书前·脉络〕
  - 表现章：有劲的行为样子等于可谈的表现
  - 全书一条线：从力场与组织，走到可懂的意思
  - 脉络读完：进正文时带着地图，才看见作者的心

### 新版序

- 〔书页 序〕
  - 新版几乎整本重写，不是旧版重印
  - 初版写得快、很个人，冲劲有用，但原理不够醒目
  - 新版要把几条基本道理讲清楚，结构排得更齐
- 〔IMG_0006〕
  - 几条基本道理适用于形状、颜色、空间、运动各个方面
  - 问题不是谈得太多，而是感官理解力睡着了
  - 概念和知觉脱节，眼睛只剩识别与测量，这是文化的毛病

### 绪论

- 〔书页 1〕
  - 语言不能代替看，但可以给已经看清楚的东西起名
  - 理智和直觉要一起干活，不是关掉一个开一个
  - 本书要谈视觉的长处；谈艺术离不开心理学
- 〔IMG_0008〕
  - 本书主要谈绘画、素描、雕塑；从看见走向意思
  - 「格式塔」：整体不是部分相加；部分长什么样，看它在整体里的位置
  - 看见是创造性地把握，不是相机式记录；艺术看见是日常看见的延长
- 〔IMG_0009〕
  - 看见是对象和观察者共同作用，不是纯主观乱贴
  - 艺术能力可以发展，不是少数天才垄断
  - 本书拒绝空话和伪科学；艺术是最具体的事
- 〔IMG_0010〕
  - 先整体感受，再谈零件；只数形式元素仍在回避艺术
  - 本书工具用来磨利直觉，不是取代直觉
  - 绪论收束：写作缘起于补缺口，成书于课堂与工作室的反复打磨
