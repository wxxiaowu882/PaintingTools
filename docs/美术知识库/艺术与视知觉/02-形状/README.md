## 精录要点（摘自 @@要点）

### 二 · 形状

- 〔书页 42〕
  - 日常「看见」常常只是最低限度的定向识别
  - 视看是主动探索，不是把世界被动复印进眼睛
  - 我们抓的是突出特征；少数线索就能撑起完整式样
- 〔IMG_0028〕
  - 细节只有嵌进整体框架才有意义；缺整合则整体不可认
  - 知觉从整体结构特征开始，不是从个别慢慢抽到一般
  - 知觉用一般感官样子代表刺激，不是复制刺激本身
- 〔IMG_0029〕
  - 真实景观必须被整理成可把握的配置，才算被知觉——这就是形成「知觉概念」
  - 视看即创造；看见等于看懂
  - 物理形由边界定；知觉形还受取向、环境、经验与再现意图牵动
- 〔IMG_0030〕
  - 看见的形 = 物 + 光 + 神经系统，还要加上经验
  - 画形可以画「要紧的特征」，不必画完整边界
  - 过去会影响现在，但不是简单「见过就会看成那样」
- 〔IMG_0031〕
  - 过去要「结构相像」才起作用，不是见过就自动套用
  - 模糊图给经验和预期留空间，但仍有硬边界
  - 当前配置偏向哪种结构，往往压过「学过多少次」
- 〔IMG_0032〕
  - 强烈需要会让人「看见想看见的」，并把对应标准放宽
  - 坐标与方程能复制形，却少谈形的本性
  - 正常视觉抓整体；在条件允许下，所见结构尽可能简单
- 〔IMG_0033〕
  - 简单首先是好懂、好记，但最终要用结构特征衡量
  - 主客观简单常分叉：看不出复杂，不等于对象真简单
  - 更长可以更简单——关键在结构是否一致
- 〔IMG_0034〕
  - 规律交替可以比「块数少」更简单
  - 简单性看距离、角、对称这类结构特征，不是数零件
  - 局部最简未必整体最简——要以整盘样式定特征
- 〔IMG_0035〕
  - 简单性数「知觉到的结构」，不是纸上线段种类
  - 每个复杂度层级内部，还有相对简单要问
  - 看起来简单的杰作，表面往往并不初级
- 〔IMG_0036〕
  - 艺术里的简单 = 秩序统摄复杂，不是零件少
  - 统一手段（一种笔触、一种线责）是常见的「省」法
  - 简单形组合加上近似的比例位置，可造出非初级的微妙张力
- 〔IMG_0037〕
  - 整体合一靠比例距离与「差一点」的巧合共同维持
  - 简单也看形与意义是否结构同构——形义脱节就不简单
  - 刺激越弱，知觉越能把图案简化成更基本的形
- 〔IMG_0038〕
  - 弱刺激下看与记都会整理图案，不是原样复印
  - 实验结果要留画技与表达媒介的余地
  - 闪视临摹是证明知觉组织力的经典手段
- 〔IMG_0039〕
  - 简化有两路：减特征（匀平）或把差异分更清（锐化）
  - 视觉场是格式塔——所见互动在神经系统，不在物体物理变化
  - 简单律在弱刺激或分组约束下把图案收束到最简结构
- 〔IMG_0040〕
  - 脑会补全简单形；戴畸变镜后仍会重新校正
  - 运动知觉服从整体最简情境——圆盘转、方块转，结论不同
  - 同一笔画可被读成一块，也可被读成两形组合——取更简者
- 〔IMG_0041〕
  - 分割看谁更简单：有时整体赢，有时部分把形撕开
  - 黄金分割矩形：整体与部分力量平衡，既合又不僵
  - 同样形在不同上下文、不同运动下，会裂成不同单元
- 〔IMG_0042〕
  - 分割是辨认物体的前提，不是附带动作
  - 视觉会被倒影、星座、伪装误导，但多数时候仍可靠
  - 眼睛常看得准，是因为人造物与自然物本身就常以清楚、稳定的方式显形
- 〔IMG_0043〕
  - 艺术中的分割直接关系到作品想说什么
  - 整体与部分谁压谁，会改变同一题材的意义
  - 好作品常有多级分割，并靠稀处与密处的对比建立重点
- 〔IMG_0044〕
  - 被切出来的一段，不一定是结构上的「部分」
  - 部分的身份由整体结构决定，不能只看局部连接
  - 好的局部既有自身完整性，又会把人引回整体
- 〔IMG_0045〕
  - 相似让已经分开的项目重新成组，是基本的编组力量
  - 比较必须先有共同基础，不能拿毫不相干的东西硬比
  - 我们往往先凭相似看成一组，再在组内注意差异
- 〔IMG_0046〕
  - 大小、形状、明暗、邻近、方向都能成为编组依据
  - 运动中的方向与速度差，会比静止图更强地分开群组
  - 分组不只靠挨得近，远距离呼应同样能成立
- 〔IMG_0047〕
  - 只从局部相似往上拼，无法推出所有整体结构
  - 轮廓方向和位置的一致性，会让断开的部分被知觉为连续
  - 知觉偏爱的连法，往往对应更简单、更顺的整体动力骨架
- 〔IMG_0048〕
  - 轮廓可由许多局部共同「暗示」出来，不一定非要画实线
  - 形越一致，越容易从背景里脱出并维持身份
  - 视觉的顺接原则，在音乐的声部进行中也能找到对应
- 〔IMG_0049〕
  - 相似可发生在整体中的对应位置，不只是相邻单位之间
  - 当单位彼此连续或紧贴时，视觉会把它们收成一个实体
  - 对象形成依赖简单原则，是知觉最基本的组织成就之一
- 〔IMG_0050〕
  - 艺术中的相似常表现为渐变，不是机械重复
  - 颜色和形式的呼应，可以跨画面大距离把意义连成一组
  - 相似不仅能分组，还能安排观者的阅读顺序和视觉运动
- 〔IMG_0051〕
  - 相似可以把分散部位连成有意味的运动线
  - 眼睛会跟着颜色相似去「演出」画里的动作
  - 要比较差异，先得有相似作共同底子
- 〔IMG_0052〕
  - 相似可统一整幅，也可单独挑出人物结构
  - 颜色既能跟分割走，也能故意反向搅一搅
  - 同与异是相对的；艺术里常让分组因素彼此对打
- 〔IMG_0053〕
  - 「形」等于实际边界，加上知觉诱发的结构骨架
  - 画家与观者心里真正抓的，是骨架，不是逐点轮廓
  - 眼动轨迹并不等于最终看到的结构
- 〔IMG_0054〕
  - 轮廓连续变，骨架可以阶跃变
  - 骨架等于该形在简单律下能抽出的最简轴线结构
  - 同一轮廓可抽两套骨架，就是两种完全不同的看见
