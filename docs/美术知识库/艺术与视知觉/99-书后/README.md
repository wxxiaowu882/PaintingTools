### 注释

- 〔IMG_0239〕
  - 注释用法：主题小标题定位，再按括号号回书目
  - 方边「磁」排斥与视觉后效同族；知觉力有生理对话者
  - 不平衡会暗示运动；重量与方向条目指向杠杆与舞台孤立
- 〔IMG_0240〕
  - 弥漫 vs 分节（轴/中心/极化）是读构图的粗分类
  - 上下朝向可测，但抽象画四向实验说明意图朝向常需学习
  - 注释把「感觉如此」钉成可复查的出处网
- 〔IMG_0241〕
  - 简化/整体自持有实验与哲学文献双撑
  - 勿把秩序缩成「分组」一义
  - 形状章注脚直接扣进形态章的结构骨架
- 〔IMG_0242〕
  - 埃及法=概念忠实，不是透视失败
  - 平面/深度竞争有实验传统
  - 形态是发明；儿童与艺术史走同一分化逻辑
- 〔IMG_0243〕
  - 深度整合有艺术史分期，不是自古如此
  - 生长章注脚连猿画、儿童分化与教学对话
  - 倾斜/垂直条目把「风格」接回知觉定向
- 〔IMG_0244〕
  - 原初圆与分化=生长顺序，不是品味
  - 倾斜=动力；垂直水平=安息骨架
  - 注脚已为空间章的图底/画框论备料
- 〔IMG_0245〕
  - 图底/轮廓争夺有实验族谱；画框与窗是归属装置
  - 物理最简≠总是最短；艺术「经济」要拆开说
  - 空间注脚把实验室演示接回绘画与雕塑
- 〔IMG_0246〕
  - 视觉悬崖等：深度敏感早于测量式教育
  - 造深度是手段束，不是单靠透视法
  - 空间注脚衔入光的象征讨论
- 〔IMG_0247〕
  - 光章注脚含藏地与歌德读画的鉴定谨慎
  - 色=物理+知觉+实践三线并行
  - 歌德/德拉克洛瓦/笛卡尔被拉进同一色问题场
- 〔IMG_0248〕
  - 冷暖有实验，不只有习惯说法
  - 色章收束直接扣进运动/时间
  - 神话—文学例与电影理论一起谈时间尺度
- 〔IMG_0249〕
  - 闪现实验与剪辑实践是同一问题的两面
  - 运动力=性格，不只是速度矢量
  - 注脚已搭好通向动力/表现的桥
- 〔IMG_0250〕
  - 罗丹「相位运动」被校正为动力渐变更贴
  - 表现章注脚重申：象征=图像与观念，非器官对照

### 参考文献

- 〔IMG_0251〕
  - 编号=注释与正文的文献钩子
  - 用法：主题→编号→出版信息；或索引→页码→正文
  - 书目光谱=艺术×心理×生理×设计
- 〔IMG_0252〕

  - 精译正文不必展开的，可指向这些专书
  - 再版改名以书目款为准
- 〔IMG_0253〕

  - 外证路径：精译→注脚→编号
  - 不要靠书目「名气」代替论证
- 〔IMG_0254〕
  - 完形后效与生理视觉是本书科学侧支柱
  - 设计教育文献支撑「课堂例」不是点缀
  - 核对出版年，防早期表述覆盖新版论点
- 〔IMG_0255〕
  - 透明性/定向实验→空间章；蝌蚪人→生长章
  - 语言文献在场，但不等于「看由词决定」
  - 概念卡外证优先走书目编号，不走名望
- 〔IMG_0256〕

  - 经验论对手文献被有意保留
  - 文学条目=寓言工具，不是跑题
- 〔IMG_0257〕
  - 行为/本能文献是旁证，不是还原论执照
  - 结构工程书与建筑表现论可互参

- 〔IMG_0258〕

  - 书目保持检索性，不做故事化意译
  - 索引=第三入口：词→页→文
- 〔IMG_0259〕

  - 中文知识库主词优先；索引指路不定义
