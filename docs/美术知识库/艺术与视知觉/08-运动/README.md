## 精录要点（摘自 @@要点）

### 八 · 运动

- 〔书页 372〕
  - 动最抢眼，因为生存需要我们对变化立刻反应
  - 多数「事」是物在动；纯运动少见，但实验里确实有
  - 物理上一切都在时间里；心理上，雕像可以像不在时间里——所以「会不会动」不等于「有没有时间感」
- 〔IMG_0195〕
  - 有的紧张只是空间悬念；有的才真靠时间能不能对上
  - 电影/交响要整本同时在心里，不能看一段忘一段
  - 记忆把「已经过去的」留成可同时互相作用的痕迹——所以序列艺术仍要求同时性
- 〔IMG_0196〕
  - 会动 ≠ 必须按规定顺序看；有静画须按序读，也有动作品无固定顺序
  - 扫画时眼睛的先后不重要；戏与音乐的先后却是要命的
  - 画的等级关系要「同时在场」才懂——这和上一页「整本同时在心」是同一条线
- 〔IMG_0197〕
  - 永久与变化是一对：画偏用空间定力，舞台偏用运动力定空间
  - 看见谁在动，不总等于物理上谁在动
  - 下一页：框架规则——蚊子依附大象，不是反过来
- 〔IMG_0198〕
  - 框架常显得静，依附者常显得动（邓克尔）
  - 包围、可变、更小、更暗、被注视——都容易让某物「承担运动」
  - 舞台与电影用不同框架，讲出不同的「谁在动」
- 〔IMG_0199〕
  - 动的上下文里，静常常等于「被冻住/在顶着」，不是「在时间外」
  - 方向服从简单：线沿自身伸展；看得见轴，轮才拆成转+走
  - 复杂舞蹈运动=可分主题叠加，有时渗出合成曲线
- 〔IMG_0200〕
  - 看得见的速度窗口很窄：进化调到「对人要紧」的快慢
  - 上下文的快慢水准会改写你觉得有多快
  - 电影用慢拍/快拍，把草长、子弹、细胞劳动变成可见手势
- 〔IMG_0201〕
  - 改速度会改性格：快可变恐慌冲撞，慢可变羊毛软
  - 快慢既可归给物体力气，也可归给媒介阻力
  - 越大越显慢；场越小越显快——速度从来不是单纯数字
- 〔IMG_0202〕
  - 闪现运动更像时间里造连贯形，不只是网膜残留「糊」在一起
  - 位置近、角色相似，帮助两刺激连成一流
  - 路径形一致、隧道暂时遮住，仍可能保住「还是同一个」
- 〔IMG_0203〕
  - 对称轴会劝阻交叉，哪怕局部路径更想交叉
  - 复杂闪现里，整体常移到结构对应位（特努斯）
  - 旋律听起来像「一音在走」——和闪现是同一类组织
- 〔IMG_0204〕
  - 剪辑要同时做到：跨切仍是同一人，又绝不误连成别人
  - 闪现会「变身」；魔术可用，叙事常要躲开
  - 多机位要认得出同一，又要避免位置太像造成跳跃
- 〔IMG_0205〕
  - 位移在知觉里是有力的故事，不只是位置账
  - 远距离「死移」是例外；近处主动运动才像活的
  - 米肖特用极简方块，把身份与因果拆开测——组织一变，故事就变
- 〔IMG_0206〕
  - 接触瞬间别停——一停，因果就断
  - 推=能量跳过去；释放=只给信号（常滑稽）
  - 一端先动传全身=自生有机动力（毛虫感）
- 〔IMG_0207〕
  - 伸缩一体=有机；裂成两刚体追随=机械
  - 同一种位移，组织一变，活度就变
  - 自发知觉按活度与行为复杂度分级，不先问灵魂
- 〔IMG_0208〕
  - 活度是连续阶梯，不是死/活二元开关
  - 儿童标准逐步收紧：行动 → 运动 → 自生 → 动物
  - 艺术家按可见力行为选剂量，不先查物种护照
- 〔IMG_0209〕
  - 停停走走/之字=互动力；摄影机复杂动=隐形角色
  - 几何形只靠运动就能被读成「恶霸」「受害者」
  - 越复杂越「像人」——但人也可机械，膝也可像机器
- 〔IMG_0210〕
  - 对观众：舞者=可见形姿；磅数与渴望若不在画面就不在
  - 头是神经中心，躯干才是舞的可见动力中心——两者错位
  - 躯干中心舞偏「自然之子」；许多舞者抗拒离开理性控制
- 〔IMG_0211〕
  - 一切舞/戏运动都必须服从主导主题；自觉会把灵魂「坐错地方」
  - 克莱斯特木偶：重心外的灵魂=做作；最低整合仍不够优雅
  - 舞者在动觉里造，观众在视觉里收——共元是动力张力
- 〔IMG_0212〕
  - 媒介尺度：舞台大手势 / 特写小眉毛 / 有声片压手势
  - 死位移 ≠ 动力行动；拉班从度量矢量走到「努力」质
  - 下一章：导向张力——不动形里也有的动力；简单律之外的第二条原则
