## 精录要点（摘自 @@要点）

### 一 · 平衡

- 〔书页 10〕
  - 一眼看出偏了，不是先量再比
  - 看见里有拉力、推力，不是静态贴图
  - 中心可以看不见，却仍有「力」
- 〔IMG_0012〕
  - 视野里有「诱导」出来的结构，不只视网膜上的墨迹
  - 圆盘可当探针，探出安稳、吸引、太挤、摇摆
  - 正方形有结构骨架：中心、十字轴、对角线
- 〔IMG_0013〕
  - 中心与对角线上的安静点，都来自力的和解
  - 含糊摇摆比明确偏离更干扰判断
  - 结构骨架给整体平衡当参照，像音阶定音高
- 〔IMG_0014〕
  - 视觉图案是连续力场；死中心也活着紧张
  - 看见就是知觉到行动，不是读尺寸表
  - 知觉力在经验里真；生理上应是场过程
- 〔IMG_0015〕
  - 两盘的吸引、排斥与成对读法，都受正方形结构牵动
  - 形状与位置顶牛时，平衡会含糊难忍
  - 视觉平衡定义像物理平衡，但重心算法跟物理不完全一样
- 〔IMG_0016〕
  - 物理稳 ≠ 看起来稳；颜色、位置、方向会改视觉账
  - 视觉重量能让场面的样子配上它要讲的意思
  - 平衡使配置显得必然；不平衡像半路冻住的偶然
- 〔IMG_0017〕
  - 不相等要靠制衡钉住，意思才站得住
  - 含糊比明确的不平衡更伤——说不清图案想说什么
  - 重量与方向特别能左右均衡；强位置能托更大重量
- 〔IMG_0018〕
  - 离中心越远、伸进深度越深，重量往往越大
  - 大小、颜色、趣味、孤立、规整形、紧凑都会改重量
  - 「知道它该轻」改不了看起来的轻重
- 〔IMG_0019〕
  - 技术上撑得住，不等于看起来撑得住
  - 方向由吸引、形状轴、题材目光与真运动共同决定
  - 真运动与言语也会加入重量和方向的账
- 〔IMG_0020〕
  - 平衡格局从「一强众弱」到「满屏等重」都可以
  - 一律求稳适合讲气氛与生存方式，不适合讲中央权力
  - 排法本身参与意义——形式说的话要和题材合拍
- 〔IMG_0021〕
  - 上升像胜利，下降像投降——上下动力本就不对称
  - 同样的东西放上方更重，所以上面往往要做得更轻
  - 传统偏底重；现代常略增顶部重量以摆脱「贴地」
- 〔IMG_0022〕
  - 版式与装裱常底下多留空；完全对称形塞进不对称空间要小心
  - 天花板可读成房间延伸，也可读成独立画面空间
  - 左右差别弱于上下，但画里仍有从左向右的动态偏向
- 〔IMG_0023〕
  - 画从左往右读；镜像会改外观和意思
  - 左侧重认同，右侧更显眼、往往更重
  - 朝右的运动像顺水；朝左像逆流、更费力
- 〔IMG_0024〕
  - 左右矢量来自观看组织，不是眼球轨迹本身
  - 人在身心与艺术里都求均衡，为让陈述站住
  - 只求歇住不够——活的充实在做与创造；平衡是终点不是唯一内容
- 〔IMG_0025〕
  - 作品意义来自激活之力与制衡之力的配方，不是只要和谐
  - 竖、瘦、亮的等级与椭圆核，共同推出又托住人物
  - 左右重叠、椅人反倾、头手分工，把「要动」冻在平衡里
- 〔IMG_0026〕
  - 带框构图像音阶：升起之后在新的「底」上再歇住
  - 题材是结构的一部分；对位有主有从，才不陷入含糊
  - 平衡让力的关系说清楚；下一章问这些力附在什么形状上
