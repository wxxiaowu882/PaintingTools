## 精录要点（摘自 @@要点）

### 十 · 表现

- 〔书页 444〕
  - 只用量一量的办法描述所见，会漏掉画面里直接传来的「劲」
  - 只写动力特征，性格仍会自己露出来
  - 表现=对象外观里看得见的行为样子；不限于人脸
- 〔IMG_0231〕
  - 表现问题的核心：眼睛只见皮肉位移，却读出心境
  - 面相学史上有人捧、有人鞭；「鼻疣=懦夫」式联想靠不住
  - 关键不在外在凑巧，而在结构本身能否直接载意义
- 〔IMG_0232〕
  - 移情论承认「力」，但仍是间接：把我的体感投射出去
  - 传统论把表现当学会的标签，否认样子与意义天生对得上
  - 真正关键的是：轮廓里的动力有没有被看见
- 〔IMG_0233〕
  - 速度、形、方向可直接被眼睛读成表现
  - 同构=结构上对得上：圆单条件更硬，抛物双条件更柔
  - 米开朗基罗穹顶用两圆妥协，造出「沉重却往上起」
- 〔IMG_0234〕
  - 根与抽象形，常常比人体更干净地传出表现
  - 不是「像人才悲」，而是「下垂结构先在，悲伤类比后到」
  - 表现是一般知觉属性；人体只是特例，而且更难用
- 〔IMG_0235〕
  - 在特殊事件里感到普遍象征，是文化的日常地基；病态极端才会变成「身体替心理说话」
  - 「量一量」这种看法，是很晚才练出来的专业态度；先感到表现，更原始也更常见
  - 走进表现章，是把动力事实正面说出来，不是另开新题
- 〔IMG_0236〕
  - 写生判笔：是否抓住动力心境，而不是几何正确本身
  - 圆首先是紧、硬、稳；表现主题是选形的自然向导
  - 反对自我发泄；好练习本身就表现——帕卢卡《技术即兴》
- 〔IMG_0237〕
  - 弗氏器官对照不是艺术象征的终极内容
  - 题材只是指向观念的形式材料；两幅静物可以说出两种现实观
  - 《创造亚当》用指尖火花与臂桥，把创世写成可见的动力事件
- 〔IMG_0238〕
  - 结构骨架揭示动力主题；力在观者里活起来，才是艺术参与
  - 故事与图案互为手段，共同给普遍主题穿上血肉
  - 具象与抽象不断裂；风格只是圣山的一个视点，不是终点
