## 精录要点（摘自 @@要点）

### 九 · 动力

- 〔书页 410〕
  - 简单律解释力很强，但只靠它会把艺术说成「都合得好看」
  - 极简能清眼睛，却喂不饱；先问：被平衡的是什么？
  - 活体不是封闭系统：减张之外，还有往上抬的结构主题——这就是动力章要讲的第二条原则
- 〔IMG_0214〕
  - 作品里同样有抬张与减张：结构主题尽量做成最简，但张力可高可低
  - 看见=经验视觉力；只谈度量会漏掉外指、碰撞、猛冲
  - 「静中之动」是隐喻；别急着用「幻觉/回忆贴上去」打发——下一页要反驳
- 〔IMG_0215〕
  - 好坏差不在「联不联得上跑」，在形是否真的载力
  - 楔/斜/糊有助动力，但动力不是「想起位移」的幻觉重演
  - 最像「要挪地方」的不平衡，往往显得冻结——假动其实是麻痹
- 〔IMG_0216〕
  - 「想挪」的不平衡往往僵；真「运动感」要掐灭「真要动」的迹象
  - 导向张力=形色固有，不是回忆贴上去
  - 自然形是力的化石；艺术形多靠笔迹式运动印记
- 〔IMG_0217〕
  - 笔触/指印把创造行动加进作品；复制机垂直压常「压死」动力
  - 动力不必对应物理内力；磨光仍可肿胀
  - 视错觉=眼睛看到的样子为减张而改客观图
- 〔IMG_0218〕
  - 斜求正交、放射场求圆等价——错觉常是减张
  - 三角有侧推；沿形内导向张力（往哪边使劲）动，位移显得更快
  - 动力不仅「感觉」，还能量化改位置与形
- 〔IMG_0219〕
  - 平行四边形「想」回矩形——动力=潜在恢复
  - 快照单帧常无行动感；有效再现可以「物理错误」
  - 最大张开才译出强度——艺术对，摄影「真」却僵
- 〔IMG_0220〕
  - 成功静像把整段行动收成不拴在某一瞬间上的姿势，可以叠「仍/已」而不荒谬
  - 斜向是行动与休息的基础开关
  - 不对称斜最强，对称对角次之，正交最静
- 〔IMG_0221〕
  - 斜向推深度；巴洛克爱整画轴斜对观者
  - 火焰与楔是主动形；曲线变速率比直边更「活」
  - 规范位记忆可额外加张力——举臂比树杈更紧
- 〔IMG_0222〕
  - 一切张力来自相对更省力的底本的变形；底本还得隐含在场
  - 卵/瘦矩形比圆/方更紧；总场倾斜给整场行动感
  - 间隔也会压或被压——空不是死白
- 〔IMG_0223〕
  - 偏离人体规范造张力；全风格拉长是一般陈述，不是个体残障
  - 雕塑表面应是「朝你的体积末端」——从内推出
  - 不完整、重叠、半埋，都是求闭合与挣脱的张力装置
- 〔IMG_0224〕
  - 纯原色少张力；偏色可像导音朝纯色奋力
  - 局部再「动」也会互拆成堵塞——必须服从总动力主题
  - 主题必须从主动脉流到毛细血管；孤立推敲局部最易死
- 〔IMG_0225〕
  - 角折若与软流冲突就停动力；须统一形构思
  - 无导向张力=作品死，别的优点救不了
  - 闪现摄影/未来派倍增/多像合成=不动媒介里的序列动力
- 〔IMG_0226〕
  - 互为倒置的像可合成旋转组——位置关系本身在转
  - 加倍/重叠相似单元在斜向上造张力与渐强；反程序可成死壳
  - 动力来自知觉结构，不来自「知道该转九十度」的知识
- 〔IMG_0227〕
  - 动力不是随便加上去的，也不是物理世界现成属性；它在神经系统组织刺激时长出来
  - 看起来静，往往只是推拉暂时打平
  - 灯忽然亮时的扩张/收缩，是静止图案里「往哪边使劲」的活标本
- 〔IMG_0228〕
  - γ 运动可当静止图案张力的解剖线索
  - 「知不动」不挡动力；贝雷帽可与舞裙一样动
  - 皮耶罗把升起写成永恒对称，把动力留给睡着的兵——意义靠反转
- 〔IMG_0229〕
  - 闪现把站立→跌倒写成九十度刚完成；死降被生升盖过
  - 绝望用极端相位互切，不作渐变
  - 哀悼者排成可与旋律线对照的表现曲线；高潮旁立收束竖直
