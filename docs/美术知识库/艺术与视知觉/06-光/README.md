## 精录要点（摘自 @@要点）

### 六 · 光

- 〔书页 303〕
  - 午夜白手帕 vs 正午黑炭：亮度是相对尺度上的位置，不是绝对光量
  - 眼睛分不出「物亮」与「光照」——只收到合在一起的强度
  - 辉光 = 相对场尺度越级；绝对可以很暗，仍像「自己在亮」
- 〔IMG_0160〕
  - 整场可一起转调：久处昏室、沉进暗画，都不觉得「真有那么暗」
  - 相对白信封：看见的是它在总亮度坡上的位置
  - 反阴影、刷浅窗墙：用物面坡抵光坡，造「更匀」或「更扁」
- 〔IMG_0161〕
  - 两物可同「恒常白」却仍显不同——照明差没被抹掉
  - 均匀亮场不等于看见照明；照明是可认出来的「披上去」一层
  - 自然看：物色一层加光影透明层；小孔逐寸看则只见色阶
- 〔IMG_0162〕
  - 照明等于光坡透明叠在固有色上；简单律拆成两层
  - 侧光造体积；顺光或均匀光易压扁
  - 明度加速坡度可塑曲面曲率
- 〔IMG_0163〕
  - 坡度陡度与速率塑平面或曲面；对称阴影弱立体
  - 深度读法一翻，哪边该亮该暗跟着翻
  - 相似明度约等于相似朝向：侧光把整场织成统一浮雕
- 〔IMG_0164〕
  - 明暗收成「一串葡萄」才不散视线
  - 附着影要糊边才像透明膜；锐边聚光把影钉成物面斑块
  - 多灯要有主次等级，否则形与空间关系被撕乱
- 〔IMG_0165〕
  - 附着影帮塑形常被忽略；投影影是对他物的「放暗」干涉
  - 投影须让眼睛同时懂「不属于此」与「属于彼」
  - 影的民俗与象征：黑暗是积极实体，是第二自我
- 〔IMG_0166〕
  - 固体加影常被当成一个对象来读深度
  - 太阳影近等轴测；近灯影物理发散，再加透视
  - 照明等于第二套收敛系统，与形状透视叠加
- 〔IMG_0167〕
  - 黑影明暗易弄脏固有色；色与空间浮雕曾长期打架
  - 日常光影「服务完就忘」；儿童早期把阴影当习俗
  - 阴影可先当塑形手段，不必先等于「有光源」
- 〔IMG_0168〕
  - 明度可先服务重叠与构图，再谈「合不合光源法」
  - 写实照明学会后，仍可「抽象」用坡度分离平面
  - 艺术允许「违反自然」的双光——若表达需要
- 〔IMG_0169〕
  - 早期光多半塑形；后来光成主动力与戏剧
  - 伦勃朗汇合象征光与感官光：启示而非装饰
  - 画外上光等于影谷依赖彼方；画内藏烛等于物自身发光传讯
- 〔IMG_0170〕
  - 辉光：相对越级加少影加薄膜色（无清晰质地壳）
  - 光可当解释工具：亮谁压谁，不必改场面清单
  - 逆光、深暗、白雾：物从虚无涌现或只作挡光的负面存在
- 〔IMG_0171〕
  - 点彩：每点自发光，取消外在总光源
  - 布拉克把明暗从「披上的光」改成「构成物」的两半
  - 光章收束：照明可被拆解为物性对立或发光点阵
