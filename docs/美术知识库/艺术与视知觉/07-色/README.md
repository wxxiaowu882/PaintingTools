## 精录要点（摘自 @@要点）

### 七 · 色

- 〔书页 330〕
  - 色既帮你认出东西，也让世界多一股「活起来」的劲
  - 雷东从黑走到全色：同一题材换色质，意义大变
  - 色名跟着用途和文化走；眼睛能辨上千，脑子却从简到繁地收成概念
- 〔IMG_0173〕
  - 色名大致按这条路长：暗亮 → 红 → 绿或黄 → 蓝 → 其余基本色
  - 缺某个色名，不等于视网膜没进化好，多半是概念还没分那么细
  - 形能分的种类远多于色；色擅长并排放细辨，不擅长隔空或靠记忆点名
- 〔IMG_0174〕
  - 形更能扛环境变化；固有色最怕照明色和光强弱
  - 色恒常靠视网膜适配「摊平」——连照明色本身也常被看错
  - 换照明差不多等于换色组织；形几乎不动
- 〔IMG_0175〕
  - 幼童先抓形，再迷色，入学后又常被训练回形
  - 色偏接收、像情绪打来；形偏主动组织——可艺术两边都需要
  - 西方传统常抬形压色；那是价值偏见，不是知觉定律
- 〔IMG_0176〕
  - 牛顿：色是射线固有属性，白是混在一起彼此中和
  - 歌德：保卫日光纯度，色是光与暗互动的「受苦」
  - 叔本华：补色对来自视网膜功能二分——预告后来的对抗过程论
- 〔IMG_0177〕
  - 生成原色谈怎么造色；根本原色谈眼睛怎么看成组织——两套不能混
  - 视网膜大约三色素；黑林对抗过程与扬三色论要合着用
  - 「光加、颜料减」太粗：滤片可减，颜料粒子常常加减搅在一起
- 〔IMG_0178〕
  - 印象派并置蓝黄，加合得灰白，不是颜料那种绿
  - 生成互补（混出灰白）不等于画家根本互补（眼里互相完成）
  - 互补也管明度：黑的后像是白，浅绿会对上暗红
- 〔IMG_0179〕
  - 色复制与老化，常让「看见原作真色」变成幻觉
  - 色没有「本身如何」：总在上下文里被邻色与照明改写
  - 难谈不等于乱：成功构图里，色彼此钉住成客观陈述
- 〔IMG_0180〕
  - 色立体：轴是灰阶，赤道是色相，半径是饱和
  - 和谐理论常押「共同元素」或「过中心互补」
  - 生成互补不等于根本互补——这混淆在和谐规则里再次潜伏
- 〔IMG_0181〕
  - 色和谐「简单规则」几乎从不拟合真画；面积等变量一加就崩
  - 只求彼此顺滑，等于托儿所和谐，也像熵最大的死静
  - 音乐关心的是表达形状，不是「怎样不碍眼」——色也一样
- 〔IMG_0182〕
  - 色组织需要有限骨架；细微差是屈折，不是无限乱飞
  - 分离与不协和跟连接一样必要
  - 知觉「纯」不等于光谱纯；三不可分根本原色是蓝黄红
- 〔IMG_0183〕
  - 画家根本原色是红黄蓝；绿是否第四原色有争议
  - 纯原色是极与主音；间色是振动桥
  - 间色主导等于动力拉扯；原色主导等于古典稳定
- 〔IMG_0184〕
  - 偏色像导音：逼回主导纯原色
  - 同是「共有红」，从属对从属顺，主导对从属常撞
  - 主导相似刺耳；结构反转或因对称而可和谐——仍待实验核验
- 〔IMG_0185〕
  - 不协和是工具，不是禁令——用错位置才乱
  - 根本互补靠眼睛「互相完成」，不必等于混出灰白
  - 红黄蓝像三脚凳：缺一则张力，齐则平
- 〔IMG_0186〕
  - 下一层组织：纯原色对上「另两的平衡混合」
  - 互补既可以像婚姻般完成，也可以像红绿暴力那样对打
  - 完成等于最大对比加互相中和——剂量与面积决定你怎么读
- 〔IMG_0187〕
  - 细分互补变成银灰：丰富又宁静；大块互补变成对峙高潮
  - 强互补组像圆：自足，难当配角
  - 色影比灰影更能「封住」体积的两极
- 〔IMG_0188〕
  - 色身份在关系里，不在「色本身」
  - 同时对比推向互补；中间色可以同化、减碰撞
  - 对比与同化成对出现——哪个近就朝哪个走
- 〔IMG_0189〕
  - 细点真混合；略大点同化抹差；大块锐对比
  - 等明度异色相，边界容易融化；画家多用明度差加固
  - 马蒂斯例：同色三人体压深度；顶底色对称压纵深
- 〔IMG_0190〕
  - 最亮白往前顶，把黄人体「夹回」景深刻度
  - 黄管下半、蓝管上半，在中央绿碰头
  - 最大深度跳跃处用近似互补：又撕开又缝上
- 〔IMG_0191〕
  - 形斜轴偏左连；色方案跟着偏连或撞隔
  - 圣婴黄发补齐红蓝黄三脚凳，是色拱心石
  - 左：紫绿近互补易合；右：主导相似红撕尺，造屏障
- 〔IMG_0192〕
  - 格列柯下半：灵感与沉思两态度嵌进总对称
  - 色表达太直接，联想说不够；长波扩张、短波收缩有实验线索
  - 暖冷或看「偏往哪」：掺红偏暖、掺蓝偏冷——仍待验证
- 〔IMG_0193〕
  - 温度词借的是「邀请/挡开」的反应，不是字面热冷
  - 色趣闻与偏好调查，几乎帮不了我们懂构图结构
  - 色章收束：结构因素可谈；「谁喜欢什么色」靠边
