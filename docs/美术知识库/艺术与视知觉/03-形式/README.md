## 精录要点（摘自 @@要点）

### 三 · 形式

- 〔书页 96〕
  - 形态就是内容显出来的样子；分析时可暂时拆开形状，可知觉里它总在代表某物
  - 形状先告诉我们「类」，不是某一个孤例
  - 外观也可被读成处境的象征——艺术正靠这一层说话
- 〔IMG_0056〕
  - 写实传统让人忘了：图像本来就是媒介里的等价物，不是投影复本
  - 「越像越好」站在双重素朴实在论上，站不住
  - 朝向一变，对象的性格可能大变——这正是下一页要回答的问题
- 〔IMG_0057〕
  - 倾斜有时只是「歪了一点」，有时换了一套骨架
  - 「同一个纸板」不等于「同一个视觉对象」
  - 朝向由视网膜框架、环境框架、画内框架共同拉扯
- 〔IMG_0058〕
  - 画内多个参照框必须排清主次，否则互相开火
  - 竖横对调或上下颠倒，会改写形的动力性格
  - 人脸倒放时，视觉会坚持「这是一张怪新脸」
- 〔IMG_0059〕
  - 儿童画纸起初不强制「正立」；正立是逐渐学来的
  - 投影是否保住身份，看它是否仍能诱发原对象的骨架
  - 简单律常让人把斜投影读成立体里更稳的矩形
- 〔IMG_0060〕
  - 形状常性很早就有，但并非对一切投影自动生效
  - 不动画面冻住的「怪投影」，在连续运动里可能毫不刺眼
  - 扁平方有「最佳正交投影」；真立体没有等价的单一平面像
- 〔IMG_0061〕
  - 任何单一侧面都任意：造出假轮廓，又藏起真表面
  - 最简投影常被偏爱，却不一定最能传达立体概念
  - 「正确」不等于「够用」——顶视墨西哥人像磨盘
- 〔IMG_0062〕
  - 早期图像与教学图追求最直接、最少隐瞒的侧面
  - 同一对象不同部分常要求不同最佳角
  - 一把椅的四个正交面信息都不可少，却难并进一幅
- 〔IMG_0063〕
  - 埃及法：每部分选最合适侧面，不是「不会画」
  - 他们早会投影，却偏好正交以保对称与清楚
  - 从固定点抄写并不比埃及法更「真」——那是风格选择
- 〔IMG_0064〕
  - 两种再现法各按自己的「真」互相指责
  - 透视靠常性把歪的补回来「做错」的刺激；直接法用真方表方
  - 平面画深度弱，常性不完全——畸变刺激仍渗进知觉
- 〔IMG_0065〕
  - 再现力量首先来自媒介本身的属性
  - 侧面要能暗示「我是整体的一部分」，且暗示对的结构
  - 非典型正面可能误导补全——马变企鹅
- 〔IMG_0066〕
  - 缩短有几何义、知识义、知觉义——艺术里关键的是第三种
  - 斜位保留「从更简正面偏离」的证据；正侧面常不算缩短
  - 投影本身太简单时，会钉在平面上，不肯进深度
- 〔IMG_0067〕
  - 对称轴上的缩短更「冻」、更危险
  - 重叠打断连续，坏接缝处整体崩；好画靠技巧把跳跃融回一体
  - 重叠成立要分得开、分前后；合太简单会误看成一物
- 〔IMG_0068〕
  - 关节切断易成「截肢」；斜切、中段切断更像重叠
  - 补全靠形状性质，不靠解剖知识
  - 重叠把关系收紧、加强，使「在一起」变成互相干涉
- 〔IMG_0069〕
  - 重叠建立前景到背景的主从等级
  - 复杂构图里主从可对调，织成互相主动又被动
  - 相对画中人的对称，常靠斜排与重叠才办得到
- 〔IMG_0070〕
  - 相对画中另一方的对称，圆形群体尤其难，常靠重叠
  - 平面深度的发展，像音乐从复调走向融合连续体
  - 再现始终是：把立体视觉概念译进平面媒介
- 〔IMG_0071〕
  - 同一场面在立体与平面上可分成很不同的小组
  - 投影图案能造出深度安排里没有的序列与对称
  - 事实编组与表情编组不必重合，深度强弱会改变谁占上风
- 〔IMG_0072〕
  - 文艺复兴传统通常只许一个视点，早期艺术则可拼最有信息的面
  - 早期拼面也很少让同一部分的两面并置，双面多为例外
  - 现代拼面继承的是投影传统的危机，路径与早期不同
- 〔IMG_0073〕
  - 早期拼面追求有机完整，立体主义拼面追求故意矛盾
  - 立体派不是简单“看得更全”，而是让不相容看法在平面上冲突
  - 互渗与推力抵消，把社会理论里的“矛盾”做成了可见结构
- 〔IMG_0074〕
  - 机械正确投影反而授权剧烈偏离结构规范
  - 投影自由用尽后，会回流到基本形与基本图式
  - 现代艺术常接管投影特许，却不再用物理投影辩护
- 〔IMG_0075〕
  - 像真是相对图画规范水位而言，不是绝对复制现实
  - 熟悉风格常被直接当成“物本身”，写实也不例外
  - 知觉会随风格适应而改变，前人看见的“乱”，后人可以看不见
- 〔IMG_0076〕
  - 成功之作让人先抓住题材；只见形状往往说明适应水准不对
  - 风格是求真的手段；故意「搞个性」会引进任意性
  - 好形态消融进动力行动——抽象画也一样
- 〔IMG_0077〕
  - 形态是媒介里的等价发明，不是从模特表面抄形
  - 死亡面具很像却常无形——机械逼真不等于形态
  - 同一几何形在不同风格里可当头，也可当石块
- 〔IMG_0078〕
  - 地图式偏离是日常能力：抓结构等价，不抓逐点同一
  - 「画要像真空间」是后来才养成的习惯，不是天性
  - 想象力就是为旧的普遍题材发明新形态
- 〔IMG_0079〕
  - 儿童在媒介里发明再现公式，本不是为了「独创」
  - 对象只规定极少骨架；其余全是想象活动
  - 比较同一主题的不同画，才看得见想象力有多大
- 〔IMG_0080〕
  - 抽象程度是再现风格的自由维度
  - 高度抽象常伴简单规则对称——因心灵偏最简结构
  - 更写实有时不但无益，还会妨碍目的
- 〔IMG_0081〕
  - 原始造像服务日常事务与效力，不服务乱真
  - 写实细节会干扰「种类—功能—关系」的清楚枚举
  - 高度抽象也可来自撤退（拜占庭），不单来自「早期」
- 〔IMG_0082〕
  - 现代抽象常伴随艺术家抽身公共需要——有得有失
  - 纯形态可更直接抓本质，但须保住感官吸引力
  - 失联经验全幅，就成形式主义空转，不是艺术
- 〔IMG_0083〕
  - 异化艺术常剩「秩序本身」，生命与意义枯干
  - 形态插在观者与主题之间，是危险信号
  - 涂鸦与某些精神分裂画共享无调制的形式自我繁殖
- 〔IMG_0084〕
  - 装饰是从属整体的轻松秩序；艺术品是秩序与冲突的互动
  - 严格对称易「冷」，也易成喜剧机械感
  - 蒙德里安抽象不是装饰——别把二者混用
- 〔IMG_0085〕
  - 《泉》姿势「自然」是平面解法，不是解剖学自然
  - 罐与头、开与闭的对位讲「扣住却许诺」
  - 好形式手段消融进整体——看见生命，未必看见机关
- 〔IMG_0086〕
  - 科技插图也要省略、挑选，并把相关事实说清楚给眼睛
  - 再现就是视觉解释；不懂对象结构，就容易画糊或画错
  - 解剖等知识帮助发明「由表及里」说得通的形态图案
- 〔IMG_0087〕
  - 最好的信息图常靠省略与扭曲，把相关结构说死
  - 表达清楚度就是承载特征的清楚度；形糊则意糊
  - 复杂图案也须有丢勒式精确，才送得出信息
