## 精录要点（摘自 @@要点）

### 四 · 生长

- 〔书页 163〕
  - 生长阶段在儿童画里最纯；早期艺术与初学者亦有类比
  - 早期再现并不贴光学投影——事实与「先写真再自由」的预期相反
  - 不是手笨：夹脚趾临摹耳，仍与「两圆耳」原则不同
- 〔IMG_0089〕
  - 「好画」「不关心」「符号」都解释不了几何公式式的儿童画
  - 「画所知」里的知识，主要是视觉概念，不是口头抽象
  - 儿童心智绑在感官上；非知觉概念很难再译回形
- 〔IMG_0090〕
  - 触摸也不直接给空间——脑同样要合成；不能用来「救」视觉问题
  - 「概念艺术 / 知觉艺术」二分掩盖：清楚形对一切艺术都必需
  - 高度风格化作品里仍有知觉观察——斜线海不是纯符号
- 〔IMG_0091〕
  - 知觉从「类的结构」起步；早期画关心一般性，正合所见
  - 画不必复制一切所见；简单图案可满足孩子对「像样」的标准
  - 用圆表头是发明，不是从头上描下一个现成圆
- 〔IMG_0092〕
  - 再现概念就是视觉概念在媒介里的可做等价物
  - 艺术家特权是「用媒介抓住经验」；非艺术家常卡住说不出形
  - 认出对角线不等于能做；必须学会构成它的形式组件
- 〔IMG_0093〕
  - 早期简单公式是下一阶段的前提，不是须打碎的枷锁
  - 成熟艺术里再现概念仍在，只是更难一眼看出
  - 布里奇证明形式有机分化；但对象知觉的影响也不该抹掉
- 〔IMG_0094〕
  - 乱涂先是运动快感与可见痕迹，后才成再现
  - 描述性空中手势已接近把痕迹固定成画
  - 完成画看不出的画序、停顿，对孩子仍有再现意义
- 〔IMG_0095〕
  - 手作画是时间过程；完成作是同时整体——二者经验不同
  - 只看成品会漏掉画序与停顿里的组织
  - 生长就是再现概念逐步分化，不是从「错」改到「对」
- 〔IMG_0096〕
  - 放射覆盖一切方向，故整体仍未分化出「特定方向」
  - 已得图案会套到结构相应的多种对象——常以牺牲逼真为代价
  - 分化：从简单到复杂；也从不定到确定
- 〔IMG_0097〕
  - 未分化前：最简形代表该特征的全部可能性
  - 圆只有在与三角等对立时才真正意指「圆」
  - 理想阶段序列只是粗略对应；可跳、可合、可退回
- 〔IMG_0098〕
  - 年龄不等于绘画阶段；宜用结构标准评画
  - 直线对眼最简，对肌肉很难——却仍被早期艺术看重
  - 「火柴人」多是成人发明；孩子要保住物的实在感
- 〔IMG_0099〕
  - 早期的直不等于僵硬人格；须按分化律读
  - 直角先于斜向；菱形难于正方形
  - 竖直—水平先在孤立单元内练熟，再扩到整幅画面
- 〔IMG_0100〕
  - 框架先在零件里，后扩到整幅；整合后位置有「地址」
  - 竖直—水平像节拍：不显形也仍是参照
  - 斜向就是相对竖直—水平的受控偏离，不是早期乱方向
- 〔IMG_0101〕
  - 直角阶段的平伸臂不等于绝望；那是功能澄清。
  - 斜向让再现更活、更具体；须先过竖直—水平。
  - 勿过早教复杂形——讨好社会野心，害认知节奏。
- 〔IMG_0102〕
  - 复杂形要自己长到，不宜提前灌。
  - 早期：简单零件相加；眼已为整体做规划。
  - 后来：一条更分化的轮廓把零件融成一体。
- 〔IMG_0103〕
  - 连续轮廓增强运动感，也可能超出眼的控制。
  - 弯躯干是更高分化；缩短透视更少自发达到。
  - 相加零件与体内变形：语言、概念、科学、音乐里都有平行。
- 〔IMG_0104〕
  - 细分与融合交替上升，不是单向「越拼越碎」。
  - 先问「为何分化大小」，别先骂「大小错了」。
  - 对等对话要一般大；纯写实比例常破坏视觉关系。
- 〔IMG_0105〕
  - 大小差响应意义与清楚呈现，不响应机械比例。
  - 间距先用「标准空隙」；写实贴近往往难受。
  - 「蝌蚪人」并不是漏画躯干——下一页拆开两种类型。
- 〔IMG_0106〕
  - 蝌蚪人：圆常=头+躯，或竖线=躯+腿；并不是漏躯干。
  - 线可同时当轮廓又当对象本身——功能尚未分化。
  - 二维是无标记：深与扁起初用同一套手段。
- 〔IMG_0107〕
  - 「开肚子/透明房」常是二维媒介的逻辑，不是解剖兴趣。
  - 矩形轮廓可等价六个面；舞台「缺前墙」成人也接受。
  - 圆线可同时当环、盘、球——暧昧促使孩子很快放弃。
- 〔IMG_0108〕
  - 写实解法换来空间一贯，常丢掉早期的结构清楚。
  - 直立空间与水平空间各擅胜场，难在同一幅里两全。
  - 电影用时间先后「正当化」埃及式的等大与改角。
- 〔IMG_0109〕
  - 每一早期阶段有自身正当与美；跳步以后还得补爬。
  - 干预可能骗走孩子自己的发现；逼抽象与逼乱真同样有害。
  - 教什么，要看生长过程此刻呼唤什么——透视史是类比。
- 〔IMG_0110〕
  - 社会野心不可压过认知生长的节奏。
  - 视觉素养须贯串课程，不能只做艺术课孤岛。
  - 未分化形式不等于内向；认知与人格须一起看，不可互替。
- 〔IMG_0111〕
  - 分化原则也管色、舞台、建筑、雕塑——不只素描。
  - 有体积材料不等于已掌握三维组织。
  - 「原初球」代表一切紧凑物，尚未分形分向。
- 〔IMG_0112〕
  - 棍就是雕塑里的「直线」：物理三维，构思却常一维。
  - 须区分对象维（自身形）与空间维（占空间的图案）。
  - 分化路径：平面直角 → 多平面 → 斜与弯 → 粗细、板、立方。
- 〔IMG_0113〕
  - 二维对称图案最简落在平面；球面划脸常显任意。
  - 早期可「无脸」、切平面、或整人压扁。
  - 鼻乳等戳出正面；直角后再抹成有机形。
- 〔IMG_0114〕
  - 细分从划线进到贴条、角阶、凹腔，再融成连续浮雕。
  - 立方阶段就是四主视直角相会，一次只经营一个自足侧面。
  - 连续圆被拆成正面/侧面/背面等最简部分视。
- 〔IMG_0115〕
  - 立方四视各求完整；斜角「五腿」是误加算。
  - 真圆是晚期掌握，不是原初球已有的。
  - 巴洛克螺旋更复杂不等于更高；过早教复杂风格最危险。
