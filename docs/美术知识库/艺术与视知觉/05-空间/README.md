## 精录要点（摘自 @@要点）

### 五 · 空间

- 〔书页 218〕
  - 艺术家抓空间按分化逐步来：一维轨道 → 二维形向 → 三维自由
  - 正常知觉几乎做不到纯一维；线总相对周围空间被看见
  - 严格扁平的二维图像并不存在——对象与空的区分挥之不去
- 〔IMG_0117〕
  - 线有三种身份：对象线、排线（成面）、轮廓线（成边界）
  - 密平行排线可造曲面；雕塑与建筑里也有「线构面」
  - 闭环倾向被读成物的轮廓——两侧对称难稳住
- 〔IMG_0118〕
  - 轮廓内表面取简单律下最简可用形
  - 单元越大，轮廓越难「撑起」坚实；现代素描常故意松、轻
  - 大块平色易显空——老画留给天空，现代也用于实体
- 〔IMG_0119〕
  - 轮廓被一边独占时，基底在「下面」继续，才稳住
  - 两边都争边 → 轮廓争夺；弱刺激或儿童临摹常拆开接触
  - 同一物理轮廓，归属不同则形动力相反——杯与脸不可同见
- 〔IMG_0120〕
  - 轮廓归属翻转就是空满与主动被动翻转
  - 乱真加暧昧，可用来震醒对「现实」的迷信
  - 画上物/空与前后是组织结果；下节系统谈图形与基底
- 〔IMG_0121〕
  - 图底是正面平面系统最朴素的两层组织
  - 被围、较小、更密的肌理，都倾向当图形
  - 暧昧时因素对冲，接近多稳态——短暂可反转
- 〔IMG_0122〕
  - 下方、较亮、较红、更对称，都可加强「在前」
  - 凸易当图形，凹易当基底；注意点一移，结果可翻
  - 方位对齐竖直—水平框架，本身就是图底筹码
- 〔IMG_0123〕
  - 相对运动与立体视可澄清谁是图、谁是底
  - 经典「图与底」只是两层特例；更稳妥的说法是谈深度层
  - 省力原则：层数能少则少——穿孔常胜过多叠一层
- 〔IMG_0124〕
  - 经济、被围、亮度相似等，共同投票决定深度读法
  - 画家须用直接视觉因素，不能指望题材知识撑住深度
  - 故意反用因素，可把冲突做成表现
- 〔IMG_0125〕
  - 日常眼忽略背景；画家必须把间隙当可塑形
  - 负空间要有足够图形品质，关系才站得住
  - 画面空间是连续浮雕：层数、深浅、阶距皆可风格化
- 〔IMG_0126〕
  - 对象间距响应场里的吸引排斥，近似生物分支网络
  - 传统厚框像窗子：框为图，画世界为无边底
  - 德加式切边强调边界偶然——世界在框外仍延续
- 〔IMG_0127〕
  - 深度缩短后：画变图形，框收成细条或后斜
  - 窗洞悖论：小围区注定像图，却意在像洞——线脚帮墙「收边」
  - 现代幕墙反转：杆件为图，玻璃为空底
- 〔IMG_0128〕
  - 传统雕塑垄断凸与图形品质；间隙只是实体之间的空
  - 现代凹使空获得准实体密度，周围空间主动入侵
  - 凹让群像与建筑更可嵌合；凸则难真正组合
- 〔IMG_0129〕
  - 凹使群像榫合、使建筑内部空间成正图形
  - 深度分离是第三维上的再划分，服从简单性
  - 投影越统一越贴面；零件越独立越想在深度里离婚
- 〔IMG_0130〕
  - 第三维是自由大道：可为简化而分层，不改投影
  - 视网膜输入是二维；经验却非主要二维——须解释机制
  - 画必须自己提供深度证据；题材知识挡不住反证
- 〔IMG_0131〕
  - 切断比相触更强制：叠置服务于补全
  - 更简者吞并公共边界，邻居被迫在下延续
  - 交点连续轮廓规则很有用，但须放进整体结构看
- 〔IMG_0132〕
  - 交点规则有用，但整体简单形可反转局部预测
  - 重叠是深度队列的硬手段——古画与中国山水皆然
  - 重叠效果可压过真实前后距离
- 〔IMG_0133〕
  - 遮挡制造张力；早期构思常排队避开重叠
  - 物理透明不等于知觉透明；需三平面，且形状须叠置
  - 透明的形式条件先与叠置相同，颜色还要过第二关
- 〔IMG_0134〕
  - 透明由上下文诱导；窥视孔一挡就消失
  - 形要交叉再划分，色要像组合——两关都过才稳
  - 复调拆音与视觉拆色，是同一类结构强制
- 〔IMG_0135〕
  - 较小明度台阶让更近的那一色条保持完整在前
  - 形状本身可造微弱透明；衣褶与肢体是经典双系统
  - 透明专指有意透出；勿与早期二维内脏画混谈
- 〔IMG_0136〕
  - 透明不等于叠线或内外同显；那是别种再现契约
  - 深度还可靠倾斜与圆转体积，不只是前后排
  - 变形就是相对更简规范的偏离，制造张力，于是把形推进第三维
- 〔IMG_0137〕
  - 倾斜平行四边形读成后倾矩形：简单律自发抓取
  - 变形像若环境不支持，不会被看成正常投影
  - 形简单常胜过取向简单；立方体是三斜面交易的赢家
- 〔IMG_0138〕
  - 对称正面构型可压死立方读法
  - 等轴测用平行保客观属性，深度弱些却更可建造
  - 图画深度服从媒介条件，不是挡风玻璃式压扁
- 〔IMG_0139〕
  - 斜向是平面深度的基础变形，不是一切斜都有效
  - 反向透视常是误名：发散是早期手段，不是倒过来的中央透视
  - 发散为露侧面、保体积；收敛为藏侧面、强纵深
- 〔IMG_0140〕
  - 光学错误的正面加斜面立方，在媒介逻辑里仍正确可信
  - 正面直角像主音：让偏离可读、深度更稳
  - 放弃正面锚点，物体更自由漂浮，也更难正对观者
- 〔IMG_0141〕
  - 日式等轴测常让观者斜窥；人像却常保持正面迎视
  - 一切深度都是心智造的；生理线索并不是另一原理
  - 双眼与运动视差强推深度；扁画上它们反而揭穿扁平
- 〔IMG_0142〕
  - 扁画上去掉视差更深；全息保留真实视差
  - 恒常不是总看见物理真相，而是简单律的副产品
  - 投影被读成最简形——有时对物理错，对知觉对
- 〔IMG_0143〕
  - 物理斜向叠透视斜向，简单律读出更深的正规房间
  - 走进假深柱廊会晕：定向线索互相打架
  - 建筑与雕像也可用反向补偿，对抗透视缩短
- 〔IMG_0144〕
  - 艾姆斯：宁要怪身材的正规房间，不要正常身材的歪房间
  - 单眼窥视约等于只认投影；期望解释不够
  - 斜向是梯度；收敛再加大小梯度
- 〔IMG_0145〕
  - 梯度效力靠说清楚，不靠「像不像自然」
  - 膨胀圆盘多半被读成走近或走远，而不是变胖变瘦
  - 规则同质元素的梯度最干净；杂乱尺寸会搅浑
- 〔IMG_0146〕
  - 陡梯度更深；速率变→曲面；缺口→深度断裂
  - 前景远景大跳可保正面二元；密连续则斜退更顺
  - 大气透视有效，主要因梯度本身，不是「我们知道远处糊」
- 〔IMG_0147〕
  - 光晕式梯度、同形不同读法 → 可不造深度
  - 等轴测是斜退却恒距的带状世界，宜手卷不宜中心世界
  - 地方透视并置是过渡：旧统一已破，新统一未成
- 〔IMG_0148〕
  - 汇聚先局部、多灭点，后法典化为中央透视
  - 中央透视历史只出现一次：既最写实又最剧烈变形
  - 两根根：画内几何优雅 + 机械客观再现欲望
- 〔IMG_0149〕
  - 视觉金字塔加玻璃切片，就是机械投影理论
  - 暗箱到摄影：同一逻辑的技术加冕
  - 中央透视伴生机械忠实诱惑；意象仍靠精神创造保住
- 〔IMG_0150〕
  - 中央透视仍「能不变形就不变形」：竖线常保持平行
  - 广角凸轮廓因不可译成深度而不被画者采用
  - 「正确」站位点最深最稳；死盯侧灭点会挖塌构图平衡
- 〔IMG_0151〕
  - 远近比较时，「看得准」不等于永远看见物理等大
  - 大小与距离互相定义：后像投远就变大
  - 金字塔空间：又收敛又平行、又不等又相等——相对框架成立
- 〔IMG_0152〕
  - 恒常的是相对框架的尺度，不是绝对尺寸
  - 近处正面是「牛顿绿洲」；走进透视系统才能「又等又不等」
  - 孤立形可诱导整片周围空间——简单律自动选最简设置
- 〔IMG_0153〕
  - 框架冲突三角：设置赢 / 物体赢 / 裂成两套空间
  - 收敛压缩是渐进高潮，巴洛克与短焦爱用
  - 塞尚等常压低后退线，要稳浮雕而非漏斗兴奋
- 〔IMG_0154〕
  - 扁画与等轴测把观者挡在外；中央透视漏斗向观者张开
  - 灭点既是观者位置反射，也是画内世界顶点
  - 中心灭点适合等级庄严；偏心灭点适合戏剧冲突
- 〔IMG_0155〕
  - 偏心透视 = 个体中心挑战整体之法
  - 三中心：画布中心 / 透视焦点 / 故事中心可互相对抗
  - 中央透视第一次让画「说出」无穷：可触灭点等于无限远处
