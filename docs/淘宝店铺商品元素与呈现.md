## 2. 在线写生台 / 在线画室（原「学写生」纠正）

### 对外分区名（草案）

首页分区主称：**在线写生台**（已钉）。「在线画室」可作详情里的别称，不抢主称。

**不要叫**「学写生」——易被理解成笼统课程，说不清「进场景练」的价值。

### 两个商品

| 编号 | 对内 | 对外短名（草案） |
|------|------|------------------|
| **P1** | 静物写生台 | 几何体静物「写生台」 |
| **P2** | 肖像写生台 | 人物肖像「写生台」 |

### 核心优势（站长口述 → 润色稿，详情/官网可复用）

**你要用户记住的事：**

不是买一节课听完，而是**进入一个线上、逼真的写生场景里动手练**——不必自己买模型、布景布光，也不必赶到画室，就能在可控、甚至优于常见画室光线的环境里观察形体与光影。

**润色版（详情可用段落）**

> **在线写生台**：把画室搬到网页里。  
> 场景里有可写生的对象与空间，你可随时转视角、调灯光与氛围，把形体转折和明暗交界看得更清楚。  
> 不必自备石膏或静物、不必布置灯光，也不必出门占画室——在理想光线条件下练观察、练落幅。  
> 适合想认真写生、又受场地与设备限制的学员。

**更短卖点条（主图角标 / 楼层副文）**

- 不用买模型、不用布光  
- 视角 · 灯光 · 氛围可调  
- 看清形体与光影特征  
- 不出门，也有理想写生环境  

（站内模块名已统一为「静物写生台 / 肖像写生台」；对外叙事可用「在线写生台 / 在线画室」。）

## 3. 手绘工坊 Pro（原「系统学」纠正）

### 对外怎么说

分区/入口宜用：**高级会员 Pro · 按时长**，**不要用「系统学」**，**不要写「全站打包」**（土且不具体）。

### 卡面 / 首页短句（2026-11-07 定稿）

**写生台 + 三工具 + 课件库（非视频课）**

较长说明见 `docs/手绘工坊_对外卖点文案库.md` §3。

### Pro 实际包含

1. **在线写生台**（几何静物、人物肖像等，以官网说明为准）  
2. **画室工具**：晓阶、晓色、晓摹  
3. **课件库**（可交互 3D 场景课件，**非视频课**）  

### 详情页再展开（待写进商品详情，首页不堆）

几何体光影、色彩、氛围、构图、解剖、头像结构、造型规律等 3D 场景课件主题。

### 硬性排除 / 防误会

对外优先写 **非视频课**（避免被当成录播网课）。水彩人像等录播另售 / 预告，不塞进 Pro 首页短句。

### 与单买

- 写生台、三工具可单买「长期可用」  
- Pro = **按时长**的会员权益；到期后未单买部分按规则恢复  
- 录播课走 P7，与 Pro 分开讲
