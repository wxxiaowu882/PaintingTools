# 构图教学体系：构图通法 · 舞台叙事主课

## 前言：这一版到底要解决什么问题

构图主课不再拆成几十个细碎单点，而是做成一条**能记住的舞台故事**。

我们要同时做到两件事：

1. **让学员听得懂、记得住**：用舞台表演与观众感受，把抽象构图讲成有血有肉的戏。
2. **让场景做得出、验得清**：九大几何体场景就是构图主课；每一场只认一个教学核。

**学员请先读第一章「知识地图」**，再读九大场景。不先立地图，后面的差异、秩序、四大秩序就容易看成一堆并列名词。

全文结构：

| 段 | 内容 | 作用 |
| --- | --- | --- |
| **通法篇** | 知识地图 + 九大舞台几何体场景 | 把构图底层讲透 |
| **应用篇** | 经典构图例子（S / V / 三角 / 天地分界等） | 用通法拆行业老配方 |

全文唯一总纲：

> **差异负责造起伏，章法秩序负责定品相；基底统一保成立，章法秩序保高级。**

更好记的人话：

> **没有差异，画面会平；没有章法秩序，画面会乱。高级构图不是「没冲突」，而是「冲突被章法驯服」。**

## 一、知识地图：构图要达成的两个层级

### 1.0 总图：先知道自己在学什么

构图课真正要教学员做到的，不是先背很多名词，而是先达成**两个层级**：

| 层级 | 名称 | 回答什么问题 | 解决什么毛病 |
| --- | --- | --- | --- |
| **第一层** | **基底统一** | 这幅画是不是在同一个世界里？ | 假、碎、裂、穿帮 |
| **第二层** | **章法秩序** | 这幅画有没有品相、有没有章法？ | 乱、俗、散、无主题 |

一句话记：

> **先让世界成立，再让世界好看。**

下面所有概念，都挂在这张地图上，不再另起炉灶：

```text
构图知识体系
│
├─ 第一层目标：基底统一（让画面成立）
│   └─ 光源 / 透视 / 地面 / 氛围 逻辑统一
│
├─ 第二层目标：章法秩序（让画面高级）
│   └─ 由四大秩序落实：主次 → 平衡 → 节奏 → 律动
│
├─ 第二层里的运作机制
│   ├─ 差异：画面起伏的来源（造险、造看点）
│   └─ 章法秩序：差异的总管法（不让画面翻）
│
├─ 通法篇实训（第二节）
│   └─ 九大舞台几何体场景：从乱到成，再从成到僵
│
└─ 应用篇（第三节）
    └─ 经典构图例子：用通法拆 S / V / 三角 / 天地分界等
```

**概念归属表**（后文一律照此理解）：

| 概念 | 在体系中的位置 | 它是什么 | 它不是什么 |
| --- | --- | --- | --- |
| **基底统一** | 第一层目标 | 画面成立的物理底线 | 不是审美高级 |
| **章法秩序** | 第二层目标 | 差异的总管法、品相保障 | 不是物理统一 |
| **差异** | 第二层里的运作燃料 | 让画面不平、不呆、有看点 | 不是与两层并列的第三层 |
| **四大秩序** | 第二层目标的四个落实抓手 | 章法秩序的具体展开 | 不是新的独立层级 |
| **九大场景** | 通法篇主课 | 把上面逻辑演成连续剧 | 不是平行理论 |
| **经典构图例子** | 应用篇 | 行业老配方的印证 | 不是另立门派 |

---

### 1.1 第一层：基底统一

**作用**：让构图**先成立**。这是所有课的**前置前提**。

它回答：

- 光源是不是一套逻辑？
- 透视是不是成立？
- 地面、空间、氛围是不是同一个世界？

具体包括：光源逻辑统一、透视空间统一、地面与环境基调统一、大气氛围统一。

**它解决的是**：画面碎、假、裂、穿帮。  
**它不解决的是**：好不好看、有没有主角、有没有品相。

舞台比喻：舞台还没搭好、灯光乱跳、演员站在不同空间里——戏还没法看。

验收只问一句：

> **这些变化，是不是发生在同一个世界里？**

---

### 1.2 第二层：章法秩序

**作用**：让构图**从成立走向高级**。这是构图课的**审美中枢**。

它回答：有没有主角？有没有压秤？变化有没有顺序？全体是不是一股气？

**它解决的是**：乱、俗、散、无主题、有变化但没品相。  
**它不负责**：让画面物理上成立——那是第一层的事。

舞台比喻：舞台搭好了，但全员抢戏、阵容要倒、节奏乱跳、演员各演各的——戏能看，但不好看。

**四大秩序**不是和「两层」并列的第三层，而是**第二层目标「章法秩序」的四个落实问题**：

1. **主次秩序**：谁是主角？
2. **平衡秩序**：有没有倒？
3. **节奏秩序**：变化有没有顺序？
4. **律动秩序**：全体是不是一股气？

```text
第二层：章法秩序
    ├─ 主次秩序
    ├─ 平衡秩序
    ├─ 节奏秩序
    └─ 律动秩序
```

后文凡写「秩序」，如无特别说明，**均指「章法秩序」**。

---

### 1.3 第二层怎么运作：差异与章法秩序

第一层搞定之后，画面还要**活起来**，又不能**翻掉**。第二层靠两件事配合：

#### 差异

差异是画面「活起来」的来源，对应舞台里的反差、起伏、造险、冲突、看点。

它**不是新的层级**，而是第二层里的**运作燃料**——在基底统一之上，引入可控变化。

三类差异工具：

- **形态差异**：大小、体量、方圆、曲直、欹正、长短
- **位置差异**：疏密、聚散、高低、藏露、走势、顾盼
- **光影色彩差异**：明暗、虚实、浓淡、素艳、冷暖、强弱

它解决：画面太平、太呆、没有记忆点。

#### 章法秩序

章法秩序是差异的**总管法**，不是另一种差异。它解决：画面太乱、太吵、有变化但没品相。

运作流程：

```text
基底统一（先成立）
    ↓
在统一世界里引入差异（让画面活）
    ↓
用章法秩序管住差异（让画面高级）
    ↓
四大秩序逐项落实（主次 → 平衡 → 节奏 → 律动）
```

> **差异让画面不平，章法秩序让画面不翻。**

---

### 1.4 四大秩序：分工与判尺

#### 主次秩序

**一句话**：先回答「谁是主角」。画面必须有唯一视觉主峰；其余元素都要服务它；主不一定最大，但必须最明确。

**舞台比喻**：一台戏不能全员抢戏。  
**验收**：学员第一眼落在哪里？其他元素有没有主动衬托它？

#### 平衡秩序

**一句话**：再回答「这幅画有没有倒」。不追求死板对称，追求动态压秤；一边造险，另一边要能托住。

**舞台比喻**：阵容可以偏，但不能塌。  
**验收**：哪一边在施压？哪一边在压秤？

#### 节奏秩序

**一句话**：再回答「变化有没有顺序」。有起伏、有递进、有松紧；不平铺，也不乱跳。

**舞台比喻**：不是全场一个拍子，也不是乱拍子。  
**验收**：大小、疏密、明暗变化，能不能顺着读下去？  
**判尺**：节奏看「变化有没有顺序」——递进、过渡、张弛、起伏。

#### 律动秩序

**一句话**：最后回答「全体是不是一股气」。物体不能孤立；走势要互相呼应；小组能抱团，整体能成势。

**舞台比喻**：不是各演各的，而是整台戏同气联动。  
**验收**：个体之间有没有呼应？整体是不是朝同一个气场在走？  
**判尺**：律动看「个体有没有关系」——呼应、走势、联动、抱团、气脉。

#### 四大秩序的推进顺序

1. **主次**：先定核心  
2. **平衡**：再定不翻  
3. **节奏**：再定不板  
4. **律动**：最后定不散  

后面九大场景按这个顺序推进，**每场只认一个核心进步**，不四项平均讲。

---

### 1.5 学习流动脉络

| 步骤 | 学什么 | 带走什么 |
| --- | --- | --- |
| **0** | 构图要达成两层 | 先成立，再高级 |
| **1** | 第一层：基底统一 | 没有统一，后面都谈不上 |
| **2** | 第二层：章法秩序 | 没有章法，画面会乱、会俗 |
| **3** | 差异 + 章法秩序 | 差异让画面活，章法秩序让画面稳 |
| **4** | 四大秩序 | 主角、压秤、顺序、联动 |
| **5** | 九大舞台场景（通法篇） | 从乱到成，再从成到僵；每场用「三方对照」把层级钉死 |
| **6** | 经典构图例子（应用篇） | 用通法拆行业老配方 |

**故事线主轴**：

> **先立主角，再整队形，再拉反差，再驯冲突。**

展开为：

1. 先看废图为什么废：没有基底统一，也没有章法秩序  
2. 先立主次：让画面有唯一观看核心  
3. 再稳全局：让周边站好队、别抢戏  
4. 再引入差异：让画面不平庸  
5. 最后讲高阶对立统一：让张力和稳态共存  

九大场景不是九个平行名词，而是：

> **一条从乱到成，再从成到僵的完整教学线。**

## 二、通法篇 · 九大舞台几何体场景

### 2.0 使用说明

这九个场景就是**构图主课本体**：每个都是可生产的几何体场景，用舞台戏把道理钉进记忆。

- **场景 1～6**：第一层、第二层逐步落地，解决「乱、平、无主题、无张力」
- **场景 7～9**：第二层仍在，但差异被削弱，解决「稳了但僵、规整却无魂」

每场固定五块：

1. **舞台剧情**（有情绪）
2. **观众感受**（心里发生了什么）
3. **几何体怎么摆**（中文形体名；一眼能悟）
4. **三方对照**（构图层级 ↔ 舞台 ↔ 几何体；用「就像……」把条件讲透，只对照本场该落地的那一两层）
5. **本场只带走一句**

**关于标注**：下文「场景总说明」可写较长。产品侧如何展示（说明幕 / 标注展开收起）**后定**；生产时暂可将长文放入场景总说明。

| 场景 | 对应层级 / 秩序 | 本场唯一教学点 |
| --- | --- | --- |
| 一 | 两层皆缺 | 坏图 = 无统一 + 无章法 |
| 二 | 主次秩序起步 | 谁是主角？ |
| 三 | 主次完成 + 平衡起步 | 配角主动衬托 |
| 四 | 差异 + 四大秩序成型 | 统一基调下的精准反差 |
| 五 | 差异造险 | 造险须守住主次与平衡 |
| 六 | 第二层圆满 | 驯服冲突，不是消灭冲突 |
| 七 | 差异减弱 | 工整但不生动 |
| 八 | 节奏、律动崩塌 | 平均化是僵化元凶 |
| 九 | 差异几近归零 | 完全抹平则画面死 |

场景编号：**待定**（生产时再编入课程环）。统一用画框 + 推荐视角；光/气沿用氛围段已学默认，**只改框内摆法**。

---

### 场景一：无序乱演

**场景标题（草案）**：【构图】无序乱演 · 全员无主

#### 舞台剧情

舞台没有剧本，也没有主角。一群演员东一撮、西一撮，谁也不让谁；有人面向观众，有人背对观众，有人蹲着、有人倒立似的歪着；灯光这边闪一下、那边跳一下，没有主光，没有焦点。整台戏像临时拼凑的嘈杂集市——热闹，却没有戏。

#### 观众感受

眼睛被四处拽着跑，脑子忙着「找重点」，却怎么也找不着。越看越烦，越看越累，最后只想离场。这不是「内容太多」，而是**根本不知道该看谁**。

#### 几何体怎么摆

- **形体**：球体、立方体、圆柱、圆锥、棱柱，混用 8～12 个，大小、朝向尽量乱。
- **摆法**：满框乱撒，互不呼应；有的斜躺、有的倒扣感（圆锥尖朝旁）、有的挤成一团、有的孤零零贴边。
- **光与色**：故意破坏「同一世界」——局部过亮、局部过暗，色相杂乱跳变（可多色固有色硬拼），让人一眼觉得「不像同一台戏」。
- **画框**：取景框入镜；推荐视角略俯，把「乱」看全。

**顿悟点**：学员应觉得「这哪是构图，这是事故现场」。

#### 三方对照（本场：两层皆缺）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **基底统一**（未达成） | 灯光乱闪、演员像不在同一台戏 | 主光不统一、色相硬拼、透视/地面气场割裂 |
| **章法秩序**（未达成） | 无主角、无队形、无人调度 | 无最高最亮者、朝向互不理睬、疏密乱跳 |
| **差异**（失控） | 每个人都在「抢不一样」 | 大小朝向乱变，却没有人管 |

> **就像**集市里人人喊话、灯却东闪西灭——不是花样太多，而是**既不在同一个世界，也没人排戏**。几何体场景把这件事直接摆到眼前。

#### 本场只带走一句

> **坏构图不是「差异太多」，而是「差异没有统一、也没有章法」。**

#### 场景总说明（可贴入场景，可较长）

今晚的舞台彻底失控了：没有主角，没有队形，没有统一灯光。演员各演各的，几何体也各歪各的。你心里烦，是因为画面既不在同一个世界里，也没有任何章法——**乱，不是因为有变化，而是因为变化没人管。** 对照第一章：第一层、第二层这里都没站住。

### 场景二：先立主角

**场景标题（草案）**：【构图】先立主角 · 单点破局

#### 舞台剧情

嘈杂还没散尽，忽然有人走到舞台偏中心，挺直身姿、拔高身形；一束聚光灯追上来，只照亮他。周围演员还在乱动，但他已经成了全场唯一能「站住」的人——戏，从这一刻开始有了主线。

#### 观众感受

终于有地方可以落眼了。心里松一口气：「原来该看他。」但余光仍被周边吵闹干扰，还不够干净。

#### 几何体怎么摆

- **主角**：一枚**高大圆柱**（或竖立长方体），体量明显大于周围；放在画框中心略偏，竖向最高。
- **配角群**：保留场景一式的小球体、小立方体、小圆锥 5～7 个，仍可略乱，但**体量一律更小、更矮**。
- **光**：主光对准高大圆柱，使其最亮、最清楚；周边形体偏暗、偏灰。
- **其余**：光源方向与地面逻辑开始统一（恢复第一层的「同一世界」），但周边站位仍可散乱。

**顿悟点**：乱局里只要出现「唯一最清楚、最高、最亮」的那一个，眼就会过去。

#### 三方对照（本场：先立主次）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **基底统一**（开始成立） | 灯光系统回到同一套，不再乱闪 | 同一主光方向、同一地面世界 |
| **主次秩序**（本场核心） | 一束追光打在唯一主角身上 | 高大圆柱最高、最亮、最清楚 |
| **平衡 / 节奏 / 律动** | 周边仍可吵，本场先不管 | 小形仍可略乱——故意留给后面 |

> **就像**嘈杂里忽然有人被追光钉住——眼立刻有了落点。几何体里那根最高最亮的圆柱，就是在满足 **主次秩序**：先让观众知道该看谁。

#### 本场只带走一句

> **构图第一步：先让观众知道——谁是主角。**

#### 场景总说明

混乱里忽然有人被聚光灯打中。你终于知道该看谁了。构图也一样：**先立主角**，主题才有落点。这一场不要求全局完美——周边还可以吵，但主角必须唯一。**就像**排戏：先定主演，再整队形。

### 场景三：配角归位

**场景标题（草案）**：【构图】配角归位 · 层级规整

#### 舞台剧情

配角们忽然懂事了。他们主动退到两侧与后方，放低身姿，统一朝向中心那位主角；不再抢戏，只做陪衬。舞台从「一人出头、四周仍乱」变成「中心高、四周低，中心聚、四周疏」——像正式演出终于排好了站位。

#### 观众感受

主题清楚了，心里踏实了。不用再费劲「从噪音里捞重点」，一眼就能读完这台戏在讲谁。

#### 几何体怎么摆

- **保留**：场景二的高大圆柱作主角，主光仍打在它身上。
- **配角**：两侧与后方摆 4～6 个较矮的球体、立方体、短圆柱；体量约为主角的 1/3～1/2。
- **站位**：左右略对称托住，中心前方留气；配角朝向微微「顾盼」主角（如圆锥尖、棱柱长边朝向主角）。
- **光**：配角整体更暗、更素，不抢高光。

**顿悟点**：主次不是把主角单独放大，而是**所有次要因素主动服务主角**。

#### 三方对照（本场：主次完成 + 平衡起步）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **主次秩序**（完成） | 配角退位、放低、朝向主演 | 矮形分列两侧后方，主光仍在高圆柱 |
| **平衡秩序**（起步） | 左右站位托住，阵容不塌 | 左右分量大致压秤，中心前方留气 |
| **律动**（萌芽） | 群演眼神、朝向顾盼主角 | 锥尖、棱边微微朝向主角 |

> **就像**正式演出终于排好站位：不是主演一个人喊，而是全员知道自己站哪。几何体里配角变矮、变暗、让出中心——这就是 **主次完成**；左右托住不倒，就是 **平衡起步**。

#### 本场只带走一句

> **主次的完成，靠的是配角主动让位，不是主角一个人喊话。**

#### 场景总说明

配角终于知道自己不是主角：退位、让位、衬托。画面开始「不倒」——因为周边站好了队。记住：**主次不是孤立主体，而是全域归宗。** **就像**舞台调度：戏好不好看，一半在主演，一半在配角肯不肯让。

---

### 场景四：差异开始好看

**场景标题（草案）**：【构图】差异好看 · 精准反差

#### 舞台剧情

站位对了，还不够好看。主角开始「出彩」：身姿更舒展、妆造更鲜明、灯光更利落；配角统一素淡、体态收敛，动作慢半拍。全场仍是同一台戏、同一灯光系统，只是**气质差**拉开了——从「合格演出」变成「有品相的演出」。

#### 观众感受

不只是看得懂，还开始觉得耐看：有层次、有呼吸、有记忆点。像看一场用心排过的正式戏。

#### 几何体怎么摆

- **主角**：修长圆柱或高锥，固有色略艳、略亮；轮廓最清楚。
- **配角**：统一矮胖球体/短圆柱，固有色降低饱和（灰、米、浅褐），体量更小。
- **节奏**：前中后略有大小递进；疏密有「中心略聚、外侧略疏」。
- **律动**：配角朝向、边缘走势统一指向主角；地面基准一致。
- **基底**：全场同一主光、同一色温基调——反差发生在统一世界里。

**顿悟点**：好看的差异，是**统一基调下的精准反差**，不是乱加花样。

#### 三方对照（本场：差异在统一里变好看）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **基底统一**（守住） | 同一台戏、同一灯光系统 | 同一主光、同一色温基调 |
| **差异**（本场核心） | 主演更出彩，配角更素淡 | 主角略艳略亮修长；配角灰矮胖 |
| **节奏秩序** | 快慢高低有起伏，不齐步走 | 大小、疏密有递进，不平铺 |
| **律动秩序** | 全员气场朝向同一中心 | 走势、朝向抱团指向主角 |

> **就像**同一场戏里，妆造与体态拉开气质差——仍是一台戏，却忽然有了品相。几何体里艳与灰、高与矮的反差，必须发生在**统一世界**里，这才叫可控差异，不是乱加戏。

#### 本场只带走一句

> **差异不是乱差，而是统一世界里的精准反差。**

#### 场景总说明

主角与配角不只站对位置，还拉开了气质、体态与光感。你开始觉得「有品相了」。这一场告诉你：**从合格到好看，靠的是可控差异，不是堆更多东西。** **就像**好戏不怕有反差，怕的是反差不在同一套灯光里。

---

### 场景五：冲突入局

**场景标题（草案）**：【构图】冲突入局 · 造险起伏

#### 舞台剧情

正戏演得平稳时，一股「反派」忽然入场：站位更聚、姿态更硬、颜色更冲，和主角阵营形成对峙。剧情陡然有了悬念——像两个阵营在舞台两侧拉扯，观众心里跟着紧起来。但主角仍是主角，戏没有散成群架。

#### 观众感受

被吸住了：有险、有拉扯、有期待。不再平淡，却还不至于烦——因为你心里仍知道「该站哪一边看戏」。

#### 几何体怎么摆

- **正派阵营**：延续场景四——高大圆柱主角 + 素淡配角，偏画面一侧（如左中）。
- **反派阵营**：新增 3～4 个形体（棱柱、斜置圆柱、尖锥），**补色或强对比固有色**（如暖主角对冷反派，或灰场对一抹刺眼饱和色），集中在对侧空白区，形成疏密与色相的对冲。
- **守底**：主角仍最高、最清楚、主光仍在主角；反派可强，但**不能比主角更抢眼**（体量或亮度略让）。
- **动势**：反派可略斜、略聚，制造不稳定感；正派相对更稳。

**顿悟点**：可以主动造险，但造险时**主次与平衡不能丢**。

#### 三方对照（本场：造险，但守章法）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **差异 · 造险**（本场核心） | 反派入场，姿态硬、颜色冲 | 对侧补色/斜势聚团，形成拉扯 |
| **主次秩序**（必须守住） | 悬念再大，主演仍是主演 | 主角仍最高最亮；反派不得更抢眼 |
| **平衡秩序**（必须守住） | 两边对峙，阵容不塌成群架 | 左右有对冲，但全框仍能压秤 |
| **≠ 场景一的乱** | 有剧本的冲突，不是无调度的嘈杂 | 冲突在统一世界里，不是光色穿帮 |

> **就像**正戏里忽然杀进一股对峙势力——心会紧，但你仍知道该看谁。几何体里对侧那一团冲色斜形，是在造险；主角光不让、分量不倒，就是章法在守底。

#### 本场只带走一句

> **差异可以造险，但造险必须守住主角与压秤。**

#### 场景总说明

冲突入局，画面有了张力。你开始有悬念，却仍知道主角是谁。构图要摆脱平庸，就得敢造险；但**险必须可控**——否则又退回场景一的乱。**就像**好戏的冲突是导演安排的，不是后台电线走火。

---

### 场景六：对立统一

**场景标题（草案）**：【构图】对立统一 · 驯服冲突

#### 舞台剧情

终场不是「打倒反派、清空舞台」，而是把对抗**驯服成互补**：两股势力互相穿插，你中有我、我中有你；刺眼的冲突被收进有呼吸的起伏里。主角仍在，戏更完整——像高潮之后的圆满收束，观众心里既过瘾又踏实。

#### 观众感受

既觉得有戏，又觉得稳；既丰富，又不低俗。情绪释放完，愿意再看一眼——这就是「高级」的感觉。

#### 几何体怎么摆

- **在场景五基础上微调**：降低反派色的刺眼纯度，使冷暖/补色**和谐兼容**但仍可辨。
- **穿插**：把 1～2 个反派小形插入正派疏区，把 1 个正派小形点到反派侧，形成「强弱强弱」的起伏，而不是左右硬切两半。
- **秩序自检**：主角仍一眼可辨；全框不倒；大小疏密能顺着读；朝向与走势仍抱团指向主气场。
- **差异仍在**：不要抹平冲突，只是把冲突编进章法。

**顿悟点**：高级不是没冲突，而是**冲突被驯服**。

#### 三方对照（本场：第二层圆满）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **主次** | 高潮后主演仍在中心 | 主角一眼可辨 |
| **平衡** | 对抗化作互补，阵容不翻 | 穿插后全框仍稳 |
| **节奏** | 强弱起伏有呼吸 | 「强弱强弱」可读，不硬切两半 |
| **律动** | 两股势力同气收束 | 走势抱团，指向同一气场 |
| **差异仍在** | 冲突没被删掉，被编进戏里 | 冷暖/疏密仍在，只是不再刺眼失控 |

> **就像**终场不是清空反派，而是把对抗收进圆满的戏——过瘾，又踏实。几何体里降低刺眼、互相穿插，就是在用章法**驯服**差异：有险而不乱，有变而不散。

#### 本场只带走一句

> **高级构图不是消除冲突，而是驯服冲突——有险而不乱，有变而不散。**

#### 场景总说明

冲突没有被抹掉，而是被收进章法里。你既觉得过瘾，又觉得稳。请记住通法篇的终点：**以差异造起伏，以章法定品相。** **就像**最好的舞台不是没有对手，而是对手也成了戏的一部分。

---

### 场景七：活力开始消退

**场景标题（草案）**：【构图】活力消退 · 工整不生动

#### 舞台剧情

戏还没垮。演员仍在，站位仍对，主角也还在——但所有人忽然「收情绪」了：反差变弱，动作变齐，灯光变平。像一台还在演、却开始念稿的戏，规规矩矩，却没味道。

#### 观众感受

不烦，但也不想多看。心里说：「挺整齐的……然后呢？」

#### 几何体怎么摆

- **从场景六退化**：保留主次与大致平衡；抹平补色强对比，全域色相、纯度靠拢。
- **光**：明暗层级变弱，接近均匀。
- **疏密**：穿插起伏减少，聚散变温和。
- **仍保留**：主角略大、略清楚——秩序框架还在，只是「没劲了」。

**顿悟点**：「不乱」不等于「高级」。

#### 三方对照（本场：秩序在，差异睡了）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **章法秩序**（框架还在） | 站位还对，主演还在 | 主角略大略清楚，大体不倒 |
| **差异**（本场问题） | 情绪收了，反差没了，开始念稿 | 补色抹平、明暗变匀、聚散变温和 |
| **节奏 / 律动**（变弱） | 动作越来越齐，气场变平 | 起伏减少，呼吸变浅 |

> **就像**戏还在演，却开始念稿——规规矩矩，没味道。几何体里秩序架子还在，但对比睡着了：这提醒你，**第二层要靠差异供能**；光有章法、没有起伏，只会温吞。

#### 本场只带走一句

> **工整但不生动：秩序还在，差异开始睡着了。**

#### 场景总说明

戏没垮，但开始没味道。你不烦，却也不想多看。记住：**少了适度反差，画面会温吞——不乱，也不高级。** **就像**乐队还在，但所有人都改成同一个音量。

---

### 场景八：全局平均

**场景标题（草案）**：【构图】全局平均 · 只剩整齐

#### 舞台剧情

演员们越来越像复印出来的：身高、动作、站距几乎一样；灯光均匀铺满；没有聚散，没有高低错落。舞台像机械列队——严肃、整齐，却没有表演。

#### 观众感受

规整，但僵。视线匀速滑过，无处停留，也无处起伏。

#### 几何体怎么摆

- **形体**：6～8 个**同尺寸球体**（或同尺寸立方体），等距平铺成栅格或横排。
- **朝向**：一致，无顾盼。
- **光色**：全域均匀，无主光焦点，无冷暖/艳灰差。
- **主角**：几乎消失，仅位置上略偏中心也不再强调。

**顿悟点**：平均化，是僵化的元凶。

#### 三方对照（本场：节奏与律动崩塌）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **差异**（大幅抹平） | 演员像复印出来的 | 同尺寸形体等距平铺 |
| **节奏秩序**（崩） | 无快慢高低，齐步走 | 无大小疏密递进，栅格感 |
| **律动秩序**（崩） | 无顾盼、无互动 | 朝向一致，互不牵引 |
| **主次**（几乎消失） | 没有人真正出彩 | 无主光焦点，中心也不再强调 |

> **就像**机械列队：严肃、整齐，却没有表演。几何体栅格把「平均化」拍在脸上——**节奏与律动一死，画面就从戏变成队列。**

#### 本场只带走一句

> **平均化，是构图僵化的元凶。**

#### 场景总说明

所有人都太像，所有节奏都被抹平。只剩整齐。节奏断了，律动也断了——画面从「艺术」滑向「队列」。**就像**检阅方阵可以整齐，但那不是一台戏要的章法。

---

### 场景九：全域死寂

**场景标题（草案）**：【构图】全域死寂 · 静止布景

#### 舞台剧情

舞台不再是表演，只剩布景。所有人姿态、站位、妆造百分之百同一；无中心、无互动、无起伏。灯光死寂均匀。时间像停住了——不是安静的美，是无声的空。

#### 观众感受

没有烦躁，也完全无感。大脑既不用整理，也得不到任何审美回馈。

#### 几何体怎么摆

- **极致平均**：全部相同球体（或全部相同立方体），绝对等距、绝对同高、绝对同色、同亮度。
- **无主次、无疏密、无朝向变化、无明暗层次。**
- **对比记忆**：可与场景六并置回想——同一「几何体世界」，一个活，一个死。

**顿悟点**：完全抹平主次、起伏与联动，画面就会死。

#### 三方对照（本场：差异归零，秩序空壳）

| 构图要满足的条件 | 舞台上像什么 | 几何体里看见什么 |
| --- | --- | --- |
| **差异**（几近归零） | 不再是表演，只剩布景 | 全同形体、全同色、全同距 |
| **主次 / 平衡 / 节奏 / 律动** | 无中心、无起伏、无互动 | 四问卡全答不上 |
| **对照场景六** | 同一舞台世界，一个活一个死 | 回想场景六的穿插与驯服——反差何在 |

> **就像**时间停住的空布景：不烦，也无感。几何体把「抹平一切」推到极端——不是统一高级了，而是**主次、起伏、联动都被删光，灵魂就没了。**

#### 本场只带走一句

> **完全抹平主次、起伏与联动，画面就会死。**

（不说「无差异不成构图」这种绝对话，避免被反例击穿。）

#### 场景总说明

不再是表演，而是静止布景。你没有烦躁，却也完全无感。通法篇的反面终点在此：**不是「统一就高级」，而是「把一切抹平，灵魂就没了」。** **就像**关掉所有戏的开关，只留下空台——第一层也许还「成立」，第二层已经空了。

## 三、应用篇 · 经典构图例子（骨架）

通法篇走完，学员应能用**四问卡**读任何画面：

1. **主角是谁？**（主次）  
2. **有没有倒？**（平衡）  
3. **变化有没有顺序？**（节奏）  
4. **整体是不是一股气？**（律动）  

应用篇的任务：**不另立门派**。S 形、V 形、天地分界等，都是行业积累的「老配方」——我们用通法去拆，而不是重新背一套名词。

### 3.1 用法

每个经典例子只做三件事：

1. 用几何体摆出该「老配方」的典型样子  
2. 用四问卡走一遍  
3. 点明：它在通法里主要碰了哪一类差异、守住了哪一层秩序  

### 3.2 预列目录（摆法后写）

| 例子 | 常见观感 | 用通法怎么读（草案） |
| --- | --- | --- |
| **S 形** | 眼沿弯路走 | 曲直差异造势；弯心/终点常落主题；要有直边或稳形托住 |
| **V 形** | 眼向交汇处收 | 疏密与动势向 V 口聚；口上要留气，防闷 |
| **X 形** | 两势交叉最尖 | 动势对冲；交叉点常是焦点；交叉外要压秤 |
| **L 形** | 边重中空 | 边角密、中疏；角上主体须偏而不倒 |
| **三角** | 正三角偏稳，倒三角偏险 | 稳与险（动势）对举；择一造势，对极托住 |
| **天地分界 · 天少地多** | 地平线偏上 | 高与低：下重上轻，上区要透气 |
| **天地分界 · 天多地少** | 地平线偏下 | 高与低：上开下要压住，防空散 |
| **线与线交锋** | 横竖交汇 | 偏与正 + 高与低；力量点在交锋处 |

> **本节目前只列骨架与用法，几何体摆法与场景总说明下一步再写满。**

## 五、全篇最短结论

### 5.1 三层记忆（学员版）

1. **构图先要做到两层：先成立，再高级。**  
2. **差异让画面活，章法秩序让画面稳。**  
3. **四大秩序就是章法秩序的四个落实问题：主角、压秤、顺序、联动。**

### 5.2 一条故事主线

> **先立主角，再整队形，再拉反差，再驯冲突。**

### 5.3 一条判尺（四问卡）

1. **主角是谁？**  
2. **有没有倒？**  
3. **变化有没有顺序？**  
4. **整体是不是一股气？**

### 5.4 终极金句

> **差异让画面不平，章法秩序让画面不翻；基底统一保成立，章法秩序保高级。**

> **少一分起伏会平，多一分失控会乱；有变有序，有险有衡，才是构图正道。**
