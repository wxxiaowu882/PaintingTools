# 构图教学体系：构图通法 · 舞台叙事主课

## 前言：摸着主线过河

构图主课不再拆成几十个细碎单点，而是做成一条**能记住的舞台故事**。

我们要同时做到两件事：

1. **让学员听得懂、记得住**：用舞台表演与观众感受，把抽象构图讲成有血有肉的戏。
2. **让场景做得出、验得清**：十场驯冲突就是构图主课；每一场只认一个教学核。

**学员主路径**（氛围 900～903 / 910～924 之后）：

> **构图入门（脉络三遍）→ 十场驯冲突 → 应用篇经典例子**

第一章「知识地图」供策划深读与对照；学员可先走入门三场，不必一上来通读整章。

全文只抓一条主线：

> **用章法秩序，驯化各个大小层级上的差异（冲突）。**

先立几个词，后文不再打架：

| 词 | 它是什么 | 人话 |
| --- | --- | --- |
| **基底统一** | 差异得以发生的共同世界（共识） | 大家先在同一个世界里 |
| **差异 / 冲突** | 在共识之上的分歧与张力 | 有分歧，画面才不平 |
| **造险** | 主题级、最吸睛的那一档差异 | 最大的冲突，用来立题 |
| **章法秩序** | 驯住冲突的调度规矩 | 有分歧，但不翻车 |

所以：

> **冲突不是差异之外的东西；冲突就是带张力的差异。最大的那一处，叫造险。**

全文结构：

| 段 | 内容 | 作用 |
| --- | --- | --- |
| **通法篇 · 入门** | 脉络三遍（剥洋葱） | 同一条主线，由浅入深讲清 |
| **通法篇 · 主课** | 十场驯冲突 | 按主线一场一核落地 |
| **知识地图** | 第一章细则 | 策划 / 深读对照 |
| **应用篇** | 经典构图例子（S / V / 三角 / 天地分界等） | 用通法拆行业老配方 |

总纲金句：

> **先共一个世界，再驯一场戏里的冲突。**  
> **基底统一管成立，章法秩序管高级；差异是共识上的分歧。**  
> **小层驯住，才不碎；中层驯住，才耐看；大层驯住，主题才立得住。**  
> **无秩序则乱，无冲突则平；驯住冲突，才是构图正道。**

## 一、知识地图：同一世界、分歧、驯化

### 1.0 总图：先知道自己在学什么

构图课真正要教学员做到的，不是先背很多名词，而是先抓住：

> **先同一世界，再有分歧；有分歧，再驯化。**

| 层级 | 名称 | 回答什么问题 | 解决什么毛病 |
| --- | --- | --- | --- |
| **同一世界** | **基底统一** | 分歧是不是发生在同一个世界里？ | 假、碎、裂、穿帮 |
| **章法调度** | **章法秩序** | 分歧有没有被驯住、主题立不立得住？ | 乱、俗、散、无主题、太平 |

> 不要把上面两层都叫成「法」——一层是**世界能不能成立**，一层是**戏怎么排、冲突怎么驯**，分工不同。

```text
构图知识体系
│
├─ 同一世界：基底统一（共识）
│   └─ 光 / 透视 / 地面 / 氛围 —— 可验的共同条件
│
├─ 共识上的分歧：差异（冲突）
│   ├─ 小冲突：局部起伏（疏密、高低、递进、顾盼……）
│   └─ 大冲突 / 造险：主题级拉扯（最吸睛、最能立题）
│
├─ 章法秩序：驯冲突的调度
│   └─ 主次 → 平衡 → 节奏 → 律动
│
├─ 通法篇 · 入门：脉络三遍（1000～1002，同一主线由浅入深）
├─ 通法篇 · 主课：十场驯冲突（同一世界 → 分驯四大秩序 → 造险圆满 → 无冲突则平）
└─ 应用篇：经典构图例子（用通法拆老配方）
```

**概念归属表**（后文一律照此理解）：

| 概念 | 在体系中的位置 | 它是什么 | 它不是什么 |
| --- | --- | --- | --- |
| **基底统一** | 同一世界 / 共识 | 差异两方得以对峙的共同条件 | 不是审美高级；也不算「驯冲突」本身 |
| **差异** | 共识上的分歧 | 一切可控变化 | 不是与两层并列的第三层 |
| **冲突** | 带张力的差异 | 能拽眼的分歧 | 不是差异之外的另一套概念 |
| **造险** | 最大的冲突 | 主题级、最吸睛的差异 | 不是只有「反派对峙」这一种摆法 |
| **章法秩序** | 驯冲突的调度 | 管住冲突、定品相 | 不是「另一个世界法则」；也不是物理统一 |
| **四大秩序** | 章法秩序的四个抓手 | 主次 / 平衡 / 节奏 / 律动 | 不是新的独立层级 |
| **十场驯冲突** | 通法篇主课 | 按学习顺序演成连续剧 | 不是平行理论 |

### 1.1 基底统一：差异两方的基本共识

**作用**：让所有「两边」先站在**同一个世界**里。这是冲突能发生的**场地**，不是驯冲突本身。

可以这样记：

> **基底统一，是差异两方的基本共识。**  
> 没有共识，分歧只是各说各话，画面会碎、假、裂。  
> 有了共识，分歧才成为可读的张力。

它回答：

- 光源是不是一套逻辑？
- 透视是不是成立？
- 地面、空间、氛围是不是同一个世界？

具体落地（可验条件）：光源逻辑统一、透视空间统一、地面与环境基调统一、大气氛围统一。

> **就像**同一块台、同一套灯光系统——再激烈的对手戏，也得先站在同一个世界里演；否则不是冲突，是穿帮。

**它解决的是**：碎、假、裂、穿帮。  
**它不解决的是**：好不好看、主题立不立得住。

验收只问一句：

> **这些分歧，是不是发生在同一个世界里？**

---

### 1.2 章法秩序：驯冲突的调度

**作用**：在共识之上，把各个大小层级的冲突驯住，让画面从「成立」走向「高级」。

它回答：有没有主角？有没有压秤？变化有没有顺序？全体是不是一股气？

**它解决的是**：乱、俗、散、无主题、有冲突但没品相。  
**它不负责**：让画面物理上成立——那是基底统一（同一世界）的事。

舞台比喻：舞台搭好了，但全员抢戏、阵容要倒、节奏乱跳、演员各演各的——戏能看，但不好看。

**四大秩序**不是和「同一世界」并列的另一套世界法则，而是**章法秩序驯冲突时要问的四个问题**：

1. **主次秩序**：分歧再大，主角是谁？
2. **平衡秩序**：造险之后，有没有倒？
3. **节奏秩序**：大小起伏有没有顺序？
4. **律动秩序**：全体是不是一股气？

```text
章法秩序（驯冲突）
    ├─ 主次秩序
    ├─ 平衡秩序
    ├─ 节奏秩序
    └─ 律动秩序
```

后文凡写「秩序」，如无特别说明，**均指「章法秩序」**。

---

### 1.3 差异、冲突、造险：共识上的分歧

基底统一搞定之后，画面还要**活起来**，又不能**翻掉**。

#### 差异

差异是在共识之上引入的可控变化。三类工具：

- **形态差异**：大小、体量、方圆、曲直、欹正、长短
- **位置差异**：疏密、聚散、高低、藏露、走势、顾盼
- **光影色彩差异**：明暗、虚实、浓淡、素艳、冷暖、强弱

#### 冲突与造险

| 说法 | 含义 |
| --- | --- |
| **冲突** | 带张力、能拽眼的差异（对外可简称冲突） |
| **小冲突** | 局部起伏：疏密、高低、递进、顾盼…… |
| **大冲突 / 造险** | 主题级拉扯：最吸睛、最能定「这幅画在讲什么」 |

> **后面的「造险入题」专场，不是另起概念，而是把差异推到造险强度——它是所有差异里最大、最主题的那一记。**

#### 运作流程

```text
基底统一（先同一世界）
    ↓
在共识之上引入差异 / 冲突（让画面活）
    ↓
用章法秩序在小、中、大各层驯住（让画面高级）
    ↓
四大秩序逐项落实（主次 → 平衡 → 节奏 → 律动）
```

> **差异让画面不平，章法秩序让画面不翻。**  
> **有冲突无秩序则乱；有秩序无冲突则平。**

---

### 1.4 小 / 中 / 大：同一根绳子上的驯化尺度

| 尺度 | 驯什么 | 意义（学员版） | 主要靠什么 |
| --- | --- | --- | --- |
| **世界前提** | 先同一世界 | 不碎、不假、不穿帮 | **基底统一**（场地，不算驯冲突本身） |
| **小层** | 局部小冲突 | 基础合理、有呼吸、不碎 | 细起伏、局部呼应、小处压秤 |
| **中层** | 整台戏的冲突编排 | 稳而不僵、活而不乱（品相） | 平衡 + 节奏 + 律动 |
| **大层** | 主题级造险 | 一眼有主题、有戏、不翻车 | **主次** + 最大冲突落在主题处 |

> **基底统一先搭台；小冲突养呼吸；中冲突定品相；大冲突立主题——全程都靠章法秩序驯。**

---

### 1.5 四大秩序：分工、判尺、各驯哪类冲突

四大秩序都在驯冲突，但**主攻的冲突类型不同**。先总表，再逐条。

| 秩序 | 主要驯服哪类冲突 | 一句话 | 若驯不住会怎样 |
| --- | --- | --- | --- |
| **主次** | **角色级 / 主题级冲突**（谁抢眼、谁立题；常含造险落点） | 驯「抢戏」 | 多焦点、无主题 |
| **平衡** | **分量级冲突**（左右/上下谁更重、造险后会不会倒） | 驯「要翻」 | 一边塌、一边空 |
| **节奏** | **序列级冲突**（大小、疏密、明暗等起伏是否乱跳） | 驯「乱拍子」 | 平铺死板，或跳变刺眼 |
| **律动** | **关系级冲突**（各朝各向、互不理睬、气脉断裂） | 驯「各演各的」 | 散、碎、拼贴感 |

#### 主次秩序

**一句话**：先回答「谁是主角」。

**主要驯服**：角色级、主题级冲突——谁最抢眼、主题落在哪；造险再大，也必须落在可辨的主峰上（或明确服务于主峰）。

- 画面必须有唯一视觉主峰
- 其余元素都要服务它
- 主不一定最大，但必须最明确

**舞台比喻**：一台戏不能全员抢戏。  
**验收**：学员第一眼落在哪里？其他元素有没有主动衬托它？

#### 平衡秩序

**一句话**：再回答「这幅画有没有倒」。

**主要驯服**：分量级冲突——疏密、轻重、偏正、造险造成的「一边压过来」；一边造险，另一边要能托住。

- 不追求死板对称
- 追求动态压秤

**舞台比喻**：阵容可以偏，但不能塌。  
**验收**：哪一边在施压？哪一边在压秤？

#### 节奏秩序

**一句话**：再回答「变化有没有顺序」。

**主要驯服**：序列级冲突——大小、疏密、明暗、聚散等**沿视线展开时**的起伏；要递进、有松紧，不平铺，也不乱跳。

**舞台比喻**：不是全场一个拍子，也不是乱拍子。  
**验收**：大小、疏密、明暗变化，能不能顺着读下去？  
**判尺**：节奏看「变化有没有顺序」——递进、过渡、张弛、起伏。

#### 律动秩序

**一句话**：最后回答「全体是不是一股气」。

**主要驯服**：关系级冲突——朝向各异、走势互扯、小组互不理睬；要呼应、抱团、气脉贯通。

**舞台比喻**：不是各演各的，而是整台戏同气联动。  
**验收**：个体之间有没有呼应？整体是不是朝同一个气场在走？  
**判尺**：律动看「个体有没有关系」——呼应、走势、联动、抱团、气脉。

#### 四大秩序的推进顺序

1. **主次**：先驯「谁抢戏」→ 定核心  
2. **平衡**：再驯「会不会倒」→ 定不翻  
3. **节奏**：再驯「乱不乱跳」→ 定不板  
4. **律动**：最后驯「散不散」→ 定不散  

> **同一处造险，往往要几项秩序一起驯：** 主次定它落在主题上，平衡定它不翻车，节奏定它嵌进起伏，律动定它仍属一股气。分项是为了好学，不是说现实里只开一个开关。

后面十场按「同一世界 → 四大秩序分驯 → 造险圆满 → 无冲突则平」推进，**每场只认一个核心进步**，不四项平均讲。

### 1.6 学习流动脉络

| 步骤 | 学什么 | 带走什么 |
| --- | --- | --- |
| **0** | 主线：秩序驯冲突 | 无秩序则乱，无冲突则平 |
| **1** | 基底统一 = 同一世界 / 共识 | 没有共识，分歧只是穿帮 |
| **2** | 差异 / 冲突 / 造险 | 造险 = 最大的、主题级冲突 |
| **3** | 章法秩序 + 小中大驯化 | 小层不碎、中层耐看、大层立题 |
| **4** | 四大秩序各驯哪类冲突 | 角色 / 分量 / 序列 / 关系 |
| **入门** | **脉络三遍**（通法篇 · 入门） | 同一条主线，由浅入深讲清 0～4 |
| **5** | 十场驯冲突（通法篇 · 主课） | 按知识顺序一场一核落地 |
| **6** | 经典构图例子（应用篇） | 用通法拆行业老配方 |

**入门怎么教（剥洋葱）**：不把 0～4 拆成五场单点，而是用 **三场** 把同一条主线梳理三遍——第一遍抓住主线，第二遍钉关键词，第三遍拆四个问题。主标注 = 本遍梳理全文；黑体词配 **概念标注**（短释）。

**故事线主轴（与十场同轴）**：

> **先同一世界，再分清乱冲；再按主次→平衡→节奏→律动分驯；再造险立题、合驯圆满；最后看无冲突则平。**

展开为：

1. 无共识 → 穿帮（场 1）  
2. 有共识但失驯 → 乱（场 2）  
3. 驯主次 → 驯平衡 → 驯节奏 → 驯律动（场 3～6）  
4. 造险入题 → 合驯圆满（场 7～8）  
5. 冲突消退 → 冲突归零（场 9～10）  

十场不是十个平行名词，而是：

> **一条与第一章知识顺序同轴的「驯冲突」教学线。**

### 入门场 1：构图脉络 · 第一遍

**副标题**：先抓住主线

**主标注**：

> 氛围练完，万物共一气、共一套光，世界开始像真的了。接下来谈**构图**：框里怎么排才好看。
>
> 构图先抓住一条主线：
>
> **用秩序，驯住冲突。**
>
> **冲突**让画面不平、有看头；**秩序**让冲突不乱、站得住。少一头都不行：
>
> **无秩序则乱；无冲突则平。**
>
> 主线展开是三步——第一遍只记顺序：
>
> 1. **先同一世界**：光、气、空间要像在同一个环境里；否则会假、会碎。  
> 2. **再有分歧**：世界共了，还要有变化，画面才活。  
> 3. **再用秩序去驯**：有看头，但不乱、不倒、不散。
>
> 下一场还沿着这条主线走，把关键词说清楚。

**概念标注**：

| 词 | 释义 |
| --- | --- |
| **构图** | 框里怎么排：有看头，又不乱。 |
| **冲突** | 能抓住眼睛的分歧；画面因此不平。 |
| **秩序** | 驯住冲突的规矩。（后文也称章法秩序） |

**金句**：先共一个世界，再驯冲突。

**几何体怎么摆**：可不摆；若有背景静帧，画框 + 2～3 体居中略稳，光/气用氛围默认，不造险。

---

### 入门场 2：构图脉络 · 第二遍

**副标题**：把关键词说清楚

**主标注**：

> 还是这条主线。这一遍给三步换上更准的词。
>
> **构图：用章法秩序驯住冲突。**  
> （无秩序则乱，无冲突则平。）
>
> **第一步：先同一世界。**  
> 共同条件叫**基底统一**——先有共识。没有共识，再怎么对比也只显得假、碎。同气、同光，就是同一世界的一部分。
>
> **第二步：再有分歧。**  
> 共识上的变化叫**差异**（大小、疏密、明暗等）。  
> 有张力、能抓住眼睛的差异叫**冲突**。  
> 最大、最能说明「这幅画在讲什么」的那一处叫**造险**。  
> 冲突不是另起一套；造险是最大的冲突。
>
> **第三步：再用秩序去驯。**  
> 驯冲突的规矩叫**章法秩序**。检查时可以从近到远看三层：
>
> - **局部**：细节碎不碎、闷不闷  
> - **整幅**：整张稳不稳、活不活、耐不耐看  
> - **主题**：最要紧的那一处清不清楚、站不站得住  
>
> 下一场仍沿这条主线，把检查时常用的四个问题说清楚。

**概念标注**：

| 词 | 释义 |
| --- | --- |
| **基底统一** | 同一世界的共识：同光、同气、透视通等。 |
| **差异** | 共识上的变化：大小、疏密、明暗等。 |
| **冲突** | 有张力、能抓住眼睛的差异。 |
| **造险** | 最大、最能立住主题的冲突。 |
| **章法秩序** | 驯冲突的规矩；管好不好看，不管像不像同一个世界。 |
| **局部 / 整幅 / 主题** | 检查时的三层：细节 → 整张画 → 这幅画主要在讲什么。 |

**金句**：差异让画面不平，秩序让画面站得住。

**几何体怎么摆**：可不摆（纯文字场）。

---

### 入门场 3：构图脉络 · 第三遍

**副标题**：四个问题，可以开始练

**主标注**：

> 第三遍仍是这条主线，只把秩序拆成四个好记的问题。
>
> 主线回顾：
>
> **先同一世界 → 再有差异与冲突（必要时到造险）→ 再用秩序按局部、整幅、主题去驯。**
>
> 画画时，可以依次问自己：
>
> 1. **主次**：哪里最重要？——先别让到处都在抢眼。  
> 2. **平衡**：会不会一边太重、像要倒？  
> 3. **节奏**：大小疏密的变化乱不乱、闷不闷？  
> 4. **律动**：各部分连不连得上，像不像一个整体？  
>
> 建议顺序：**主次 → 平衡 → 节奏 → 律动**。真画时常常一起想；分开问，只是更好学。
>
> 三遍够了。接下来按这条主线，一场一场练。跟着看就行；看完可以问自己：刚才不舒服，是假、是乱，还是平？
>
> 下面进入构图主课。

**概念标注**：

| 词 | 释义 |
| --- | --- |
| **主次** | 先定哪里最重要；避免到处抢眼。 |
| **平衡** | 看会不会倒、站不站得住。 |
| **节奏** | 看变化顺不顺、闷不闷。 |
| **律动** | 看各部分连不连成一个整体。 |

**金句**：先定重点，再问倒不倒、顺不顺、连不连。

**几何体怎么摆**：可不摆；若做四问示意，勿抢眼。

## 三、通法篇 · 十场驯冲突

### 3.0 这一出戏怎么看

十场是**同一出连续剧**，戏名可以叫：**《一出差点散掉的戏》**。

学员像坐在观众席里，**事先不知道下一幕会发生什么**。每一幕只解开眼前这一步的困境；知识点藏在故事里，最后才点题——不要先发讲义。

讲述顺序（主标注一律遵守）：

1. 上一幕留下什么（钩子）
2. 这一幕舞台上发生了什么
3. 观众心里怎样
4. 几何体里对应看见什么（就像……）
5. 最后一句才点出本场道理

生产端仍保留「几何体怎么摆」。主标注走引线展开/收起。

| 幕 | 标题 | 副标题 | 故事上发生什么 | 本场核（对内） |
| --- | --- | --- | --- | --- |
| 1 | 无共识·穿帮 | 灯乱了，台也不像一台 | 信不过这个世界 | 先同一世界 |
| 2 | 乱冲·失驯 | 人到齐了，戏却更吵 | 烦从「假」变成「乱」 | 无秩序则乱 |
| 3 | 立主角 | 终于有人被光钉住 | 眼有了落点 | 驯抢戏 |
| 4 | 压得住 | 人有了，阵容还像要塌 | 不踏实 | 驯要翻 |
| 5 | 有呼吸 | 稳住了，却像一个拍子念到底 | 腻、想走神 | 驯乱拍 |
| 6 | 一股气 | 拍子有了，人还不互相看 | 仍散 | 驯各演各的 |
| 7 | 造险入题 | 忽然杀进一股对峙 | 悬着、被吸住 | 最大冲突立题 |
| 8 | 驯住圆满 | 对峙被收进戏里 | 过瘾又稳 | 驯住而非消灭 |
| 9 | 温吞失味 | 情绪收掉了 | 不烦也不想看 | 无冲突则平 |
| 10 | 死寂无魂 | 连戏都没了 | 空 | 抹平则死 |

场景编号：**待定**。画框 + 推荐视角；光/气沿用默认，只改框内摆法。

### 场 1：无共识·穿帮

**标题**：无共识·穿帮  
**副标题**：灯乱了，台也不像一台

#### 主标注

开场你就觉得不对劲。灯这边亮一下、那边灭一下，演员像踩在不同的地板上——有人亮得刺眼，有人整个人像被贴进另一套布景。你还没开始「看戏」，心里先退了一步：这真是同一台演出吗？那种烦，不是内容太多，而是**信不过这个世界**。把目光转到几何体：主光乱跳、颜色硬拼、有的形大得不像在同一空间——你刚才那种「穿帮感」，就摆在眼前。先记住今晚的第一课：分歧可以有，但大家得先站在同一个世界里；否则热闹只是事故，还成不了构图。

#### 几何体怎么摆

- 球体、立方体、圆柱、圆锥混用 6～8 个，大小可乱。
- **故意破坏基底统一**：局部过亮/过暗互不相关；固有色硬拼多色；个别形体尺度违和，像「浮」在另一套透视里。
- 地面基调不统一感（可局部色差）；取景框入镜，略俯看全。

#### 本场只带走一句

> **先同一世界：没有同一个世界，分歧只是事故，不是构图。**

---

### 场 2：乱冲·失驯

**标题**：乱冲·失驯  
**副标题**：人到齐了，戏却更吵

#### 主标注

好消息是：灯总算像同一套系统了，地板也像同一块台。你松半口气——至少不像穿帮了。可麻烦马上换了一种：人人都在抢话，有人朝左、有人朝右，密的地方挤成一团，空的地方又甩着几个人各演各的。你仍烦，但说不清为什么：世界好像「成立」了，戏却更吵。就像演员都到齐了，导演却还没来。几何体也一样：光与透视已经统一，却找不出谁最该看，到处都在拽眼。上一幕问的是「是不是同一个世界」；这一幕逼你发现——**光有同一个世界还不够，冲突若没人管，照样会乱。**

#### 几何体怎么摆

- **恢复基底统一**：同一主光、同一地面、透视成立、色温基调一致。
- 8～12 个形体仍乱：大小朝向无呼应，多处同时抢眼，无唯一主峰。
- 可有强烈疏密/明暗差，但故意无人调度。

#### 本场只带走一句

> **世界齐了仍会乱：冲突失控、无人驯化，戏还是立不住。**

---

### 场 3：立主角

**标题**：立主角  
**副标题**：终于有人被光钉住

#### 主标注

吵到你几乎想离场时，忽然有人走到偏中心，挺直身姿——一束光追上去，只照亮他。周围还在动、还在响，可你的眼睛第一次肯停住了。心里那句几乎脱口而出：原来该看他。注意：这一幕并没有把全场收拾干净，配角仍可能乱七八糟；它只做了一件要紧事——让「抢戏」先停一停。几何体里，你会看见一根又高又亮的圆柱（或竖立长方体）从乱局里站出来，小形还在，却明显矮一截、暗一截。就像正式演出终于定了主演：主题有了落点，后面才谈得上排阵容。

#### 几何体怎么摆

- **主角**：高大圆柱（或竖立长方体），中心略偏，竖向最高；主光对准它。
- **配角**：5～7 个更小更矮的球体/立方体/小锥，可略散，体量明显让步。
- 基底统一保持；暂不要求完美平衡与节奏。

#### 本场只带走一句

> **先让观众知道谁是主角——驯住抢戏，戏才开得了头。**

---

### 场 4：压得住

**标题**：压得住  
**副标题**：人有了，阵容还像要塌

#### 主标注

主演定了，你松了口气，却隐约觉得台面还在晃：人好像都堆在一侧，另一侧空荡荡，整台戏像跷跷板要翻。你看得懂「该看谁」，却看不踏实。于是配角开始懂事——退到两侧与后方，放低身姿，给中心让出气口；不是对称排队，而是把分量托住。你心里那句变成：可以偏，但不能倒。几何体里，高圆柱仍在，矮一些的球体、短圆柱分列两侧后方，前方留白，配角更暗更素。就像阵容终于站稳：上一幕解决「看谁」，这一幕解决「会不会塌」。

#### 几何体怎么摆

- 保留场 3 高大圆柱主角与主光。
- 两侧与后方 4～6 个矮球体/短圆柱/小立方体，左右分量大致压秤；前方留白。
- 配角更暗更素；可有轻微左右疏密差，但全框不倒。

#### 本场只带走一句

> **可偏、可险，但不能倒——阵容要压得住。**

---

### 场 5：有呼吸

**标题**：有呼吸  
**副标题**：稳住了，却像一个拍子念到底

#### 主标注

台面不晃了，你却开始走神：所有人好像用同一个音量、同一个间距在表演——规整是规整，像念稿，不像戏。你不烦了，但也不想往下听。于是舞台悄悄换了呼吸：有人近、有人远，亮有强弱，疏密有快慢，视线能顺着走下去，而不是被齐步走催眠。几何体里，大小从前到后递进，中心略聚、外侧略疏，主角最亮、远处更弱——你刚才嫌「平」的地方，开始有起伏了。记住：这一幕不是再立一个主角，而是让变化有顺序；戏要耐看，得会换气。

#### 几何体怎么摆

- 在场 4 站位上：主体→次体→远小形，尺度递减可读。
- 疏密：中近略聚，外缘与留白交替，避免等距栅格。
- 光：主角最亮，中景次之，远景更弱；忌忽明忽暗无序。

#### 本场只带走一句

> **稳住之后还要会换气——起伏有顺序，戏才不腻。**

---

### 场 6：一股气

**标题**：一股气  
**副标题**：拍子有了，人还不互相看

#### 主标注

呼吸有了，你却仍觉得像拼盘：每个人零件都不错，眼神却不往来，走位也不朝一处使。台上像开了好几场小戏。直到群演开始「顾盼」——朝向中心那位，两两先抱团，再汇成一股气，你才忽然觉得：哦，这是一台戏，不是一堆人。几何体里，锥尖、棱边、短轴微微朝向那根高圆柱，小组互相牵引，没有一件孤立背对主角。上一幕管「变奏顺不顺」；这一幕管「人连不连」。散，往往不是缺主角，而是缺呼应。

#### 几何体怎么摆

- 在场 5 基础上：辅助体朝向/长轴倾向主角；2～3 个先抱团，再汇向主峰。
- 杜绝背对主角的「各演各的」；画面以正例为准。
- 保持主次、平衡、节奏成果，本场只加强呼应。

#### 本场只带走一句

> **零件好不算戏——互相看、抱成团，才是一股气。**

---

### 场 7：造险入题

**标题**：造险入题  
**副标题**：忽然杀进一股对峙

#### 主标注

戏眼看要「排顺了」，忽然侧翼杀进一股人不一样的势力：站得更聚，姿态更硬，颜色更冲，和主演阵营拉成对峙。你心里一紧——有悬念了，也不再平淡。可你仍清楚该看谁：追光还在主演身上，台面也没塌。别误会：这不是换了一出新戏，而是这出戏里**最响的那一记分歧**来了；它仍是差异，只是拉到最能立题的强度。几何体里，对侧冲色的斜棱柱、尖锥聚成一团拽眼，但高圆柱仍最高最亮。敢造险，才有戏；险若盖过主角、压垮台面，就退回开场的乱。

#### 几何体怎么摆

- **正派**：延续场 6——高大圆柱主角 + 素淡配角，偏一侧。
- **造险侧**：3～4 个棱柱/斜圆柱/尖锥，补色或高饱和，集中对侧，略斜略聚。
- 守底：反派不得比主角更抢眼；基底统一不破。

#### 本场只带走一句

> **最响的分歧用来立题——可以造险，但不能抢戏、不能翻台。**

---

### 场 8：驯住圆满

**标题**：驯住圆满  
**副标题**：对峙被收进戏里

#### 主标注

你以为终场会把对手清空，舞台却做了更聪明的事：两边开始穿插，颜色不那么刺，强弱有了呼吸——对抗还在，却像被写进剧本里的一部分。你既过瘾，又踏实；愿意再看一眼。几何体里，冲色降了一点纯度，小形你中有我、我中有你，主角仍清楚，全框仍稳，走势仍朝同一气场。回想从穿帮、乱吵、立主演、压阵容、换呼吸、成一股气，到造险——这一幕不是删掉冲突，而是把冲突驯住。高级感，往往就在这里：有险不乱，有变不散。

#### 几何体怎么摆

- 在场 7 上：反派色降纯，仍可辨冷暖/补色。
- 1～2 个反派小形插入正派疏区，1 个正派小形点到对侧；强弱强弱可读。
- 自检：主角清？不倒？能顺着读？一股气？差异仍在？

#### 本场只带走一句

> **终场不是清空对手——把冲突驯进戏里，才有险不乱、有变不散。**

---

### 场 9：温吞失味

**标题**：温吞失味  
**副标题**：情绪收掉了

#### 主标注

圆满之后，戏忽然「收了」。人还在，站位大致对，主演也还在，可反差淡了，灯平了，动作齐了——像还在演，却开始念稿。你不烦，奇怪的是也不想看了。心里那句很诚实：挺整齐的……然后呢？几何体里，刺眼的对冲被抹平，明暗变匀，聚散变温和，只剩一个还算清楚的主角。架子没垮，劲没了。这一幕提醒你另一半真理：乱是冲突没人管；平，往往是冲突被管没了。不乱，不等于好看。

#### 几何体怎么摆

- 从场 8 退化：保留主次与大致平衡。
- 抹平强对比色与明暗层级；穿插起伏减弱。
- 主角略大略清楚——框架在，劲没了。

#### 本场只带走一句

> **不烦了也不想看：架子还在，冲突睡着了，只剩温吞。**

---

### 场 10：死寂无魂

**标题**：死寂无魂  
**副标题**：连戏都没了

#### 主标注

若再往下收，连「念稿」都不必了：所有人一个姿势、一个间距、一个妆面，灯均匀得像仓库。没有中心，没有起伏，没有谁看谁。你没有烦躁，也完全无感——不是安静的美，是空。几何体把这件事推到极端：一排完全相同的球（或方），等大等距同色同亮。回想场 8 那个还活着的世界，再看眼前——同一类几何体，一个是戏，一个是布景。别被「特别整齐」骗了：把主次、起伏、联动一起抹平，灵魂就没了。

#### 几何体怎么摆

- 6～9 个完全相同的球体（或立方体）：等大、等距、同色、同亮度、同朝向。
- 无主光焦点、无疏密、无顾盼。
- 宜与场 8 对照看。

#### 本场只带走一句

> **连戏都没了：抹平主次、起伏与联动，画面就会死。**


## 四、应用篇 · 经典构图例子（骨架）

通法篇走完，学员应能用**四问卡**读任何画面（亦即场 3～6 分驯过的四类冲突）：

1. **主角是谁？**（主次 · 驯角色级冲突 · 场 3）  
2. **有没有倒？**（平衡 · 驯分量级冲突 · 场 4）  
3. **变化有没有顺序？**（节奏 · 驯序列级冲突 · 场 5）  
4. **整体是不是一股气？**（律动 · 驯关系级冲突 · 场 6）  

应用篇的任务：**不另立门派**。S 形、V 形、天地分界等，都是行业积累的「老配方」——我们用「秩序驯冲突」去拆，而不是重新背一套名词。

### 3.1 用法

每个经典例子只做三件事：

1. 用几何体摆出该「老配方」的典型样子  
2. 用四问卡走一遍  
3. 点明：它主要制造了哪一档冲突（小冲突还是造险），又主要靠哪几项秩序驯住

## 六、全篇最短结论

### 6.1 学员版四句

1. **基底统一是同一世界（共识）；差异是共识上的分歧。**  
2. **冲突 = 带张力的差异；造险 = 最大的、主题级冲突。**  
3. **用章法秩序驯冲突：小层不碎，中层耐看，大层立题。**  
4. **四大秩序各有主攻：主次驯抢戏，平衡驯要翻，节奏驯乱拍，律动驯各演各的。**

### 6.2 一条故事主线（入门 → 十场）

先走入门三遍（同一条主线，由浅入深），再看通法主课连续剧：**《一出差点散掉的戏》**——观众跟着入场，一幕解开一幕的困境。

> **穿帮 → 乱吵 → 立主演 → 压阵容 → 换呼吸 → 成一股气 → 造险 → 驯住 → 温吞 → 死寂。**

### 6.3 一条判尺（四问卡）

1. **主角是谁？**（角色级）  
2. **有没有倒？**（分量级）  
3. **变化有没有顺序？**（序列级）  
4. **整体是不是一股气？**（关系级）

### 6.4 终极金句

> **先共一个世界，再驯一场戏里的冲突。**  
> **基底统一管成立，章法秩序管高级；无秩序则乱，无冲突则平。**
