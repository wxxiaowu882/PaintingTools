## 0. 设计原则（2026-11-06 修订）

1. **美感优先、少字**：深色工坊格调；避免说明书式长文。  
2. **说人话，但不罗嗦**：四入口用短主标 + 一行短注；内部产品名放商品页。  
3. **图说话**：作品图 + 站内场景图混排（具体版式在确认页甲/乙/丙/丁中选）。  
4. **旧货次要**：不抢主视觉。  
5. **未定稿不实施**：不改线上装修、不重导正式静帧，直到确认页点名定稿。

## 7. 确认页 ↔ 千牛落地（能否实现）

**一句话**：确认页是**设计预览台**，不是淘宝装修引擎。调好看的效果，定稿后靠**导出静帧图 + 热区链接**进千牛；气质可高度还原，HTML/CSS 不能原样跑在淘宝里。

| 确认页上的东西 | 淘宝里能不能有 | 怎么落地 |
|----------------|----------------|----------|
| 深色多列长条、暖底衬字、虚拟剪裁取景 | 能（观感） | 把「图 + 遮罩 + 字」合成一张 PNG/JPG 再上传 |
| 悬停「编辑」、滑条、本机换图 | 不能 | 只在我们确认页用；顾客看不到 |
| 手机 / PC 同一套气质 | 能（设计共用） | 两端后台仍分开装；各导出对应宽度 |
| 点卡片进商品 | 能 | 手机用「多热区切图」等；PC 自定义区/热区能力较弱，常一张图一个链或付费代码 |
| 字号字距与网页 100% 一致 | 难保证 | 字尽量做进图里；淘宝文本模块字体不可控 |
| 与官网同款 **Inter** 细字 | **基本做不到** | 官网用 Google Fonts「Inter」+ 苹方/雅黑回退；旺铺装修**不能**像官网那样挂自定义英文字体。手机装修编辑器有「文字标题」等模块，但是平台自带中文观感（预览里多见苹方系），**没有**可选 Inter。细节见下方 §7.1 |

**推荐落地路径（定稿后）**

1. 确认页调到满意 → 按楼层**导出成品图**（遮罩与标题已烤进图）。  
2. **手机**：单图海报 / 多热区切图为主（宽约 **1400**，高按模块限制，常见上限约 **2400**，≤约 2MB；以千牛当页提示为准）。两列写生台可做成**一张通栏双卡图**或两张并排（视模块）。  
3. **PC**：自定义区 / 通栏图；尺寸按当页提示（往往更宽）。  
4. 热区链到真实商品；真机预览后再发布。

**做不到 / 别指望的**

- 确认页 CSS 实时叠在淘宝模块上  
- 两端后台一键同步装修配置  
- 与浏览器预览像素级一致（压缩、安全区、模块缝会有轻微差）

未确认前不改线上装修。

### 7.1 字体口径（2026-11-08 后台核实）

**官网手绘工坊**：标题气质主要靠 **Inter（细字重）**，中文回退苹方 / 微软雅黑。  

**淘宝旺铺（本店基础版，已登录核）**：

- 手机装修编辑器里能找到「文字标题」一类模块，但**不能**把全店字设成与官网相同的 Inter。  
- 顾客端文本多半是平台默认中文字体；编辑器预览里官方模块文案可见苹方系（如 `PingFangSC-Medium`），未见 Inter 可选。  
- 商品详情图文侧：文字常被合成图提交，同样**不保证**挂上我们指定的 webfont。  

**落地建议（定稿导出时）**：

1. **主标题 / Pro / 分区短句**：在确认页用 Inter 排好 → **烤进静帧 PNG** 再上传（字形最稳、两端一致）。  
2. **淘宝文本模块**：只放次要说明；接受平台默认中文字，勿指望和官网 100% 同款。  
3. 确认页预览可继续用官网字体栈，方便我们自己对气质；与千牛最终观感的差距靠「字进图」消掉。

### 7.2 首页能不能放竖向视频（2026-11-08）

**一句话**：店铺**首页装修楼层**里的常规视频模块，**不宜指望直接铺满竖屏**；竖向内容另找坑位。

| 位置 | 竖向视频？ | 说明 |
|------|------------|------|
| 手机首页「单视频 / 视频模块」 | **基本按横屏** | 本店编辑器能搜到「单视频」（约 0/2）。商家文档常见要求 **16:9**、最短边约 640×360、时长约 2 分钟内、走淘宝视频。竖片硬塞多半被裁或黑边，体验差。 |
| 商品 **3:4 主图视频** | **可以竖** | 详情头图；建议约 750×1000、时长常见数十秒级。出现在商品页，不是首页楼层。 |
| 店铺二楼 / 内容带货类 | **可能支持 9:16 / 3:4** | 常需内容中心、审核，甚至报名开通；**基础版不一定开得了**，勿当默认能力。 |
| 变通 | 可用 | 首页放竖构图**静帧/海报**；要点播再进商品看 3:4 主图视频。或把竖片裁成 16:9 安全区再挂首页单视频。 |

本店当前：**基础版**；首页智能托管开着。真要上竖视频，优先评估「商品主图 3:4」是否够用，再考虑是否折腾二楼权限。

### 7.3 「约一幅肖像画」能否做成图片轮播（2026-11-08）

**能。** 手机装修编辑器里有官方模块 **「轮播图海报」**（本店可见，额度约 0/20）。多张作品轮播、每张可挂链接（可指定制沟通/商品），适合约画区。

**确认页模拟（2026-11-08）：** 手机 / PC「约画」均为 **5 张轮播**（自动约 3.5s、圆点切换、悬停暂停）；每张可换图 + 与其它槽相同的缩放 / 水平 / 垂直 / 暖底参数。文案「约一幅肖像画」叠在轮播上（实装建议烤进图）。

**和确认页比例比：**

| | 确认页「约画」轮播 | 旺铺轮播图海报（业内口径，以上传提示为准） |
|--|-------------------|-----------------------------------------------|
| 手机 / PC | `aspect-ratio` **100 / 54**（高/宽 ≈ **0.54**） | 宽常见 **1200 / 1400**；高常见 **600～2000/2400**；同组图尺寸须一致 |

**结论：**

- **出图**：按 **高/宽 ≈ 0.5～0.55**（例如 1400×750 或 1200×650）对齐确认页与常见轮播下限；轮播高度往往 ≥600，不会比稿子「矮一截塞不进去」。  
- **不要做竖长轮播**去硬凑肖像竖构图——首页轮播是通栏横条；竖构图应放进横条里做取景（与确认页虚拟剪裁同一思路）。  
- 字（「约一幅肖像画」等）建议**烤进每张图**或第一张带字、其余纯画，避免只靠淘宝文本叠字。
