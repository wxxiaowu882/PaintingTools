## 一、核心概念

**基础规律**讲「为什么」会亮会暗；**万物观察法**讲「怎么看」——从大到小，**先势后质**。  
（万物观察法用阴阳作**观察比喻**，帮助记忆；写生仍以眼中所见为准。）

### 【基础规律】面转则明暗分，体积现

面的转折 → 受光变 → 明暗分 → 体积现  
<典语>：**圆转缓变 / 方折突变**（曲而渐、折而断）

### 【万物观察法】

**一生二 · 亮暗分**  
世界有**阴阳两面**：先把物体分成 **亮部**（向光）、**暗部**（背光）。

**二生三 · 交界立**  
阴阳两面的**交锋就是「三」**（即 **明暗交界带**，不是一条线）：在亮、暗之间找这条界；**大转折**（棱、曲面转向）决定界在哪里、怎么转。

**三生万物 · 层次分化**  
交锋处融合、分化，形成**介于阴阳之间**的各种状态：

- **亮部分化**：
  - **高光**、
  - **亮灰**（哑光可无单独高光，整块亮部即可）
- **暗部分化**
  - **暗灰**
  - **反光**（多在 **暗侧根部以上** 的中下段，易接到台面/环境反射；紧贴根部往往更暗）
  - **投影**（身外，从 **暗侧** 读）
  - **<最深处>**：
    - **交界深带**、
    - **暗侧物体根部**（暗部靠台面的一截，夹角闭塞，直射与反光都难进）、
    - **投影根部**（投影挨物体脚、挨桌面处；常与暗侧根部连成最深带）
- **边缘虚实**（大明暗定后）：看 **轮廓与投影边缘**；宗旨 **对比强则实，对比弱则虚**。

<典语>：**两仪渐分** / **执两端而用中** / **五息相承**（细部一层接一层，别切成补丁）

**由亮→暗**（核对用，**不是**观察第一步）：  
高光 ＞ 亮灰 ＞ 反光 ＞ 暗灰 ＞ 交界深带；**全图最深**常在 **暗侧物体根部** 与 **投影根部**（光位不同时，也与交界深带争最深）。

**x04 最暗处**（大明暗定后）：找 **三处最暗**（交界深带 / 暗侧根部 / 投影根部），用 **受光分析** 判断谁更深。  
**x05 边缘虚实**（同上）：轮廓与投影边缘，**对比强则实，对比弱则虚**。

> **推拉**（固有色强弱、材质、远近、环境加减等）留待 **色彩 / 静物** 阶段；几何体单色阶段不讲。

### 【先势后质 · 走法】


|       | 步骤        | 做什么                        |
| ----- | --------- | -------------------------- |
| **势** | 一生二 + 二生三 | 先 **亮/暗**，再找 **交界**        |
| **质** | 三生万物      | 再拆细：层次 + **最深** + **边缘虚实** |


1. **一生二** — 分 **亮部、暗部**
2. **二生三** — 找 **明暗交界** 与 **大转折**
3. **万物·形** — **亮部分化**；**暗部分化**（层次 + **最深**）
4. **边缘虚实** — 轮廓与投影边缘：**对比强则实，对比弱则虚**

**顺序反了**（先抠高光或跳过亮暗）→ 易 **糊、花、喧宾夺主**。  
<典语>：**先势后质**

### 2 · 色彩

**前提**：学员已完成几何体 **单色 + 大明暗 + 最深 + 边缘虚实**；色彩 **不推翻** 亮暗结构。  
**手段**：用 **带固有色的几何体**；多体同屏时 **开天光**，对比前后变化。  
<典语>：**明暗为骨，色彩为肤** —— 先立骨，再谈色。

#### 色彩三性（同一色相）


| 属性      | 人话     | 在球上怎么看                    |
| ------- | ------ | ------------------------- |
| **色相**  | 是什么颜色  | 单场景固定一种（如红球）              |
| **明度**  | 有多亮/多暗 | 亮部高、暗部低；与 **一生二** 同向      |
| **饱和度** | 有多「纯」  | **亮灰** 较纯、**暗灰** 更灰；**高光** 极亮往往 **饱和度很低**（近白/漂色）；反光勿比亮灰还跳 |


**部位一般规律**（光线对固有色观感）：


| 部位   | 明度  | 饱和度      | 一句话      |
| ---- | --- | -------- | -------- |
| 高光   | 极高  | 很低（近白/漂色） | 最亮处，色被光「冲淡」 |
| 亮灰   | 高   | 相对纯      | 向光侧本色最明显   |
| 明暗交界带 | 低   | 低（收）     | 亮转暗交接；相对亮灰陡暗，色发闷 |
| 暗灰   | 低   | 更灰       | 本色被压暗、变浊 |
| 反光   | 中   | 偏灰或带环境色  | 不是第二个亮灰  |
| 投影   | 低   | 偏灰，常带环境色 | 见「天清而染阴」 |


<典语>：**亮处本色显，暗处色亦收** —— **暗灰** 是 **变灰变浊**，不是另换一色；**环境染色**见下节四类。

#### 环境四类影响


| 来源         | 典语        | 作用（人话）                |
| ---------- | --------- | --------------------- |
| **天 / 天光** | **天清而染阴** | 暗部、投影进 **冷/环境色**，不是画脏 |
| **地 / 台面** | **地厚而返色** | 地面反光给暗部、底边 **暖/环境色**  |
| **整体环境**   | **境色相渗**  | 天空、环境光统一 **偏色倾向**     |
| **邻物**     | **物邻而色交** | 邻近几何体 **互染**，暗部与反光最明显 |


环境改的是 **色味与纯度**，不改 **亮在哪、暗在哪**。

#### 802 场景说明文案（草案）

> **【六区色律，各从其位】**  
> 同一色相下，**高光、亮灰、明暗交界带、暗灰、反光、投影** 六区，各有常位：
>
> ① **高光** — 明度极高；饱和度很低，色被强光「冲淡」，近白/漂色。  
> ② **亮灰** — 明度高；饱和度相对最足，本色最明显。  
> ③ **明暗交界带** — 亮转暗的一带；**明度低**，饱和度收，色发闷。  
> ④ **暗灰** — 明度低；饱和度低而浊，本色被压暗。  
> ⑤ **反光** — 明度、饱和度略高于同区暗灰，**绝不可超过亮灰**；可略混环境色。  
> ⑥ **投影** — 明度低；饱和度低而浊，常偏灰、带环境色味。
>
> **总则**：亮处本色显，暗处色亦收。全图**谁最深**属 x04，802 不展开。

**806** 为色彩段收束：**众色互染**（803～805 环境色综合）+ **众象相摄**（多体并置时的遮挡、投影与光影互涉），不再单独开「多体共置」环。

### 3 · 氛围

**前提**：学员已完成 **几何体（骨）+ 色彩（肤）+ 806 综合**；本节 **不推翻** 亮暗与色律，在之上谈 **整幅如何被「境」统一**。  
**手段**：几何体组合；固定或半固定镜头；分阶段调 **大气/雾/纵深** 与 **主光/环境光**，**对比前后**。

<典语>：**物载于境，先气后光** —— **先讲透气，再讲透光，最后才合在一起**；一路之内 **不混讲**。

**与 806 的分工**：806 **逐物、逐源**（天/地/邻）；氛围段 **整幅一致**——全场共享 **同一套气规律** 或 **同一套光调子**。  
**边界**：氛围 = 场景内的 **气** 与 **光**（与眼/镜头对焦无关）；景深见 **§4 · 1008**。

#### 说明文案（草案）

> **【901 · 物载于境，境托于气】**  
> 先有形有色，再看 **空气与距离** 怎样 **整幅** 托住画面——让「几个物体」变成 **「有境色的空间」**。  
> 中间有 **气**：越远 **色** 越退（**902**），**形** 越柔（**903**），万物共享 **同一套远近规律**（**904** 收束）。**不换光、不混光**；光从 **911** 另起。
>
> **【902 · 色，远淡而近实】（看色）**  
> 离眼越远，中间空气越厚：物体 **明度略升或变灰**，**饱和度收**，常 **略偏天空色**（**远淡**）。近处 **本色更足**（**近实**），仍按 802 / 806 分析；远处整体「退半档」—— **不是换色相**。
>
> **【903 · 形，远柔而近利】（看形）**  
> 同样越远，**轮廓与体面转折** 在空气中 **变柔、变浑**，更易 **融进背景**（**远柔**）。近处 **形边相对利**（**近利**）。与 902 **同时存在**，本课 **专看形、不重复讲色退**。
>
> **【904 · 同气归一】**  
> 强大气、纵深摆开：万物 **共享** **902 / 903** 规律。**只练气，不练光**；光层从 **911** 另讲。
>
> **【911 · 光调归一】**  
> **主光 + 环境光** 罩全场 → **整幅一个调**，不是某一物单独换色。与 **806** 对照：806 **逐物** 圈谁染谁；这里看 **整幅什么光气氛**。**不强调** 902/903 空气远近（留 **914**）。
>
> **【912 / 913 · 换光见调】**  
> **同款摆放、同款镜头**：**912** 定 **第一种光**（如晴/暖天），**913** 为 **912 副本**、生产端改 **第二种光**（如暮/阴）。**用户切换场景** 即对比——**不同光，不同氛围**；不必先会调光（可自行调光观察）。**912 + 913** 成对验收；**仍不强调** 空气远近（留 **914**）。
>
> **【914 · 光气双涵】**  
> **光氛围**（**911 / 912 / 913**）+ **大气透视氛围**（**901 / 902～904**）**叠加**：① 整幅 **同一光调、同向偏色**；② 同一团 **空气** 下，远近仍 **色退、形柔**。分析时 **仍能分开说因**；画时 **允许两层同在**。（**景深** 见 **1008**，勿与 **903 形柔** 混因。）

<典语>：**光气相涵** —— 仅用于 **914 收束**；此前 **气归气、光归光**。

**景深** 不在氛围段，见 **1008 焦层取主**。

### 4 · 构图

**前提**：学员已能看 **形、色、境**；本节引入 **画框意识**——你看到的不是「3D 里随便摆」，而是 **「一幅画」**。  
**手段**：**画框 GLB + 固定（或锁定）镜头**；用 **几何体组合** 讲构图，**先抽象后静物**（1101 段再用真实静物复现同一法则）。  
<典语>：**框内取势，势成则意足** —— 在画框里安排 **主次、重心、动线、留白**。

**与氛围的分工**：**901/902～904 气 → 911/912/913 光 → 914 合一**；1001 起解决 **画框内怎么摆**。

#### 构图四问（每课只答一题）

| 问 | 人话 | 典型形式 |
| --- | --- | --- |
| **重心在哪** | 眼先落哪里 | 居中、三分、黄金分割 |
| **动线怎么走** | 视线被引向哪 | 对角线、三角、S 形 |
| **疏密如何** | 哪紧哪松、哪留空 | 留白、聚密、均衡 |
| **主次谁主** | 谁实谁虚、谁大谁小 | 虚实相生（**构图**虚实）、焦层取主（**对焦**推主次） |

**≠ 701 穿插体**：701 是 **一件** 穿插单体；构图课是 **多个体在画框里的关系**。**≠ 903 形，远柔而近利**：903 是 **空气** 里的形柔；构图段谈 **框内摆放** 与 **取主次**。**≠ 1007 / 1008**：1007 靠 **摆法、大小、留白** 分主次；1008 靠 **眼/镜头焦层** 推一层最清（原因 **不是空气**）。

#### 建议场景分环（1001～1008，待生产）

**标题格式**：`{编号}_画框组合 【构图 {子题}】`（画框 GLB 入镜）

| 编号 | 场景标题（草案） | 典语 / 主题 | 摆什么 | 验收 |
| --- | --- | --- | --- | --- |
| **1000**（段首） | **【构图】框内观物** | 框内取势 | 画框 GLB + 简单几何体；**固定镜头** | 用户理解：我们在学 **画框里的一幅**，不是随便逛 3D |
| **1001** | **画框组合 【构图 居中取势】** | **居中取势** | 画框内 **单一主体居中** | 重心在中轴；左右大致均衡；适合对称形 |
| **1002** | **画框组合 【构图 三分均衡】** | **三分均衡** | 主体落 **三分线/交点** | 重心偏一侧但稳；留白有意识 |
| **1003** | **画框组合 【构图 对角动势】** | **对角动势** | 形体沿 **对角线** 分布 | 视线被斜向带走；有动势但不散 |
| **1004** | **画框组合 【构图 三角稳形】** | **三角稳形** | 三物（或三团形）成 **三角** | 三角控制重心；稳定又不板 |
| **1005** | **画框组合 【构图 疏密留白】** | **疏密留白** | 一密一疏，或 **大面积留空** | 密处聚眼，疏处透气；不塞满画框 |
| **1006** | **画框组合 【构图 同式换物】** | **同式换物** | **同一构图法则**，换形体/大小/远近 | 证明：构图是 **规则**，不是死模板 |
| **1007**（可选） | **画框组合 【构图 虚实相生】** | **虚实相生** | 一主一辅，或一实一虚 | **构图**主次：主形清楚，辅形或背景退 |
| **1008**（可选） | **画框组合 【构图 焦层取主】** | **焦层取主** | 画框内多体纵深；**开/关景深** 对比 | **眼/镜头** 只对一层最清，其余层糊，**突出主体**；**≠ 903 空气形柔** |

#### 1000 场景说明文案（草案）

> **【框内观物】**  
> 画框出现、镜头固定之后：请把屏幕当成 **一幅画**，而不是「在模型里找角度」。  
> 后面每课只改 **框内怎么摆**；空气与色律仍按 902 / 806 已学，本节 **专讲摆放与视线**。

#### 1008 场景说明文案（草案）

> **【焦层取主】**  
> **不是氛围里的空气**，而是 **眼 / 镜头** 只对 **一层** 最清楚，其余距离 **变糊**——常用来 **把眼推向主体**。  
> 与 **903 形，远柔而近利** 对照：关景深，903 的形柔仍来自 **空气**；开景深，糊法 **叠加上去**，但 **原因不同**。  
> 与 **1007 虚实相生** 衔接：1007 靠 **摆**；1008 靠 **焦**；写生看参照时可 **两者皆有**，分析时 **分开记**。

### 5 · 静物

**前提**：几何体与画框构图 **已会**；静物段用 **更真实的物体** 把同一套观察 **再练一遍**（**场景变、知识不变**）。  
**编号**：**1101～**；可与 1006「同式换物」呼应——同一构图/氛围法则，换静物 SKU。

| 编号 | 方向（草案） | 说明 |
| --- | --- | --- |
| **1101** | 静物入门 | 单组静物：骨（亮暗）+ 肤（色）+ 境（氛围）一次走通 |
| **1102** | 静物 + 构图复现 | 复现 1001～1003 中某一式，换静物 |
| **1103** | 静物 + 氛围复现 | 复现 **901/902～904 气** 或 **911/912/913 光** 或 **914 合一** 中某一式，换静物 |
| **1104+** | 轮换展 | 多组静物场景轮换更新；不新增概念时只换摆法与题材 |

<典语>：**形异理同** —— 换真实物件，观察法不换。
