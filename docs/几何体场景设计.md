## 一、核心概念

**基础规律**讲「为什么」会亮会暗；**万物观察法**讲「怎么看」——从大到小，**先势后质**。  
（万物观察法用阴阳作**观察比喻**，帮助记忆；写生仍以眼中所见为准。）

### 【基础规律】面转则明暗分，体积现

面的转折 → 受光变 → 明暗分 → 体积现  
<典语>：**圆转缓变 / 方折突变**（曲而渐、折而断）

### 【万物观察法】

**一生二 · 亮暗分**  
世界有**阴阳两面**：先把物体分成 **亮部**（向光）、**暗部**（背光）。

**二生三 · 交界立**  
阴阳两面的**交锋就是「三」**（即 **明暗交界带**，不是一条线）：在亮、暗之间找这条界；**大转折**（棱、曲面转向）决定界在哪里、怎么转。

**三生万物 · 层次分化**  
交锋处融合、分化，形成**介于阴阳之间**的各种状态：

- **亮部分化**：
  - **高光**、
  - **亮灰**（哑光可无单独高光，整块亮部即可）
- **暗部分化**
  - **暗灰**
  - **反光**（多在 **暗侧根部以上** 的中下段，易接到台面/环境反射；紧贴根部往往更暗）
  - **投影**（身外，从 **暗侧** 读）
  - **<最深处>**：
    - **交界深带**、
    - **暗侧物体根部**（暗部靠台面的一截，夹角闭塞，直射与反光都难进）、
    - **投影根部**（投影挨物体脚、挨桌面处；常与暗侧根部连成最深带）
- **边缘虚实**（大明暗定后）：看 **轮廓与投影边缘**；宗旨 **对比强则实，对比弱则虚**。

<典语>：**两仪渐分** / **执两端而用中** / **五息相承**（细部一层接一层，别切成补丁）

**由亮→暗**（核对用，**不是**观察第一步）：  
高光 ＞ 亮灰 ＞ 反光 ＞ 暗灰 ＞ 交界深带；**全图最深**常在 **暗侧物体根部** 与 **投影根部**（光位不同时，也与交界深带争最深）。

**x04 最暗处**（大明暗定后）：找 **三处最暗**（交界深带 / 暗侧根部 / 投影根部），用 **受光分析** 判断谁更深。  
**x05 边缘虚实**（同上）：轮廓与投影边缘，**对比强则实，对比弱则虚**。

> **推拉**（固有色强弱、材质、远近、环境加减等）留待 **色彩 / 静物** 阶段；几何体单色阶段不讲。

### 【先势后质 · 走法】


|       | 步骤        | 做什么                        |
| ----- | --------- | -------------------------- |
| **势** | 一生二 + 二生三 | 先 **亮/暗**，再找 **交界**        |
| **质** | 三生万物      | 再拆细：层次 + **最深** + **边缘虚实** |


1. **一生二** — 分 **亮部、暗部**
2. **二生三** — 找 **明暗交界** 与 **大转折**
3. **万物·形** — **亮部分化**；**暗部分化**（层次 + **最深**）
4. **边缘虚实** — 轮廓与投影边缘：**对比强则实，对比弱则虚**

**顺序反了**（先抠高光或跳过亮暗）→ 易 **糊、花、喧宾夺主**。  
<典语>：**先势后质**

### 2 · 色彩

**前提**：学员已完成几何体 **单色 + 大明暗 + 最深 + 边缘虚实**；色彩 **不推翻** 亮暗结构。  
**手段**：用 **带固有色的几何体**；多体同屏时 **开天光**，对比前后变化。  
<典语>：**明暗为骨，色彩为肤** —— 先立骨，再谈色。

#### 色彩三性（同一色相）


| 属性      | 人话     | 在球上怎么看                    |
| ------- | ------ | ------------------------- |
| **色相**  | 是什么颜色  | 单场景固定一种（如红球）              |
| **明度**  | 有多亮/多暗 | 亮部高、暗部低；与 **一生二** 同向      |
| **饱和度** | 有多「纯」  | **亮灰** 较纯、**暗灰** 更灰；**高光** 极亮往往 **饱和度很低**（近白/漂色）；反光勿比亮灰还跳 |


**部位一般规律**（光线对固有色观感）：


| 部位   | 明度  | 饱和度      | 一句话      |
| ---- | --- | -------- | -------- |
| 高光   | 极高  | 很低（近白/漂色） | 最亮处，色被光「冲淡」 |
| 亮灰   | 高   | 相对纯      | 向光侧本色最明显   |
| 明暗交界带 | 低   | 低（收）     | 亮转暗交接；相对亮灰陡暗，色发闷 |
| 暗灰   | 低   | 更灰       | 本色被压暗、变浊 |
| 反光   | 中   | 偏灰或带环境色  | 不是第二个亮灰  |
| 投影   | 低   | 偏灰，常带环境色 | 见「天清而染阴」 |


<典语>：**亮处本色显，暗处色亦收** —— **暗灰** 是 **变灰变浊**，不是另换一色；**环境染色**见下节四类。

#### 环境四类影响


| 来源         | 典语        | 作用（人话）                |
| ---------- | --------- | --------------------- |
| **天 / 天光** | **天清而染阴** | 暗部、投影进 **冷/环境色**，不是画脏 |
| **地 / 台面** | **地厚而返色** | 地面反光给暗部、底边 **暖/环境色**  |
| **整体环境**   | **境色相渗**  | 天空、环境光统一 **偏色倾向**     |
| **邻物**     | **物邻而色交** | 邻近几何体 **互染**，暗部与反光最明显 |


环境改的是 **色味与纯度**，不改 **亮在哪、暗在哪**。

#### 802 场景说明文案（草案）

> **【六区色律，各从其位】**  
> 同一色相下，**高光、亮灰、明暗交界带、暗灰、反光、投影** 六区，各有常位：
>
> ① **高光** — 明度极高；饱和度很低，色被强光「冲淡」，近白/漂色。  
> ② **亮灰** — 明度高；饱和度相对最足，本色最明显。  
> ③ **明暗交界带** — 亮转暗的一带；**明度低**，饱和度收，色发闷。  
> ④ **暗灰** — 明度低；饱和度低而浊，本色被压暗。  
> ⑤ **反光** — 明度、饱和度略高于同区暗灰，**绝不可超过亮灰**；可略混环境色。  
> ⑥ **投影** — 明度低；饱和度低而浊，常偏灰、带环境色味。
>
> **总则**：亮处本色显，暗处色亦收。全图**谁最深**属 x04，802 不展开。

**806** 为色彩段收束：**众色互染**（803～805 环境色综合）+ **众象相摄**（多体并置时的遮挡、投影与光影互涉），不再单独开「多体共置」环。

### 3 · 氛围

**前提**：学员已完成 **几何体（骨）+ 色彩（肤）+ 806 综合**；本节 **不推翻** 亮暗与色律，在之上谈 **场景如何被「境」统一**。  
**手段**：几何体组合；固定或半固定镜头；分阶段调 **大气/雾/纵深** 与 **主光/环境光**，**对比前后**。

<典语>：**物载于境，先气后光** —— **先讲透气，再讲透光，最后才合在一起**；一路之内 **不混讲**。

**与 806 的分工**：806 **逐物、逐源**（天/地/邻）；氛围段 **全场一致**——万物共享 **同一套气规律** 或 **同一套光**。  
**边界**：氛围 = 场景内的 **气** 与 **光**（与眼/镜头对焦无关）；景深见 **§4 · 1008**。

#### 氛围的两层理解（分三路教，不混）

| 层 | 人话 | 靠什么 | 场景里发生什么 | 路线 |
| --- | --- | --- | --- | --- |
| **大气透视氛围** | **同一团气** | 空气 + 距离 | 远近 **色退、形柔**（901/902 规律） | **先 · 900 统领 → 901～903** |
| **光氛围** | **同一套光** | 主光 + 环境光 | 全场 **同属一种光调、一种光气氛** | **后 · 910 统领 → 911～ 分维示范** |
| **光气双涵** | 两层叠加 | 光定 + 气在 | 一处完整的 **光气氛 + 空间气** | **终 · 925** |

户外常 **光气同在**，但 **分析时分开记**；**925 之前** 场景里 **只练当前一层**（气段少换光，光段少强调空气远近）。

**≠ 803～805**：色彩段 **单点** 讲天/地/邻 **怎么染**；**910～ 光段** 看 **主光+环境光** 怎样让 **全场** 同处一套光（子课 **一次只改一维**）。

**916～919 光源类型**（与 `Solid.html` / 生产端一致，UI：**聚光灯 / 点光源 / 平行光 / 面积光**）：

| 类型 | 引擎键 | 人话 | 场景氛围倾向 |
| --- | --- | --- | --- |
| **聚光灯** | `spot` | 有 **锥形光柱**，像追光/手电 | 光 **集中在一团**，区外迅速变暗；影边可利可柔（看 size） |
| **点光源** | `point` | 从 **一点向四周** 发散 | **无固定光锥**，近亮远暗；各向受光，影向四周散开 |
| **平行光** | `dir` | **无限远、光线平行**（典型：太阳） | 重 **方向**，轻 **灯位距离感**；全场 **同向** 受光，投影 **互相平行** |
| **面积光** | `rect` | **一块发光面**（窗/柔光箱） | 光源 **有面积、有朝向**；过渡 **柔**，影边 **渐**；近处方向随位置变 |

**≠ 平行光 / 面积光**：平行光来自无限远，**方向处处相同**；面积光是 **近处一面在发光**，有 **面朝向**，近处方向会随位置变。详见 [`docs/美术知识库.md`](美术知识库.md) §光源类型。

**920～924 光向课**：**锁定光源类型**（建议统一 `dir` 或 `spot`），**只改 azimuth / elevation**。

#### 场景标注文案（学员，贴入场景总说明）

**写法（金字塔）**：标题下 **第一句总括整课意思**；接 **一句实例短句**（`比如：……`），帮学员 **代入想象** 该氛围；下面 **2～4 句** 只作说明（机制、场景气氛、收束）。不写「特点 / 场景效果 / 验收」标签；切换对比可放末句。**900 / 910 统领** 可略长；**911～924 子课** 宜短。子课默认已在 **910 同光归一** 体系内，不必每课重复流程句。

> **【氛围-气】物载于境，境托于气**  
> 物有色有形之后，还要问：空气与距离怎样把几个物体 **一起托成「有境色的空间」**。  
> 比如：就像隔着薄雾看桌上几物——近处还实，远处开始发淡、发柔，它们忽然住进 **同一处空气** 里。  
> 气让远近出现 **色退、形柔**（见 **901 / 902**），万物共享同一套远近规律（**903** 收束）。  
> 本段 **只练气，不练光**；光从 **910** 另起。
>
> **【氛围-气】色，远淡而近实**  
> 越远色越退、越近色越实——这是空气对 **色** 的远近规律。  
> 比如：就像远山发灰发淡、近处的球本色更足——远物像 **退了色**，近物颜色更 **实**。  
> 离眼越远，中间空气越厚：明度略升或变灰，饱和度收，常略偏天空色。  
> 近处本色更足，仍可按 **802 / 806** 分读各部；远处整体「退半档」，**不是换色相**。
>
> **【氛围-气】形，远柔而近利**  
> 越远形越柔、越近形越利——这是空气对 **形** 的远近规律。  
> 比如：就像远处的楼廓在雾里变浑，近处的棱边却清楚——远物 **边沿柔**，近物 **边沿利**。  
> 远处轮廓与转折在空气中变柔、变浑，更易融进背景。  
> 近处形边相对利。与 **901** 同时存在，本课 **专看形**。
>
> **【氛围-气】同气归一**  
> 同一场景里的各物体，共享 **同一套大气**——不是每个物体各有一套「自己的空气」。  
> 比如：就像同一间房间里，无论桌前还是桌后，空气都是 **同一股**——远淡近实、远柔近利，规则不因人而异。  
> 这套气对全场一视同仁：散射、远近对色和形的作用方式一致，远近变化有秩序、可预期。  
> 物体之间的关系，是被 **同一团气** 统一起来的；合在一起就是一个空间、一套规则，这就是「同气归一」。  
> 本课 **只练气，不练光**。
>
> **【氛围-光】同光归一**  
> 同一场景里的各物体，共享 **同一套光**——不是每个物体各有一套「自己的照明」。  
> 比如：就像同一间教室只开 **同一组灯**——每个物体各部位仍可细看，但全场是一种光、一种调子。  
> 主光与环境光按同一方案作用，全场同属一种光调、一种光气氛。  
> 各部位色味仍可按 **802 / 806** 分读；这里看的是 **场景什么光环境**，不是 **806** 那样逐物圈染。  
> 不强调 **901 / 902** 空气远近（留给 **925**）。
>
> **【氛围-光】暖调**  
> 同一组合，场景 **偏暖**——全场共享一种暖调子的光气氛。  
> 比如：就像傍晚窗边的暖灯照进静物角——全场发黄、发暖，暗部也带着温意。  
> 不是某一个物体单独变暖；亮处带暖，暗处也浸在暖环境里。  
> 可与 **912 冷调** 切换对比。
>
> **【氛围-光】冷调**  
> 同一组合，场景 **偏冷**——全场共享一种冷调子的光气氛。  
> 比如：就像阴天的冷天光铺进房间——亮处偏清，暗处偏沉，全场浸在冷调里。  
> 亮处清、暗处沉，冷味统一压在全场。  
> 可与 **911 暖调** 切换：形不变，光调变。
>
> **【氛围-光】冷暖平衡**  
> 同一组合，**冷暖兼有**——场景光气氛不偏一边。  
> 比如：就像窗外是阴天冷光、窗边又有暖灯——冷暖都在，但谁也不压垮谁。  
> 暖与冷同场共存、互相牵制，整体稳、自然。  
> 可与 **911 / 912** 切换，看偏暖、偏冷、平衡三种光调。
>
> **【氛围-光】强光**  
> 同一组合，光调 **更强、对比更高**——场景明快、有力。  
> 比如：就像正午太阳直射桌面——亮处很跳，暗处也很深，明暗拉得很开。  
> 亮处更跳，暗处更深，明暗跨度大；全场一起变「有力」，不是某一个特别亮。  
> 可与 **915 弱光** 切换，看场景如何变沉、变柔。
>
> **【氛围-光】弱光**  
> 同一组合，光调 **更弱、对比更低**——场景安静、含蓄。  
> 比如：就像黄昏将尽、室内只留一盏小灯——事事轻声细语，没有刺眼的高光。  
> 高光不刺，暗部不深，中间调子多；没有单独冒出来的亮块。  
> 可与 **914 强光** 成对切换对比。
>
> **【氛围-光】聚光**  
> 主光是 **聚光灯**——光沿锥形射出，全场呈追光式的光气氛。  
> 比如：就像舞台追光只打在中央——光柱里亮，光柱外迅速暗下去，视线被收进一束光里。  
> 有明确光区：区内亮、区外暗。各物同受这一锥光，明暗随「在不在光柱里」而变。  
> 可与 **917 点光 / 918 平行光** 切换，看光区形状如何变。
>
> **【氛围-光】点光**  
> 主光是 **点光源**——从一点向四周发散，像空间中心有一盏灯。  
> 比如：就像夜晚木屋里的一支蜡烛——光从中心向四周铺开，近处亮、远处暗，没有固定的光柱边界。  
> 无固定锥角；离灯越近越亮，越远越暗，影朝四周铺开。  
> 与 **916 聚光** 对比：聚光有光柱边界，点光各向散开、无锥口。
>
> **【氛围-光】平行光**  
> 主光是 **平行光**——来自无限远，全场同一光向，像户外日照。  
> 比如：就像晴天的太阳——光从同一方向来，所有投影彼此平行，明暗主要看面朝向。  
> 光线互相平行，重方向、轻灯位距离；投影方向一致、彼此平行。  
> 可与 **916 聚光** 对比：无追光式光团。
>
> **【氛围-光】面积光**  
> 主光是 **面积光**——从一块发光面照出，光线润、和，影边渐柔。  
> 比如：就像大落地窗或柔光箱——光从一面「窗」照进来，影边柔、过渡渐，不那么一刀切。  
> 光源有大小、有朝向，明暗过渡柔。  
> 与 **916** 比更柔、少硬边光柱；与 **918** 比有「面在哪」的近处感，不只讲方向。
>
> **【氛围-光】正光**  
> 主光从 **正前方** 打来——形体偏平、偏匀，稳而少戏剧。  
> 比如：就像证件照正面打光——迎面照亮，向光面宽、背光面窄，体积感弱一些。  
> 可与 **921 侧光** 切换：亮暗分面立刻清楚。
>
> **【氛围-光】侧光 45°**  
> 主光从 **侧上方约 45°** 来——形体立体、好分析。  
> 比如：就像窗光从斜侧照进桌面——每个体一边亮、一边暗，亮部、暗部、交界同时出现。  
> 可与 **920 正光** 对比：明暗分得更开、形更立。
>
> **【氛围-光】背光**  
> 主光从 **物体后方** 打来——场景呈逆光感，轮廓光强，透而有时空感。  
> 比如：就像人物站在亮窗前——正面暗下去，边沿被光勾亮，像勾了一层轮廓光。  
> 可与 **921 侧光** 对比：背光正面暗、边沿亮；侧光体面仍分亮暗。
>
> **【氛围-光】底光**  
> 主光从 **下方** 照上来——场景反常、戏剧，和日常经验相反。  
> 比如：就像从下往脸上打的手电——下亮上暗，影子往上跑，和日常完全相反。  
> 全场同一套反常光影，不是只有一个物体「闹鬼」。  
> 可与 **924 顶光** 对比：底光影往上，顶光影往下。
>
> **【氛围-光】顶光**  
> 主光从 **正上方** 垂直下来——场景上明下暗，硬、直。  
> 比如：就像正午头顶的太阳或舞台顶灯——顶面最亮，眼窝和下缘容易进阴影。  
> 可与 **921 侧光** 对比：顶光阴影更垂直、更贴结构下缘。
>
> **【氛围】光气双涵**  
> **光与气两层同在**——全场同一套光调，同一团空气下远近仍色退、形柔。  
> 比如：就像户外阴天里的静物——既有同一套侧光，远处又因空气发淡、发柔，光和气同时在场。  
> 分析时仍能分开说因；落笔时允许两层叠加。  
> 景深见 **1008**，勿与 **902 形柔** 混因。

### 4 · 构图

**前提**：学员已能看 **形、色、境**；本节引入 **画框意识**——你看到的不是「3D 里随便摆」，而是 **「一幅画」**。  
**手段**：**画框 GLB + 固定（或锁定）镜头**；用 **几何体组合** 讲构图，**先抽象后静物**（1101 段再用真实静物复现同一法则）。  
<典语>：**框内取势，势成则意足** —— 在画框里安排 **主次、重心、动线、留白**。

**与氛围的分工**：**900/901～903 气 → 910/911～924 光 → 925 合一**；1001 起解决 **画框内怎么摆**。

#### 1008 场景说明文案（草案）

> **【焦层取主】**  
> **不是氛围里的空气**，而是 **眼 / 镜头** 只对 **一层** 最清楚，其余距离 **变糊**——常用来 **把眼推向主体**。  
> 与 **902 形，远柔而近利** 对照：关景深，902 的形柔仍来自 **空气**；开景深，糊法 **叠加上去**，但 **原因不同**。  
> 与 **1007 虚实相生** 衔接：1007 靠 **摆**；1008 靠 **焦**；写生看参照时可 **两者皆有**，分析时 **分开记**。

### 5 · 静物

**前提**：几何体与画框构图 **已会**；静物段用 **更真实的物体** 把同一套观察 **再练一遍**（**场景变、知识不变**）。  
**编号**：**1101～**；可与 1006「同式换物」呼应——同一构图/氛围法则，换静物 SKU。

| 编号 | 方向（草案） | 说明 |
| --- | --- | --- |
| **1101** | 静物入门 | 单组静物：骨（亮暗）+ 肤（色）+ 境（氛围）一次走通 |
| **1102** | 静物 + 构图复现 | 复现 1001～1003 中某一式，换静物 |
| **1103** | 静物 + 氛围复现 | 复现 **900/901～903 气** 或 **910/911～924 光** 或 **925 合一** 中某一式，换静物 |
| **1104+** | 轮换展 | 多组静物场景轮换更新；不新增概念时只换摆法与题材 |

<典语>：**形异理同** —— 换真实物件，观察法不换。
