## 一、核心概念

**基础规律**讲「为什么」会亮会暗；**万物观察法**讲「怎么看」——从大到小，**先势后质**。  
（万物观察法用阴阳作**观察比喻**，帮助记忆；写生仍以眼中所见为准。）

### 【基础规律】面转则明暗分，体积现

面的转折 → 受光变 → 明暗分 → 体积现  
<典语>：**圆转缓变 / 方折突变**（曲而渐、折而断）

### 【万物观察法】

**一生二 · 亮暗分**  
世界有**阴阳两面**：先把物体分成 **亮部**（向光）、**暗部**（背光）。

**二生三 · 交界立**  
阴阳两面的**交锋就是「三」**（即 **明暗交界带**，不是一条线）：在亮、暗之间找这条界；**大转折**（棱、曲面转向）决定界在哪里、怎么转。

**三生万物 · 层次分化**  
交锋处融合、分化，形成**介于阴阳之间**的各种状态：

- **亮部分化**：
  - **高光**、
  - **亮灰**（哑光可无单独高光，整块亮部即可）
- **暗部分化**
  - **暗灰**
  - **反光**（多在 **暗侧根部以上** 的中下段，易接到台面/环境反射；紧贴根部往往更暗）
  - **投影**（身外，从 **暗侧** 读）
  - **<最深处>**：
    - **交界深带**、
    - **暗侧物体根部**（暗部靠台面的一截，夹角闭塞，直射与反光都难进）、
    - **投影根部**（投影挨物体脚、挨桌面处；常与暗侧根部连成最深带）
- **边缘虚实**（大明暗定后）：看 **轮廓与投影边缘**；宗旨 **对比强则实，对比弱则虚**。

<典语>：**两仪渐分** / **执两端而用中** / **五息相承**（细部一层接一层，别切成补丁）

**由亮→暗**（核对用，**不是**观察第一步）：  
高光 ＞ 亮灰 ＞ 反光 ＞ 暗灰 ＞ 交界深带；**全图最深**常在 **暗侧物体根部** 与 **投影根部**（光位不同时，也与交界深带争最深）。

**x04 最暗处**（大明暗定后）：找 **三处最暗**（交界深带 / 暗侧根部 / 投影根部），用 **受光分析** 判断谁更深。  
**x05 边缘虚实**（同上）：轮廓与投影边缘，**对比强则实，对比弱则虚**。

> **推拉**（固有色强弱、材质、远近、环境加减等）留待 **色彩 / 静物** 阶段；几何体单色阶段不讲。

### 【先势后质 · 走法】


|       | 步骤        | 做什么                        |
| ----- | --------- | -------------------------- |
| **势** | 一生二 + 二生三 | 先 **亮/暗**，再找 **交界**        |
| **质** | 三生万物      | 再拆细：层次 + **最深** + **边缘虚实** |


1. **一生二** — 分 **亮部、暗部**
2. **二生三** — 找 **明暗交界** 与 **大转折**
3. **万物·形** — **亮部分化**；**暗部分化**（层次 + **最深**）
4. **边缘虚实** — 轮廓与投影边缘：**对比强则实，对比弱则虚**

**顺序反了**（先抠高光或跳过亮暗）→ 易 **糊、花、喧宾夺主**。  
<典语>：**先势后质**

### 2 · 色彩

**前提**：学员已完成几何体 **单色 + 大明暗 + 最深 + 边缘虚实**；色彩 **不推翻** 亮暗结构。  
**手段**：用 **带固有色的几何体**；多体同屏时 **开天光**，对比前后变化。  
<典语>：**明暗为骨，色彩为肤** —— 先立骨，再谈色。

#### 色彩三性（同一色相）


| 属性      | 人话     | 在球上怎么看                    |
| ------- | ------ | ------------------------- |
| **色相**  | 是什么颜色  | 单场景固定一种（如红球）              |
| **明度**  | 有多亮/多暗 | 亮部高、暗部低；与 **一生二** 同向      |
| **饱和度** | 有多「纯」  | **亮灰** 较纯、**暗灰** 更灰；**高光** 极亮往往 **饱和度很低**（近白/漂色）；反光勿比亮灰还跳 |


**部位一般规律**（光线对固有色观感）：


| 部位   | 明度  | 饱和度      | 一句话      |
| ---- | --- | -------- | -------- |
| 高光   | 极高  | 很低（近白/漂色） | 最亮处，色被光「冲淡」 |
| 亮灰   | 高   | 相对纯      | 向光侧本色最明显   |
| 明暗交界带 | 低   | 低（收）     | 亮转暗交接；相对亮灰陡暗，色发闷 |
| 暗灰   | 低   | 更灰       | 本色被压暗、变浊 |
| 反光   | 中   | 偏灰或带环境色  | 不是第二个亮灰  |
| 投影   | 低   | 偏灰，常带环境色 | 见「天清而染阴」 |


<典语>：**亮处本色显，暗处色亦收** —— **暗灰** 是 **变灰变浊**，不是另换一色；**环境染色**见下节四类。

#### 环境四类影响


| 来源         | 典语        | 作用（人话）                |
| ---------- | --------- | --------------------- |
| **天 / 天光** | **天清而染阴** | 暗部、投影进 **冷/环境色**，不是画脏 |
| **地 / 台面** | **地厚而返色** | 地面反光给暗部、底边 **暖/环境色**  |
| **整体环境**   | **境色相渗**  | 天空、环境光统一 **偏色倾向**     |
| **邻物**     | **物邻而色交** | 邻近几何体 **互染**，暗部与反光最明显 |


环境改的是 **色味与纯度**，不改 **亮在哪、暗在哪**。

#### 802 场景说明文案（草案）

> **【六区色律，各从其位】**  
> 同一色相下，**高光、亮灰、明暗交界带、暗灰、反光、投影** 六区，各有常位：
>
> ① **高光** — 明度极高；饱和度很低，色被强光「冲淡」，近白/漂色。  
> ② **亮灰** — 明度高；饱和度相对最足，本色最明显。  
> ③ **明暗交界带** — 亮转暗的一带；**明度低**，饱和度收，色发闷。  
> ④ **暗灰** — 明度低；饱和度低而浊，本色被压暗。  
> ⑤ **反光** — 明度、饱和度略高于同区暗灰，**绝不可超过亮灰**；可略混环境色。  
> ⑥ **投影** — 明度低；饱和度低而浊，常偏灰、带环境色味。
>
> **总则**：亮处本色显，暗处色亦收。全图**谁最深**属 x04，802 不展开。

## 附 · 速查


| 说法              | 指什么                                 |
| --------------- | ----------------------------------- |
| **一生二**         | 亮部 / 暗部                             |
| **二生三**         | 明暗交界带 + 大转折                         |
| **三生万物**        | 亮部分化 / 暗部分化（层次 + **最深** + **边缘虚实**） |
| **先势后质**        | 势=一二；质=万物（层次 + 最深 + 边缘虚实）           |
| **边缘虚实**        | 对比强则实，对比弱则虚（x05）                    |
| **明暗为骨，色彩为肤**   | 先立大明暗，再谈色                           |
| **同色三性，随光可辨**   | 801：色相不变，明度/饱和度随部位变                 |
| **六区色律，各从其位**   | 802：高光/亮灰/明暗交界带/暗灰/反光/投影的色变化规律 |
| **亮处本色显，暗处色亦收** | 部位表总括；环境染色另见四类典语                    |
| **天清而染阴**       | 天光染暗部与投影                            |
| **地厚而返色**       | 地面反光染色                              |
| **物邻而色交**       | 邻近物体互染                              |


常见误会：**反光**别画比 **亮灰** 还亮。**最深**在 **暗侧** 三处争，**不是**亮侧贴地一带，见 x04（802 只讲六区色律，不展开最深）。**701 穿插体**（一件）≠ **多体共置**（多个同屏）。**推拉**（固有色、环境加减）属色彩/静物阶段，不能代替 **亮暗分**。
