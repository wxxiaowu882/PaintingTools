# 会员上线与日常使用（给业务）

## 从 Portal 怎么进（推荐）

文件夹：`自用工具文件_不部署/0_Portal/`

| 双击这个 | 干什么 |
|----------|--------|
| `20_站点发版.bat` | 把网站上传到线上 |
| `21_打开会员运营台_本地.bat` | **本机**打开运营台（不必先发版；口令多为 `ops-local`） |
| `21b_打开会员运营台_线上.bat` | **线上**打开运营台（要已发版 + 已设口令） |
| `22_会员口令设置说明.html` | 两个口令干什么、在 Cloudflare 怎么点 |

运营台页面地址：`/member-ops`  
学员兑换页：`/member`

---

## 运营台一定要发版后才能用吗？

**不一定。**

- **本机试用 / 自己练发码**：双击 `21_打开会员运营台_本地.bat` 即可，**不用先发版**。  
- **给真实学员发码、改线上收费**：要用线上运营台 → 先发版，并在 Cloudflare 配好下面两个口令。

说明：运营台要「登录、发码」，普通静态预览不够，本地 bat 会起带后台的预览（8788），这是正常的。

---

## 两个口令：干什么用

| 名称 | 白话 | 干什么 |
|------|------|--------|
| `MEMBERSHIP_ADMIN_PASSWORD` | 运营台登录密码 | 防止别人进后台乱发码、改收费 |
| `MEMBERSHIP_SECRET` | 会员总密钥（一长串） | 给兑换码和学员登录「盖章」，防伪造 |

详细点击步骤见 Portal 里的 `22_会员口令设置说明.html`。

生产环境不要开 `ALLOW_PROBE_CODES`。

可选：绑定 KV，名字 `MEMBERSHIP_KV` → 运营台里「保存收费/价格」可立刻线上生效。

---

## 日常流程（一句话）

学员付款并备注档位 → 打开运营台生成码 → 微信发给对方 → 对方在「会员 · 兑换」输入 → 可用收费内容。
