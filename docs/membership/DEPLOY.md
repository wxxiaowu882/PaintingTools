# 会员上线与日常使用（给业务）

## 从 Portal 怎么进（推荐）

文件夹：`自用工具文件_不部署/0_Portal/`

| 双击这个 | 干什么 |
|----------|--------|
| `20_站点发版.bat` | 把网站上传到**正式站** |
| `20b_站点发版_测试环境.bat` | 把网站上传到**测试站**（不碰正式） |
| `21b_打开会员运营台_线上.bat` | **正式站**打开运营台 |
| `21c_打开会员运营台_测试站.bat` | **测试站**打开运营台（`test.wuxiaoart.com`） |
| `22_会员口令设置说明.html` | 两个口令干什么用 |
| `23_设置会员口令.bat` | 正式站上传两个口令 |
| `23b_设置会员口令_测试环境.bat` | **测试站**上传两个口令（与正式分开） |

运营台页面地址：`/member-ops`  
学员兑换页：`/member`  

**权限涂色（推荐日常改档）**：先在运营台登录，再打开 Solid（测站或正式站），右下角「权限涂色」→ 点课表卡片左上角标签轮换「游客→会员→高级」；底部 Tab 同样可涂。正式发版（`20` / `docs/deploy.bat`）会自动把**测站**上的权限（及测站若有的定价 `tiers_live`）同步到正式站（可用 `SKIP_POLICY_SYNC=1` 跳过）。

**同步口径（务必一致）**：

| 测站 KV | 正式发版行为 |
|---------|--------------|
| 有有效 `policy_live` / `tiers_live` | 写入仓库底稿文件 + 正式站同名 KV |
| 没有（尚未涂色/保存） | **跳过该键**，正式站保持原样，**不阻断发版** |
| 读/写真失败（登录失效等） | 发版失败，查 `docs/last-deploy.log` |

紧急只发代码、不改线上权限：`SKIP_POLICY_SYNC=1` 后再跑 `20` / `deploy.bat`。

**发测站（`20b` / `deploy-staging.bat`）绝不覆盖测站涂色**：测站以 KV `policy_live` 为准；发测站只上传静态资源与 Worker，**不会** `kv put` 写权限。仓库里的 `access-policy.json` 只是底稿/兜底，不能拿它整表盖掉测站已涂结果。Agent / 人工发测站时禁止对测站执行 policy 覆盖写入。

**正式发版前自动预检**：`docs/membership/prod-deploy-preflight.mjs`  
- 确认正式站已配置两个 Secret（只查「有没有」，不读出口令内容）  
- 确认探针码（测试假码）已关闭（查运营开关 + 实测兑换会被拒）  
紧急跳过：`SKIP_PREFLIGHT=1`（不推荐）。

**正式发版后自动冒烟**：`docs/membership/prod-deploy-smoke.mjs`（首页 / Solid / 防内嵌头 / 会员公开配置 / 再次确认探针关闭）。Agent 发版约定见 `.cursor/skills/site-prod-deploy/SKILL.md`。

**站点安全配置（防内嵌、模型防盗链 WAF、刻意不做项）**：见 `docs/站点安全配置.md`（Agent 规则 `.cursor/rules/site-security.mdc`）。模型防盗链在 Cloudflare 面板，**不要**写进 Worker。

## 运营台一定要发版后才能用吗？

**要。** 日常验收与发码都走 Cloudflare 上的站：

- **自己练发码 / 验收改动**：先 `20b` 发到**测试站**，再用 `21c` 打开运营台（口令用 `23b` 设的，当前多为 `ops-staging`）。  
- **给真实学员发码、改线上收费**：`20` 发正式站 + `23` 设口令，再用 `21b` 打开正式运营台。

不再维护本机 8788 运营台入口。

## 测试站 / 正式站（看清再用）

| | 测试站（推荐日常验收） | 正式站 |
|--|------------------------|--------|
| 怎么开 | Portal `20b` 发版后 `21c` | Portal `20` 发版后 `21b` |
| 地址 | `https://test.wuxiaoart.com/...`（国内推荐） | `https://wuxiaoart.com/...` 或 `www` |
| 运营台密码 | 已设 `ops-staging`（可用 `23b` 改） | 「23」里设的 |
| 发码记录本 | **测试专用本**（不污染正式） | 正式本 |
| 给学员的码 | 不要用 | 只用正式站发的 |

看网址栏是 `test.wuxiaoart.com` 还是正式主域，就不会搞混。  
（旧地址 `*.workers.dev` 在大陆常需梯子，仅作备用。）

**推荐节奏：** 改完 → Portal `20b` 发测试站 → `21c` 按正常流程验 → 通过后再 `20` 发正式站。

**消费端静态预览：** `19_打开首页.bat` 是纯静态（18080），**没有**兑换/门禁后台。要测兑换、收费场景，请用测试站或正式站上的 `/member`、`/Solid`。

反复测兑换：兑换页点「注销本机会员」+ 运营台对该码点「重置可再兑」。

## 网页提示「Variables cannot be added… static assets」怎么办？

说明 Cloudflare 仍把站点当成「只发静态文件」，设置页里加不了密钥。这是预期限制。

线上项目 **soft-voice-f822 是 Worker（不是 Pages）**。发版脚本会：先把 `functions/` 编成 Worker 脚本，再 `wrangler deploy`。不要用「新建 Pages 项目」去抢同名。

**正确做法：**

1. 双击 `20_站点发版.bat`（上传静态站 + 会员后台脚本）  
2. 双击 `23_设置会员口令.bat`，按提示输入两个口令（走 `wrangler secret put`）  
3. 用 `21b` 打开线上运营台登录（口令设完一般不必再发版）

不要死磕 Workers 设置页里的 Variables。

**发版注意（Worker 单文件 ≤25 MiB）：**  
超大模型（如 `docs/model/石膏头像_男中青年_布鲁特斯_Bargello扫_opt.glb`）和整棵 `自用工具文件_不部署/` 已在 `.assetsignore` 里排除，否则上传会失败。若线上缺该石膏模型，需先压到 25 MiB 以下再放行。

## 两个口令：干什么用

| 名称 | 白话 | 干什么 |
|------|------|--------|
| `MEMBERSHIP_ADMIN_PASSWORD` | 运营台登录密码 | 防止别人进后台乱发码、改收费 |
| `MEMBERSHIP_SECRET` | 卖课总钥匙（建议 16 位以上随机串） | 给兑换码和学员登录「盖章」，防伪造；太短系统会当成没设 |

运营台「总览」里若有测试开关，以网页为准；正式卖课请关掉。也可仍用环境变量 `ALLOW_PROBE_CODES=1` 作初始值。

已绑定 `MEMBERSHIP_KV`（发码记录本）：10 位短码、发码列表、网页保存收费/价格都靠它。

## 日常流程（一句话）

学员付款并备注档位 → 打开运营台生成码 → 微信发给对方 → 对方在「会员 · 兑换」输入 → 可用收费内容。
