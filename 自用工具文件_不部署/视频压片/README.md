# 视频压片（阶段 C · C1）

本地把片子压到「好剪」或「能上 R2」的量级。**不入库大视频**；样片与输出默认在 `E:\视频测试\`。

## 推荐工作流（剪映）

1. **手机原片（常几十 GB / 卡顿）**  
   → 先压 **剪辑代理**（`edit_proxy`）→ 进剪映剪辑。  
2. **剪映导出成片**  
   → 再压 **上架档**（默认 `land_1080` 或竖屏 `vert_preview`）→ 上传 R2。  

两档**不要混用**：代理只为剪辑流畅；上架档才给学员播。

## 档位

| 档 | 用途 | 目标 | 约体积 | 默认输出目录 |
|----|------|------|--------|--------------|
| `edit_proxy` | **剪映前代理** | 最长边 1280、~2Mbps、**veryfast**（压得快） | 远小于原片 | 源旁 `_proxy\` |
| `land_1080`（默认） | **正课上架** | 拟合 1920×1080、~3.5Mbps、AAC 128k | ~**26 MB/分钟** | `_encoded\` |
| `land_720` | 省流备选 | 拟合 1280×720、~2.0Mbps | ~15 MB/分钟 | `_encoded\` |
| `vert_preview` | 小红书式短预告 | 最长边 1280、~2.5Mbps | 约 20 秒 → 数 MB | `_encoded\` |

## 命令

```bash
# 剪映前（代理）
node "自用工具文件_不部署/视频压片/encode-course-sample.mjs" "E:/视频测试/原片.MOV" --preset edit_proxy
# 代理且去掉声音（文件名带 .mute）
node ".../encode-course-sample.mjs" "E:/视频测试/原片.MOV" --preset edit_proxy --mute

# 剪映导出后（上架）
node "自用工具文件_不部署/视频压片/encode-course-sample.mjs" "E:/视频测试/剪映导出.mp4"
node ".../encode-course-sample.mjs" "短预告.mp4" --preset vert_preview
node ".../encode-course-sample.mjs" "...MOV" --t 60   # 只压前 60 秒冒烟
```

Windows：

- 剪映前：拖到 **`压剪辑代理.bat`**，或 Portal **`25_视频压剪辑代理.bat`**
- 剪映后上架：拖到 **`压上架档.bat`**，或 Portal **`25b_视频压上架档.bat`**（默认横屏；答 `V` 为竖屏预告）
- 两个入口都会交互询问 **去掉声音？**（`Y` = 去声 / 直接回车 = 保留）。命令行等价：`--mute`

输出可用 `--out` 改目录。



## 拍摄注意（重要）

- 产品要 **横屏正课**：拍摄时请 **横握手机**，让画面本身就是 16:9。
- iPhone 竖握常出现「文件里宽>高，但带旋转元数据、播出来是竖的」。本脚本按摆正后的画面压；竖拍会得到竖向分辨率（如 608×1080），**不适合当 1A 正课主档**。

## 2026-11-03 样片实测

| 源 | 压后 | 结果 |
|----|------|------|
| `绘画过程片段_原始视频.MOV`（~954MB / 3:41，竖拍+旋转） | `land_1080` | **97.1MB**、608×1080、~3.51Mbps、~26.4MB/分 |
| `剪放映剪辑后放小红书.mp4`（~32MB / 20s 竖 4K） | `vert_preview` | **6.14MB**、720×1280、~2.49Mbps |

原片勿直传 R2；压后再传。
