自用工具 Portal

本目录是「自用工具文件_不部署」的总入口抽屉（文件夹名 0_Portal 会排在最前）。
HTML：对本页或下列 *.html 右键 Open with Live Server（跳转壳会进到真实工具目录，相对资源不坏）。
BAT：在资源管理器中双击对应 .bat（会先切到原工具目录再启动）。
Glb管理器：若要用「打开所在文件夹 / 记住盘符路径」，请双击 01_Glb管理器.bat（自动起 18080），不要只开 Live Server。
模型标注生产工具：会内嵌打开 GLB 管理器，请双击 02_模型标注生产工具.bat，不要只开 Live Server。
追光沙盒场景生产工具：请双击 03_追光沙盒场景生产工具.bat（自动起 18080），不要只开 Live Server。
消费端首页：请双击 19_打开首页.bat（自动起 18080），与 Live Server 互不影响，改其它页面不必重启首页服务。
会员运营：正式发版 20_站点发版.bat + 运营台 21b_…线上.bat；日常验收用测试站 20b + 21c。口令用 23 / 23b（见 22_会员口令设置说明.html）。会员 KV 加密备份：24_备份正式站会员KV.bat（正式发版前也会自动跑）。不再提供本机 8788 运营台。
视频压片：剪映前用 25_视频压剪辑代理.bat；剪映导出后用 25b_视频压上架档.bat（默认横屏；答 V=竖屏预告）。两个入口都会问「去掉声音？Y / 回车保留」。也可把视频拖到对应 bat 上。
