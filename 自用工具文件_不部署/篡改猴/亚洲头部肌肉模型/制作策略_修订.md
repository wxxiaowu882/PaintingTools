# 亚洲头部肌肉模型 — 制作策略（修订）

> 修订原因：旧路线（欧版肌肉 + lattice/顶点追 Base15 侧视 profile_rmse）已导致**正常人头比例崩坏**。  
> Base15 六视图是**设计意向**（配色、大形、整体效果），不是严格正交真值；但**观感标准不降**——必须像正常人头肌肉，且贴近 Base15 意向。

## 1. 旧方法为什么是大方向错的

| 旧做法 | 问题 |
|--------|------|
| 用局部 lattice / 分区顶点去「抠」侧视剪影数字 | 剪影 RMSE 与「像人」无关；为过门控会把颅深、面宽拧歪 |
| 把不一致的六视图当几何真值 | 视图间本身不共形，强拟合必然撕裂比例 |
| 没有「头骨/颅型」层，直接拧肌肉表面 | 解剖上肌肉应附着骨骼；应先定颅型再贴合肌肉（业界与雕塑解剖共识） |
| 数字 4/5 通过仍可观感失败 | 证明主验收必须是**人眼比例 + Base15 意向**，不是单一 profile 小数 |

**结论：停用「profile_rmse 主驱动 + 盲目扫参」作为主线。**

## 2. 网上/业界更合理的做法（摘要）

1. **人种头型差异是全局的，不是局部补丁**  
   SizeChina vs CAESAR 等研究：华人头相对更圆（短头型）、后枕与前额更平、鼻梁更低、颏相对不突。应先改**整体颅型比例**，再谈肌肉细节。

2. **头骨 / 大形优先，肌肉后贴合**  
   Anatomy for Sculptors、解剖建模流程与多层解剖重建论文一致：先定骨骼标志与大比例，肌肉附着其上；或「外轮廓 → 预测颅骨/附着点 → 驱动肌肉网」。

3. **整体非刚性贴合，而不是碎格子拧**  
   Wrap / NRICP（如 trimesh `nricp_amberg`）把**整组拓扑**贴到目标壳，保留肌肉相对关系，避免局部过拟合。

4. **可用的参数化亚洲头作为「比例壳」**  
   Google **GNM Head**（开源）可按 ethnicity/identity 采样亚洲向头形，作笼体或目标表面；再把欧版肌肉 wrap 上去，最后按 Base15 调色与可读性。

5. **可微剪影拟合仅作辅助**  
   PyTorch3D 等适合在**比例壳已正确**之后做轮廓微调，不能从一开始替代颅型阶段。

## 3. 新制作策略（强制分阶段）

### 阶段 A — 正常人头比例壳（硬门槛）

目标：正视「竖长椭圆、不过扁过宽」；侧视「前后深正常、后枕圆而不蛋形外甩、五官不挤在前 1/4」。

做法（择一或组合）：

- **A1**：用 GNM / 亚洲头参数采样 + 我们已有亚洲头骨 GLB，做出**比例参考壳**（可简化笼体）。  
- **A2**：从欧版肌肉外包络生成笼体，按人体测量做**全局**缩放：收 A-P 深、抬颅高、收面宽（一次全局变换，不做分区乱拧）。  
- **验收**：对照页目视 — 「像正常人头」不过关，不进 B。

### 阶段 B — 肌肉整组贴合到壳

- 欧版肌肉（已上色的 Static/Deform 组）作为 floating。  
- 用 **Surface Deform / Mesh Deform / NRICP / Wrap** 整组贴到阶段 A 的壳。  
- 禁止再用「侧视 RMSE 扫几十轮」当主优化器。  
- **验收**：穿插大体保留；比例仍像人；再进 C。

### 阶段 C — Base15 意向精修（不降标）

- 配色、块面分区、深色眼、颈灰等（已有能力复用）。  
- 对照 Base15 六视图做**观感**对齐（大形氛围、结构可读），允许视图间不完全共形。  
- 可选用轻量剪影/区域修正，但**任何一步若破坏「像人」则回退**。

### 阶段 D — 对照页终审

- 唯一对外交付前闸：`打开对照页.bat` → 六视对照。  
- 通过标准：**像正常人头肌肉 + Base15 观感到位**。  
- 旧 profile 数字仅作内部参考日志，**不得单独决定交付**。

## 4. 立即停止 / 允许保留

**停止**

- Q9x 式 profile_rmse 主扫参  
- 为过 occiput/profile 互斥而强 face shrink 导致扁头、蛋形后枕  

**保留**

- 对照页审阅流程  
- 上色 / 材质管线  
- 已验证的渲染与导出脚本  
- 有价值检查点作材质/拓扑来源，**不**当比例真理

### 现行主线：头骨优先重开

1. **起点**：`Q1_recolor`（配色可用，尚未被 profile/PROP 拧坏）。  
2. **比例真值**：亚洲头骨 GLB（`UnifiedSkull`+`Mandible`）的包络，不是 Base15 剪影 RMSE，也不是拍脑袋的 sy/sz。  
3. **步骤**：等高均匀缩放 → 按头骨软组织包络微调（每轴相对均匀缩放钳制在约 ±15%）→ 对照页 + **3D GLB** 目视。  
4. **产物标签**：`SKULL_v1`（检查点 / 对照页 / `glb/SKULL_v1.glb`）。  
5. PROP / Q85 仅作「坏例对照」，不进交付。

下一关：阶段 A 比例由**执行方人眼自迭代**负责（调一点 → 正/侧/顶/背/多侧面观感对比 → 再调 → 总体确认），不以「请用户确认比例对不对」替代。用户终审看设计意向与是否可进 B/C。

| 标签 | 结果 |

| **SHELL_v1** | 短头椭球轻投影 — **用户评约 60 分，现行基线** |
| SHELL_v2 | **坏例·球形头颅** — 禁止推广、禁止当基线 |
| **SHELL_v3** | 自 v1 只补后枕靠 Base15 侧视（进行中） |

**硬规则**：比例验收看颅顶卵圆与多视角观感，**禁止**用含耳 Soft AABB 当前后深真值。  
**协作规则**：阶段 A 比例由执行方「调→看→再调→总确认」闭环；用户终审设计意向，不当比例校对员。  
**方法规则**：同一条 lattice 路线连续 3 轮观感不过关 → 换头骨笼贴合，禁止再盲扫参数。  
**观感规则**：数字进带若 3D/侧视已成「球头/扁盘」，一律判失败；对照页默认推**当前最佳可迭代基线**，不推坏例。
